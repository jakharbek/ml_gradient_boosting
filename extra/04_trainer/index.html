Генератор рабочих тетрадей

Excel-тренажёр «градиентный бустинг своими руками»: ученик сам считает каждый шаг — градиент, остатки, группы, выбор колонки, шаг спуска — а рядом с каждым числом появляется ✓ или ✗. Данные — случайные по уровню сложности или ваши; число шагов, learning rate и способ проверки — любые.

Загружаю Python в браузер…

Данные

Объекты, бинарные признаки (у каждого ровно два значения) и целевая величина y. Все ячейки редактируются; y — до сотых.

Скопируйте таблицу из Excel или Google Таблиц (заголовок + строки: объект, признаки…, y) и вставьте сюда.

4

Варианты для класса

Каждому ученику — свои числа: варианты идут подряд по seed (seed, seed+1, …) с теми же настройками. В архиве — папки «ученикам» и «ответы» и список вариантов.

Работает для случайных данных. Сюжет «наугад» даёт разные сюжеты в разных вариантах, конкретный — одни и те же признаки с разными числами.

5

Как устроена тетрадь

Та же структура, что у рабочих тетрадей № 2–7 курса.

ЗаданиеДанные, ν, число шагов, как проверяются ответы, порядок действий A–D, «где здесь градиентный спуск», шпаргалка и подсказка на старт.
РасчётШаг 0 (среднее) и N сворачиваемых блоков. Жёлтые ячейки — ученика, справа — отметка. Сверху — общий прогресс, у каждого шага — «Проверено: 41 из 41».
СводкаВыбранные колонки, Σ|rᵢ| и предсказания по шагам, «верно в шаге», сверка с эталоном и два графика — по числам ученика.
ОтветыСкрытый ключ: каждое значение тетради по порядку. Можно не включать (только с проверкой по цепочке).

Один шаг — четыре этапа

A. Градиент → остатки∂L/∂Fᵢ = F − y, затем rᵢ = y − F и Σ|rᵢ|.
B. ГруппировкаДля каждой группы каждой колонки: Σr, γ = Σr / |G|, остаток ошибки Σ(r − γ)².
C. ВыборКолонка с меньшей суммой остатков ошибки (при равенстве — верхняя).
D. Шаг спускаh = γ группы, шаг ν·h, F_m = F_{m−1} + ν·h, новый остаток и Σ|rᵢ|.

Протокол округления

Каждое вписанное число ученик округляет до сотых (половина — от нуля, как ОКРУГЛ(x; 2)) и дальше считает уже с ним. Ключ посчитан по тому же протоколу, поэтому совпадает с аккуратным учеником на всех шагах. Если хранить в ключе точные значения (0,0234375 вместо 0,02), то к 20-му шагу расхождения накапливаются: на данных тетради № 7 ученик, честно округляющий до сотых, получил бы больше 80 ложных ✗, а на поздних шагах ключ ждал бы даже другую колонку.

Случайные данные

Объекты — полный перебор значений признаков (4 при двух признаках, 8 при трёх), y = база + Σ ±вклад признака + шум. Вклады различаются в 2–6 раз — одна колонка «весит» больше и забирает первые шаги. Шум — комбинация взаимодействий признаков: он не сдвигает среднее (F₀ целое) и не виден ни одной колонке, поэтому Σ|rᵢ| сходится ровно к Σ|шум| — это «пол» из подсказки тетради.

6

Командная строка

Тот же генератор без браузера: extra/04_trainer/generate.py, нужен только openpyxl.

python extra/04_trainer/generate.py --list                                   # уровни и сюжеты
python extra/04_trainer/generate.py --level 3 --theme bakery --seed 7         # случайные данные
python extra/04_trainer/generate.py --level 4 --steps 15 --lr 0.3 --check strict
python extra/04_trainer/generate.py --data extra/04_trainer/presets/wb7_bakery.json --teacher-copy
python extra/04_trainer/generate.py --data мои_данные.csv --lr 0.5 --steps 10   # CSV: объект; признаки…; y
python extra/04_trainer/generate.py --level 3 --count 30 --out-dir 7Б --teacher-copy   # класс
python extra/04_trainer/generate.py --seed 7 --print-spec > вариант.json    # данные в JSON для правки

Формат JSON — как у кнопки «Сохранить как JSON» выше и пресетов presets/wb2…wb7 (данные рабочих тетрадей № 2–7):

{"theme": "bakery",
 "features": ["Расположение", "Выходной"],
 "rows": [["A", "спальный", "нет", 50], ["B", "спальный", "да", 62],
          ["C", "торговый", "нет", 94], ["D", "торговый", "да", 114]],
 "lr": 0.5, "steps": 20, "mode": "gradient", "check": "chain", "level": 3, "number": 7}

Из Python: from gbtrainer import make_spec, generate → generate(make_spec(level=3, seed=7)) возвращает байты .xlsx.
