# Градиентный бустинг по косточкам

Интерактивный курс на русском языке: от первого дерева решений до XGBoost, LightGBM и CatBoost.
Каждое понятие разбирается на элементы, каждый элемент — на ещё более мелкие, пока не
останутся очевидные основы. Все примеры живые: параметры меняются прямо на странице, код
запускается на Python в браузере и повторяется в Jupyter с точностью до последнего знака.

## Быстрый старт

**Только почитать и поиграть с примерами** — откройте `index.html` в браузере.
Удобнее (и надёжнее для Python в браузере) — через локальный сервер:

```bash
python tools/serve.py          # откроет http://127.0.0.1:8000/index.html
```

**ИИ-ассистент в уроках.** Выделите в уроке любой фрагмент — слово, формулу, абзац — и нажмите появившуюся
кнопку «Спросить ИИ» (или `Alt+I`): справа откроется чат, и ассистент ответит с учётом урока, раздела и
выделенного текста. Ассистент работает через локальный `claude-server` (Claude Code на вашем компьютере, вход
`claude login`, ключ API не нужен). `python tools/serve.py` запускает его автоматически; вручную —
`node claude-server/server.js`. Нужен Node.js 18+. Без сервера курс работает как обычно.
К вопросу можно приложить снимок экрана: кнопка-камера в поле ввода → разрешить показ вкладки → выделить
мышью область (график, виджет, вывод кода). Картинку можно и вставить из буфера обмена (Ctrl+V).

**Работать с ноутбуками и примерами** (Python 3.11–3.12):

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
jupyter lab                     # ноутбуки: lessons/<урок>/jupyter_notebooks/*.ipynb
python lessons/lesson_1/examples/first_model.py
```

**Сквозные примеры** — папка [`examples/`](examples/README.md) рядом с уроками: 30 готовых
сценариев от ручного счёта на 6 точках до миллиона строк, прогноза продаж, ранжирования,
страхования, калибровки, эксплуатации и мониторинга. У каждого — цель, раскрытие датасета,
этапы и проверенные выводы:

```bash
python examples/run_all.py --quick     # прогнать все примеры
python examples/3_medium/11_xgboost_complete.py
```

## Как устроен курс

- **Четыре части, 14 модулей.** Модуль (`lesson_4`) открывается обзором, его уроки
  (`lesson_4_1`, `lesson_4_2`, …) разбирают элементы темы. Внутри уроков блоки
  «Разбор по косточкам» продолжают разбиение рекурсивно.
- **Каждый урок — папка** `lessons/lesson_X_Y/`:

  | Папка | Содержимое |
  |---|---|
  | `web/` | интерактивная страница: теория, формулы, виджеты, Python в браузере, тест |
  | `jupyter_notebooks/` | ноутбук с кодом и графиками (и его исходник `.py` в формате percent) |
  | `examples/` | самостоятельные скрипты (`--save` сохраняет рисунки в `assets/figures`) |
  | `data/` | данные урока в CSV с описанием, как их воспроизвести |
  | `exercises/` | задания и запускаемые решения |
  | `assets/` | иллюстрации |

- **Учебная библиотека `gbcourse`** (`shared/python/gbcourse`) — прозрачные реализации
  дерева CART, градиентного бустинга (Фридман и Ньютон/XGBoost), функций потерь, бэггинга,
  AdaBoost, значений Шепли. Совпадает с scikit-learn и shap до ~1e-15 и работает в браузере.
- **Веб-движок** (`shared/web/js`) — зеркало `gbcourse` на JavaScript: одинаковые данные и
  модели по одному `seed` (проверяется тестом паритета).
