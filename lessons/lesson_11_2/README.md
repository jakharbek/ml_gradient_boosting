# Урок 11.2. Кросс-валидация и поиск параметров: сетка, случайный поиск, Optuna

> Как оценивать вариант, чтобы не обмануться случайностью разбиения, и как искать лучшие параметры за разумное число запусков

**Модуль:** [11. Настройка гиперпараметров](../lesson_11/README.md) · **Уровень:** Экспертный · **Время:** ~45 мин

**Нужно знать:** [11.1 Карта гиперпараметров и стратегия настройки](../lesson_11_1/README.md)

Разброс оценки по одному разбиению и кросс-валидация; вложенная CV для честной итоговой оценки. Перебор по сетке против случайного поиска на реальной поверхности ошибки LightGBM (случайный поиск выигрывает при любом бюджете, когда важны не все параметры). Байесовский поиск TPE в Optuna и отсечение неудачных запусков.

## После урока вы сможете

- оценивать модель кросс-валидацией и понимать, когда нужна вложенная CV
- объяснить, почему случайный поиск эффективнее сетки
- настраивать бустинг с Optuna (TPE, ранняя остановка, отсечение)
