Зачем это нужно

Данные в машинном обучении — это таблицы чисел. Строка таблицы — объект (квартира, клиент, письмо), столбец — признак (площадь, возраст, число слов). Линейная алгебра (linear algebra) — язык, на котором о таких таблицах говорят как о геометрических объектах: строки и столбцы становятся векторами — стрелками в пространстве, таблица целиком — матрицей, а обучение модели — поиском ближайшей точки, поворотом, растяжением и проекцией.

Для бустинга линейная алгебра важна не меньше, чем производные. Прогнозы модели на всех объектах — один вектор, остатки и градиент — тоже векторы, и каждое дерево бустинга проецирует вектор антиградиента на «ступеньки» своих листьев. Из этой одной картинки получаются формулы, которые в других уроках вводились по отдельности: значение листа — среднее, выигрыш разбиения $\sum G_j^2/n_j$, λ в знаменателе $-G/(H + \lambda)$, правило «меньше темп — больше деревьев». А ещё линейная алгебра объясняет, почему линейной регрессии и нейросетям нужна стандартизация признаков, а деревьям — нет, что такое мультиколлинеарность, PCA и регуляризация.

  2. Матрицы (шаги 9–15): матрица как таблица данных и умножение на вектор, матрица как преобразование плоскости, произведение матриц, определитель, обратная матрица, системы уравнений и метод Гаусса, ранг и обусловленность.
  3. Ортогональность и метод наименьших квадратов (шаги 16–20): ортонормированные базисы и процесс Грама — Шмидта, проекция на плоскость в трёхмерном пространстве, метод наименьших квадратов, полиномиальные признаки и переобучение, гребневая регрессия.

Интуиция: три квартиры — одна точка в пространстве

Возьмём три квартиры с ценами 2, 4 и 3 млн. Обычно мы рисуем их тремя точками на плоскости «площадь — цена». Линейная алгебра предлагает другой взгляд: все три цены — одна точка $y = (2, 4, 3)$ в трёхмерном пространстве, где ось $k$ — цена $k$-й квартиры. Любой набор прогнозов $F = (F_1, F_2, F_3)$ — тоже точка, а ошибка модели — расстояние между двумя точками.

Покрутите сцену мышью и поищите лучшую константу. Константные прогнозы $F = (c, c, c)$ лежат на одной прямой — она проходит через начало координат и точку $\mathbf 1 = (1, 1, 1)$. Ближайшая к $y$ точка этой прямой получается при $c = 3$ — это среднее цен, и отрезок от неё до $y$ перпендикулярен прямой. Прогнозы прямых $b + kx$ (площади 1, 2, 3) заполняют уже целую плоскость; ближайшая к $y$ точка плоскости — $(2.5, 3, 3.5)$, и снова отрезок-остаток перпендикулярен плоскости.

  • Обучение модели = поиск ближайшей точки среди всех прогнозов, которые модель умеет давать.
  • Ближайшая точка = основание перпендикуляра, то есть ортогональная проекция. Отсюда метод наименьших квадратов (шаг 18), среднее как лучшая константа (шаг 6) и значения листьев дерева (шаг 29).
  • Чтобы этим пользоваться, нужно уметь считать длины, углы и перпендикуляры в пространстве любой размерности — с шести квартирами пространство уже шестимерное, а нарисовать его нельзя. Этому и посвящён урок.

Шаг 1. Вектор — стрелка и список чисел

У вектора два лица. Геометрически это стрелка: у неё есть направление и длина, а где она нарисована — неважно (две стрелки одной длины и направления — один и тот же вектор). Алгебраически это упорядоченный список чисел — координат: стрелка из начала координат в точку $(3, 1)$ — вектор $a = (3, 1)$.

Вектор размерности $n$ — упорядоченный набор $n$ чисел $a = (a_1, a_2, \dots, a_n)$. Все такие векторы образуют пространство $\mathbb R^n$. Векторы равны, если равны все их координаты. Нулевой вектор $0 = (0, \dots, 0)$ — стрелка нулевой длины.

С векторами делают две операции — обе покоординатно:

$$a + b = (a_1 + b_1,\; \dots,\; a_n + b_n), \qquad c\,a = (c\,a_1,\; \dots,\; c\,a_n)$$
$a + b$
сумма: пройти по стрелке $a$, затем от её конца — по стрелке $b$ (правило треугольника); то же, что диагональ параллелограмма
$c\,a$
умножение на число: растянуть стрелку в $|c|$ раз; при $c < 0$ — ещё и развернуть
$a - b$
разность $a + (-1)b$: стрелка, ведущая из конца $b$ в конец $a$

Свойства операций те же, что у чисел: $a + b = b + a$, $(a + b) + c = a + (b + c)$, $c(a + b) = ca + cb$, $a + 0 = a$. Поэтому с векторами можно считать как с обычными выражениями, только каждое число — целый столбик.

В машинном обучении векторы повсюду, и важно различать их размерности:

Пример 1 ★. Сложение и умножение

$a = (3, 1)$, $b = (1, 2)$. Сумма $a + b = (4, 3)$, разность $a - b = (2, -1)$, $2a - b = (6 - 1, 2 - 2) = (5, 0)$. Проверьте на виджете: стрелка $a - b$ идёт из конца $b$ в конец $a$.

Пример 2 ★. Середина отрезка и среднее объектов

Середина между точками $a$ и $b$ — $\frac{a + b}{2} = (2, 1.5)$. Так же считается «средний объект» выборки — центр масс: $\bar x = \frac1n(x_1 + \dots + x_n)$. Для квартир с признаками (площадь, этаж) $(50, 3)$, $(70, 9)$, $(60, 6)$ средний объект — $(60, 6)$.

Пример 3 ★★. Остатки шести квартир

Цены шести квартир курса (площади 1…6 в десятках м²) — $y = (2, 4, 3, 7, 9, 11)$. Стартовый прогноз бустинга — константа 6, вектор прогнозов $F_0 = 6 \cdot \mathbf 1 = (6, 6, 6, 6, 6, 6)$. Остатки $r = y - F_0 = (-4, -2, -3, 1, 3, 5)$ — один вектор в $\mathbb R^6$. Нарисовать шестимерную стрелку нельзя, но считать с ней можно так же, как с плоской.

Пример 4 ★★★. Шаг бустинга — сложение векторов

Шаг бустинга $F_m = F_{m-1} + \nu h_m$ (урок ) — это сложение векторов в $\mathbb R^n$: к точке-прогнозу прибавляется стрелка $\nu h_m$, где $h_m$ — прогнозы нового дерева на всех объектах. Первое дерево для квартир даёт $h_1 = (-3, -3, -3, 3, 3, 3)$; при $\nu = 0.5$ новая точка $F_1 = (4.5, 4.5, 4.5, 7.5, 7.5, 7.5)$. Вся модель бустинга — путь из точки $F_0$ стрелками деревьев к точке $y$.

Шаг 2. Линейные комбинации и оболочка

Из двух операций складывается главная конструкция линейной алгебры:

Линейная комбинация векторов $u, v$ с коэффициентами $\alpha, \beta$ — вектор $\alpha u + \beta v$. Множество всех линейных комбинаций называется линейной оболочкой (span): $\operatorname{span}(u, v) = \{\alpha u + \beta v\}$.

Представьте два «шага» $u$ и $v$, которые можно делать любое число раз (в том числе дробное и отрицательное). Линейная оболочка — все места, куда можно так дойти. Если $u$ и $v$ не лежат на одной прямой, на плоскости можно дойти куда угодно; если лежат — только по этой прямой.

Пример 1 ★. Дойти до точки

$u = (1, 1)$, $v = (1, -1)$, цель $(3, 1)$. Ищем $\alpha u + \beta v = (\alpha + \beta,\; \alpha - \beta) = (3, 1)$: $\alpha + \beta = 3$, $\alpha - \beta = 1$, откуда $\alpha = 2$, $\beta = 1$. Проверка: $2(1, 1) + (1, -1) = (3, 1)$.

Пример 2 ★★. Когда дойти нельзя

$u = (1, 2)$, $v = (2, 4) = 2u$. Любая комбинация $\alpha u + \beta v = (\alpha + 2\beta)u$ лежит на прямой $x_2 = 2x_1$. До точки $(3, 1)$ не дойти, а до $(1, 2)$ — бесконечно многими способами: $\alpha + 2\beta = 1$.

Пример 3 ★★. Два вектора в пространстве

В $\mathbb R^3$ оболочка двух непараллельных векторов — плоскость через начало координат. В интуиции урока это была плоскость прогнозов: $b\,\mathbf 1 + k\,x = b(1, 1, 1) + k(1, 2, 3)$. Точка $y = (2, 4, 3)$ на этой плоскости не лежит — поэтому прямая не проходит через все три квартиры точно.

Пример 4 ★★★. Все прогнозы линейной модели — оболочка столбцов

Прогнозы линейной модели $\hat y = w_1 x^{(1)} + \dots + w_p x^{(p)}$, где $x^{(j)}$ — столбец $j$-го признака (значения признака на всех объектах), — это линейная комбинация столбцов. Значит, всё, что модель умеет предсказать, — оболочка столбцов матрицы признаков. Её называют пространством столбцов; к нему мы вернёмся в шагах 9 и 17. У дерева с фиксированным разбиением «столбцы» другие — индикаторы листьев (шаг 29).

Шаг 3. Базис, линейная независимость и размерность

Сколько векторов нужно, чтобы дойти до любой точки, и когда векторов «слишком много»?

Векторы $v_1, \dots, v_k$ линейно независимы, если ни один из них не выражается через остальные; эквивалентно, равенство $\alpha_1 v_1 + \dots + \alpha_k v_k = 0$ возможно только при всех $\alpha_i = 0$. Иначе они линейно зависимы. Базис пространства — независимый набор, оболочка которого — всё пространство. Число векторов в любом базисе одинаково — это размерность: у $\mathbb R^n$ она равна $n$.

Если $b_1, b_2$ — базис плоскости, любую точку $p$ можно записать единственным способом: $p = \alpha b_1 + \beta b_2$. Числа $(\alpha, \beta)$ — координаты $p$ в базисе $b_1, b_2$. Привычные координаты — это координаты в стандартном базисе $e_1 = (1, 0)$, $e_2 = (0, 1)$. Другой базис — это другая, «косая» сетка на той же плоскости.

Пример 1 ★. Координаты в косом базисе

Базис $b_1 = (2, 1)$, $b_2 = (-1, 1)$, точка $p = (1, 2)$. Решаем $\alpha(2, 1) + \beta(-1, 1) = (1, 2)$: $2\alpha - \beta = 1$, $\alpha + \beta = 2$. Складывая, $3\alpha = 3$: $\alpha = 1$, $\beta = 1$. В косой сетке точка $(1, 2)$ имеет координаты $(1, 1)$.

Пример 2 ★★. Независимы ли векторы?

$(1, 2, 3)$ и $(2, 4, 6)$ зависимы: второй — удвоенный первый. А $(1, 0, 1)$, $(0, 1, 1)$, $(1, 1, 0)$ независимы: из $\alpha(1,0,1) + \beta(0,1,1) + \gamma(1,1,0) = 0$ следует $\alpha + \gamma = 0$, $\beta + \gamma = 0$, $\alpha + \beta = 0$, откуда $\alpha = \beta = \gamma = 0$. Значит, это базис $\mathbb R^3$. Больше трёх независимых векторов в $\mathbb R^3$ не бывает.

Пример 3 ★★★. Ловушка фиктивных переменных

Категориальный признак «район» с тремя значениями кодируют тремя столбцами-индикаторами $d_1, d_2, d_3$ (one-hot, урок ). Если в модели есть ещё и столбец из единиц (сдвиг), то $d_1 + d_2 + d_3 = \mathbf 1$ — столбцы зависимы. Линейная регрессия тогда не может однозначно выбрать веса: прибавьте ко всем весам районов 1, а из сдвига вычтите 1 — прогнозы не изменятся. Поэтому в линейных моделях один индикатор выбрасывают (drop_first) или используют регуляризацию (шаг 20). Деревьям зависимые столбцы не мешают: каждое разбиение смотрит на один признак.

Шаг 4. Скалярное произведение: длины, углы, перпендикулярность

Главная операция линейной алгебры — скалярное произведение (dot product): перемножить координаты попарно и сложить. Результат — число, а не вектор.

$$a \cdot b = a_1 b_1 + a_2 b_2 + \dots + a_n b_n = \sum_{i=1}^n a_i b_i$$

У этой простой формулы есть геометрический смысл. Длина вектора по теореме Пифагора — $\|a\| = \sqrt{a_1^2 + \dots + a_n^2} = \sqrt{a \cdot a}$, а скалярное произведение связано с углом $\alpha$ между векторами:

$$a \cdot b = \|a\|\,\|b\|\cos\alpha$$

Откуда косинус: шаг 1

Рассмотрим треугольник со сторонами $a$, $b$ и $a - b$. По определению и свойствам произведения: $\|a - b\|^2 = (a - b)\cdot(a - b) = a \cdot a - 2\,a \cdot b + b \cdot b = \|a\|^2 + \|b\|^2 - 2\,a\cdot b$.

Шаг 2

Теорема косинусов для того же треугольника: $\|a - b\|^2 = \|a\|^2 + \|b\|^2 - 2\|a\|\|b\|\cos\alpha$.

Шаг 3

Сравнивая, получаем $a \cdot b = \|a\|\|b\|\cos\alpha$. В пространствах любой размерности эту формулу берут как определение угла: $\cos\alpha = \frac{a \cdot b}{\|a\|\|b\|}$.

Знак скалярного произведения сразу говорит об угле: больше нуля — угол острый, векторы «смотрят в одну сторону»; меньше нуля — тупой; ноль — векторы ортогональны (перпендикулярны). Свойства: $a \cdot b = b \cdot a$; $(\alpha a + \beta b)\cdot c = \alpha\,a\cdot c + \beta\,b\cdot c$; $a \cdot a = \|a\|^2 \ge 0$. А поскольку $|\cos\alpha| \le 1$, выполняется неравенство Коши — Буняковского: $|a \cdot b| \le \|a\|\|b\|$, равенство — только для параллельных векторов.

Пример 1 ★. Посчитать

$(3, 4)\cdot(4, -1) = 12 - 4 = 8$. Длины $\|(3,4)\| = 5$, $\|(4,-1)\| = \sqrt{17} \approx 4.123$. $\cos\alpha = \frac{8}{5 \cdot 4.123} \approx 0.388$, угол $\approx 67.2°$ — острый.

Пример 2 ★. Перпендикулярность

$(1, 2)\cdot(-2, 1) = -2 + 2 = 0$ — векторы перпендикулярны. Вообще $(a_1, a_2) \perp (-a_2, a_1)$: так строят перпендикуляр на плоскости.

Пример 3 ★★. Угол в пространстве

$(1, 1, 0)\cdot(0, 1, 1) = 1$, длины $\sqrt2$ и $\sqrt2$, $\cos\alpha = \frac12$, угол $60°$. Нарисовать не нужно — формула работает в любой размерности.

Пример 4 ★★. Прогноз линейной модели

Прогноз линейной модели — скалярное произведение весов на признаки: $\hat y = w \cdot x$. Квартира $x = (1, 5, 3)$ — (сдвиг, площадь в десятках м², этаж), веса $w = (0.5, 1.8, 0.1)$: $\hat y = 0.5 + 9 + 0.3 = 9.8$ млн.

Пример 5 ★★★. Почему градиент — направление наискорейшего роста

Скорость роста функции вдоль единичного направления $u$ — $\nabla f \cdot u$ (урок ). По Коши — Буняковскому $\nabla f \cdot u \le \|\nabla f\|\,\|u\| = \|\nabla f\|$, и равенство — только при $u$, параллельном $\nabla f$. Значит, быстрее всего функция растёт вдоль градиента, а убывает — против него. Вся идея градиентного спуска — одно неравенство о скалярном произведении.

Из скалярного произведения получаются три величины, которыми пользуются постоянно:

  • Длина $\|a\| = \sqrt{a\cdot a}$ и единичный вектор $\frac{a}{\|a\|}$ — то же направление, длина 1 (нормировка).
  • Расстояние между точками $a$ и $b$ — длина разности: $d(a, b) = \|a - b\| = \sqrt{\sum (a_i - b_i)^2}$ (евклидово расстояние).
  • Косинусное сходство $\cos\alpha = \frac{a\cdot b}{\|a\|\|b\|}$ — похожесть направлений без учёта длин: от $-1$ до $1$.

У расстояния есть ловушка: оно складывает квадраты разностей разных признаков, измеренных в разных единицах. Признак с большими числами (площадь в м²) перевешивает признак с маленькими (расстояние в км) — просто из-за выбора единиц. Метод ближайших соседей, кластеризация, SVM и нейросети это чувствуют, поэтому признаки стандартизуют: $z = \frac{x - \bar x}{s}$ (среднее 0, стандартное отклонение 1). Деревьям масштаб безразличен: разбиение «площадь ≤ 56» не изменится, если перевести метры в сантиметры (урок ).

Пример 1 ★. Длина и нормировка

$\|(6, 8)\| = \sqrt{36 + 64} = 10$; единичный вектор того же направления — $(0.6, 0.8)$. Расстояние между точками $(1, 2)$ и $(4, 6)$: $\|(3, 4)\| = 5$.

Пример 2 ★★. Косинусное сходство текстов

Тексты описывают векторами частот слов («цена», «метро», «ремонт»): $(2, 1, 0)$ и $(4, 2, 0)$ — второй текст вдвое длиннее, но о том же: косинус 1. Тексты $(2, 1, 0)$ и $(0, 1, 3)$: $\cos = \frac{1}{\sqrt5\sqrt{10}} \approx 0.14$ — почти о разном. Евклидово расстояние здесь обманывает: оно назвало бы короткий и длинный тексты на одну тему «далёкими».

Пример 3 ★★★. Сосед зависит от единиц измерения

Восемь квартир урока , ищем ближайшую к квартире 58 м² в 4 км от центра. В единицах (м², км) ближайшая — №5: 62 м², но 10 км от центра (расстояние 7.21 против 8.00 у №4 — разница в площади весит больше). Если расстояние до центра записать в метрах, всё решает только оно, и ближайшая — №4 (50 м², 4 км), а следующая отстоит уже на 1000 «единиц». После стандартизации (стандартные отклонения 20.0 м² и 3.57 км) ближайшая — тоже №4, а вторая — №6: признаки наконец весят сопоставимо. Прогноз «по соседу» меняется с 7.0 до 5.8 млн из-за одного выбора единиц.

Шаг 6. Проекция на вектор — и почему лучшая константа равна среднему

Тень вектора $b$ на прямую, идущую вдоль вектора $a$, — ортогональная проекция. Это ближайшая к $b$ точка прямой: от неё до $b$ ведёт перпендикуляр.

$$\operatorname{proj}_a b = \frac{a \cdot b}{a \cdot a}\, a, \qquad e = b - \operatorname{proj}_a b \;\perp\; a$$

Вывод, шаг 1. Что ищем

Точки прямой — это $t\,a$. Ищем $t$, при котором расстояние $\|b - t\,a\|$ минимально; удобнее минимизировать квадрат.

Шаг 2. Квадрат расстояния — парабола по $t$

$\|b - t a\|^2 = b\cdot b - 2t\,a\cdot b + t^2\,a\cdot a$. Это квадратный трёхчлен с положительным старшим коэффициентом.

Шаг 3. Вершина параболы

Производная по $t$: $-2\,a\cdot b + 2t\,a\cdot a = 0$, откуда $t^* = \frac{a\cdot b}{a\cdot a}$.

Шаг 4. Остаток перпендикулярен

$a \cdot (b - t^* a) = a\cdot b - t^*\,a\cdot a = 0$. Условие минимума и условие перпендикулярности — одно и то же. Это главная мысль урока: ближайшая точка — там, где остаток ортогонален.

Отсюда теорема Пифагора для разложения: $\|b\|^2 = \|\operatorname{proj}_a b\|^2 + \|e\|^2$.

А теперь возьмём в роли $a$ вектор из единиц $\mathbf 1 = (1, \dots, 1)$, а в роли $b$ — вектор ответов $y$. Прямая $t\,\mathbf 1$ — это все константные прогнозы. Проекция:

$$\operatorname{proj}_{\mathbf 1}\, y = \frac{\mathbf 1 \cdot y}{\mathbf 1 \cdot \mathbf 1}\,\mathbf 1 = \frac{y_1 + \dots + y_n}{n}\,\mathbf 1 = \bar y\,\mathbf 1$$

Лучшая константа по сумме квадратов — среднее: это проекция вектора ответов на прямую констант. Условие перпендикулярности $\mathbf 1 \cdot (y - \bar y\mathbf 1) = 0$ читается как «сумма остатков равна нулю». Именно так выбирается стартовое значение $F_0$ бустинга с квадратичными потерями (урок ).

Пример 1 ★. Проекция на ось

$b = (2, 3)$, $a = (1, 0)$: $t^* = \frac{2}{1} = 2$, проекция $(2, 0)$, остаток $(0, 3)$ — перпендикулярен оси. Проекция на ось — это просто «оставить одну координату».

Пример 2 ★★. Проекция на диагональ

$b = (2, 3)$, $a = (1, 1)$: $t^* = \frac{5}{2}$, проекция $(2.5, 2.5)$, остаток $(-0.5, 0.5)$, и $(-0.5, 0.5)\cdot(1, 1) = 0$. Заметьте: $2.5$ — среднее чисел 2 и 3. Проекция на диагональ — это и есть усреднение.

Пример 3 ★★. Шесть квартир и Пифагор

$y = (2, 4, 3, 7, 9, 11)$: $\bar y = 36/6 = 6$, остаток $r = (-4, -2, -3, 1, 3, 5)$, сумма остатков 0. Пифагор: $\|y\|^2 = 280$, $\|\bar y\mathbf 1\|^2 = 6 \cdot 36 = 216$, $\|r\|^2 = 64$, и действительно $280 = 216 + 64$. В статистике это разложение «сумма квадратов = объяснённая константой + разброс вокруг среднего».

Пример 4 ★★★. Проекция с весами

Если объектам приписаны веса $h_i > 0$ (важность, число повторов), длину измеряют как $\sum h_i v_i^2$, а скалярное произведение — как $\sum h_i a_i b_i$. Та же формула даёт проекцию на $\mathbf 1$: $\frac{\sum h_i y_i}{\sum h_i}$ — взвешенное среднее. Ровно так устроен лист XGBoost: веса — вторые производные потерь (шаг 32).

Шаг 7. Нормы: какой длины вектор ошибок

«Длину» вектора можно измерять по-разному. Любая функция $\|v\|$ со свойствами длины называется нормой (norm): $\|v\| \ge 0$ и $\|v\| = 0$ только для $v = 0$; $\|c\,v\| = |c|\,\|v\|$; неравенство треугольника $\|a + b\| \le \|a\| + \|b\|$. Три главные нормы:

$$\|v\|_2 = \sqrt{\textstyle\sum v_i^2}, \qquad \|v\|_1 = \textstyle\sum |v_i|, \qquad \|v\|_\infty = \max_i |v_i|, \qquad \|v\|_p = \Bigl(\textstyle\sum |v_i|^p\Bigr)^{1/p}$$
$\|v\|_2$
евклидова норма (L2) — обычная длина; «единичный шар» — круг
$\|v\|_1$
манхэттенская норма (L1) — путь по клеткам города; единичный шар — ромб
$\|v\|_\infty$
максимум модуля (L∞) — худшая координата; единичный шар — квадрат

Нормы вектора остатков — это функции потерь: $\text{MSE} = \|r\|_2^2/n$, $\text{RMSE} = \|r\|_2/\sqrt n$, $\text{MAE} = \|r\|_1/n$, максимальная ошибка — $\|r\|_\infty$. Какая норма — такая и «лучшая константа»: для L2 — среднее (шаг 6), для L1 — медиана, для L∞ — середина размаха (урок ). Нормы весов — это регуляризация: гребневая регрессия штрафует $\lambda\|w\|_2^2$, лассо — $\alpha\|w\|_1$; в XGBoost это параметры reg_lambda и reg_alpha для значений листьев (урок ).

Виджет показывает, почему L1-штраф обнуляет веса. Минимизировать потери при ограничении $\|w\| \le t$ — значит раздувать линии уровня потерь (эллипсы) из точки минимума, пока они не коснутся шара нормы. У круга (L2) касание почти всегда происходит в «гладкой» точке, где обе координаты ненулевые. У ромба (L1) острые углы торчат на осях, и эллипс часто касается именно угла — там одна из координат равна нулю. Отсюда разреженность лассо: часть признаков выключается совсем.

Пример 1 ★. Три нормы остатков

$r = (-4, -2, -3, 1, 3, 5)$: $\|r\|_2 = \sqrt{16 + 4 + 9 + 1 + 9 + 25} = \sqrt{64} = 8$, $\|r\|_1 = 18$, $\|r\|_\infty = 5$. Всегда $\|r\|_\infty \le \|r\|_2 \le \|r\|_1$: $5 \le 8 \le 18$.

Пример 2 ★. Потери через нормы

$\text{MSE} = 64/6 \approx 10.67$, $\text{RMSE} = 8/\sqrt6 \approx 3.27$, $\text{MAE} = 18/6 = 3$.

Пример 3 ★★. Чувствительность к выбросу

Пусть цена последней квартиры записана с ошибкой: 21 вместо 11. Лучшая константа по L2 — среднее — сдвинется с 6 до 7.67, а по L1 — медиана — останется 5.5 (средние значения отсортированного ряда 4 и 7 не изменились). Квадраты «раздувают» большие остатки, модули — нет. Поэтому для данных с выбросами берут потери L1 или Хьюбера (урок ).

Пример 4 ★★★. Почему L2 не обнуляет

Одномерная задача: минимизировать $\frac12(w - a)^2 + \lambda\frac{w^2}{2}$ даёт $w = \frac{a}{1 + \lambda}$ — вес уменьшается, но в ноль не обращается ни при каком $\lambda$. С L1-штрафом $\frac12(w - a)^2 + \alpha|w|$ ответ $w = \operatorname{sign}(a)\max(|a| - \alpha, 0)$ — «мягкий порог»: при $|a| \le \alpha$ вес ровно ноль. Первую формулу вы узнаете в листе XGBoost $-\frac{G}{H + \lambda}$, вторую — в его reg_alpha.

Шаг 8. Прямые, плоскости, гиперплоскости — и разбиения деревьев

Скалярное произведение задаёт самые простые «границы» в пространстве признаков. Множество точек

$$\{x : w \cdot x = b\}$$

на плоскости — прямая, в трёхмерном пространстве — плоскость, в $\mathbb R^n$ — гиперплоскость (размерности $n - 1$). Вектор $w$ — её нормаль: он перпендикулярен гиперплоскости (если $w\cdot x_1 = w\cdot x_2 = b$, то $w \cdot (x_1 - x_2) = 0$). Гиперплоскость делит пространство на два полупространства: $w\cdot x > b$ (куда смотрит нормаль) и $w \cdot x < b$. Знаковое расстояние от точки до гиперплоскости:

$$d(x) = \frac{w\cdot x - b}{\|w\|}$$

Так работают линейные классификаторы: логистическая регрессия считает $w\cdot x - b$ и пропускает через сигмоиду (урок ). А разбиение дерева «$x_j \le t$» — тоже гиперплоскость, но особая: её нормаль — базисный вектор $e_j$. Дерево умеет резать пространство только перпендикулярно осям.

Пример 1 ★. Прямая и её нормаль

Прямая $2x_1 + x_2 = 4$: нормаль $w = (2, 1)$, $b = 4$. Точки $(2, 0)$ и $(0, 4)$ на прямой; их разность $(2, -4)$ перпендикулярна $w$: $4 - 4 = 0$.

Пример 2 ★★. Расстояние до прямой

От точки $(3, 3)$ до той же прямой: $d = \frac{2\cdot3 + 3 - 4}{\sqrt{4 + 1}} = \frac{5}{\sqrt5} = \sqrt5 \approx 2.24$. Знак плюс — точка с той стороны, куда смотрит нормаль.

Пример 3 ★★. Разбиение дерева как гиперплоскость

Корень дерева урока — «площадь ≤ 56» в пространстве (площадь, расстояние до центра). Это прямая с нормалью $w = (1, 0)$ и $b = 56$: вертикальная линия на плоскости признаков.

Пример 4 ★★★. Косая граница и лестница

Если классы разделяет косая линия $x_2 = x_1$, линейной модели хватает одной гиперплоскости, а дереву — нет: оно строит лестницу из вертикальных и горизонтальных отрезков, и чем точнее нужно, тем больше ступенек (разбиений). Бустинг складывает много неглубоких деревьев и поэтому аппроксимирует такие границы, но платит числом деревьев. Иногда помогает добавить признак $x_2 - x_1$ — тогда граница становится «осевой». Поверните нормаль на виджете и посчитайте, сколько ступенек нужно лестнице.

Шаг 9. Матрица — таблица данных; умножение матрицы на вектор

Матрица размера $n \times p$ — прямоугольная таблица чисел из $n$ строк и $p$ столбцов. Матрица признаков $X$: строки — объекты, столбцы — признаки, $X_{ij}$ — значение признака $j$ у объекта $i$. Транспонирование $X^\top$ меняет строки и столбцы местами: $(X^\top)_{ij} = X_{ji}$, размер становится $p \times n$.

Линейная модель предсказывает сразу все объекты одним умножением матрицы на вектор:

$$\hat y = X w, \qquad \hat y_i = \sum_{j=1}^p X_{ij}\, w_j$$

У этого умножения два равноправных прочтения — и оба нужно уметь «видеть»:

  • По строкам: $i$-я координата результата — скалярное произведение $i$-й строки на $w$. Каждый прогноз — «признаки объекта, умноженные на веса».
  • По столбцам: результат — линейная комбинация столбцов с коэффициентами $w_j$: $Xw = w_1 X^{(1)} + \dots + w_p X^{(p)}$. Это прогнозы как точка пространства столбцов (шаг 2).

Размеры должны согласовываться: $(n \times p)$ на вектор длины $p$ даёт вектор длины $n$. Для квартир с колонкой единиц (сдвиг) $X = \begin{pmatrix} 1 & 1 \\ 1 & 2 \\ \vdots & \vdots \\ 1 & 6 \end{pmatrix}$ — размер $6 \times 2$, $w = (b, k)$, и $Xw$ — прогнозы прямой $b + kx$ на всех шести квартирах.

Пример 1 ★. По строкам

$\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}\begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 + 2 \\ 3 + 4 \end{pmatrix} = \begin{pmatrix} 3 \\ 7 \end{pmatrix}$.

Пример 2 ★. По столбцам

То же самое: $1\cdot\begin{pmatrix} 1 \\ 3 \end{pmatrix} + 1\cdot\begin{pmatrix} 2 \\ 4 \end{pmatrix} = \begin{pmatrix} 3 \\ 7 \end{pmatrix}$. Чтобы получить первый столбец матрицы, умножьте её на $e_1 = (1, 0)$.

Пример 3 ★★. Прогнозы шести квартир

При $w = (-0.4, 1.83)$: $Xw = (1.43, 3.26, 5.09, 6.92, 8.75, 10.58)$ — прогнозы прямой $-0.4 + 1.83x$. По столбцам: $-0.4\cdot\mathbf 1 + 1.83\cdot(1, 2, \dots, 6)$.

Пример 4 ★★★. $X^\top r$ — «признаки, умноженные на остатки»

Транспонированная матрица умножается на вектор длины $n$ и даёт вектор длины $p$: $(X^\top r)_j = X^{(j)}\cdot r$ — скалярное произведение столбца признака на остатки. Это (с множителем $-2$) градиент суммы квадратов по весам (урок ): вес меняется сильнее всего там, где признак сильнее всего «совпадает» с остатками. Для квартир при $w = (0, 1)$: $r = y - x = (1, 2, 0, 3, 4, 5)$, $X^\top r = (15, 67)$ — оба веса нужно увеличивать.

Шаг 10. Матрица — преобразование пространства

Матрица $2 \times 2$ умеет двигать точки плоскости: $\begin{pmatrix} a & b \\ c & d \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} ax + by \\ cx + dy \end{pmatrix}$. Такие преобразования называются линейными: они сохраняют сложение и умножение на число, $A(\alpha u + \beta v) = \alpha Au + \beta Av$. Геометрически: прямые остаются прямыми, параллельные — параллельными, начало координат — на месте, а сетка из квадратов превращается в сетку из одинаковых параллелограммов.

Главное правило: столбцы матрицы — это образы базисных векторов: $Ae_1 = (a, c)$, $Ae_2 = (b, d)$. Любой вектор $(x, y) = x e_1 + y e_2$ переходит в $x\,Ae_1 + y\,Ae_2$. Знаете, куда уходят $e_1$ и $e_2$, — знаете всё преобразование.

Пример 1 ★. Поворот на 90°

$e_1 = (1, 0)$ должен перейти в $(0, 1)$, а $e_2 = (0, 1)$ — в $(-1, 0)$. Ставим образы столбцами: $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$. Проверка: $(3, 1) \mapsto (-1, 3)$ — повёрнут на 90° против часовой стрелки.

Пример 2 ★★. Матрица по описанию

Нужна матрица, которая переводит $e_1$ в $(1, 1)$, а $e_2$ — в $(-1, 1)$. Ответ сразу: $\begin{pmatrix} 1 & -1 \\ 1 & 1 \end{pmatrix}$. Это поворот на 45° с растяжением в $\sqrt 2$ раз: длины столбцов $\sqrt2$, угол между ними 90°.

Пример 3 ★★. Что видит матрица данных

Матрица $X$ размера $n \times p$ — тоже преобразование: она переводит вектор весов из $\mathbb R^p$ в вектор прогнозов из $\mathbb R^n$. Образ всего $\mathbb R^p$ — пространство столбцов, «плоскость» внутри $\mathbb R^n$. При $p < n$ эта плоскость тоньше всего пространства, поэтому почти никакой вектор ответов $y$ в неё не попадает — точно подогнать модель нельзя, можно только приблизить (шаг 18).

Пример 4 ★★★. Проекция теряет информацию

Проекция на ось $x$ переводит $(3, 1)$ и $(3, -5)$ в одну и ту же точку $(3, 0)$. По результату нельзя восстановить исходную точку — у такого преобразования нет обратного (шаг 13). Признак этого — нулевой определитель (шаг 12).

Шаг 11. Произведение матриц — это композиция преобразований

Сделаем сначала преобразование $B$, потом $A$: $v \mapsto A(Bv)$. Это тоже линейное преобразование, и его матрица называется произведением $AB$. Раз столбцы — образы базисных векторов, $j$-й столбец $AB$ равен матрице $A$, умноженной на $j$-й столбец $B$. Покоординатно:

$$(AB)_{ij} = \sum_k A_{ik}B_{kj} = (\text{строка } i \text{ матрицы } A)\cdot(\text{столбец } j \text{ матрицы } B)$$
  • Размеры: $(n \times k)\cdot(k \times m) = n \times m$ — «внутренние» размеры должны совпасть.
  • Порядок важен: обычно $AB \ne BA$. Сначала повернуть, потом растянуть — не то же самое, что наоборот.
  • Скобки не важны: $(AB)C = A(BC)$ — поэтому пишут просто $ABC$.
  • Единичная матрица $I$ (единицы на диагонали) ничего не меняет: $AI = IA = A$.
  • $(AB)^\top = B^\top A^\top$ — при транспонировании порядок разворачивается.

Пример 1 ★. Посчитать произведение

$A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$, $B = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$. $AB = \begin{pmatrix} 2 & 1 \\ 4 & 3 \end{pmatrix}$ — столбцы $A$ поменялись местами; $BA = \begin{pmatrix} 3 & 4 \\ 1 & 2 \end{pmatrix}$ — поменялись строки. $AB \ne BA$.

Пример 2 ★★. Поворот и отражение

Поворот на 90° $R = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ и отражение $S = \begin{pmatrix} -1 & 0 \\ 0 & 1 \end{pmatrix}$. $SR = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ (зеркало относительно диагонали $y = x$), $RS = \begin{pmatrix} 0 & -1 \\ -1 & 0 \end{pmatrix}$ (зеркало относительно $y = -x$). Домик на виджете это показывает.

Пример 3 ★★. Пакетные прогнозы

Если у нас $m$ разных линейных моделей, их веса ставят столбцами в матрицу $W$ размера $p \times m$. Тогда $XW$ ($n \times m$) — прогнозы всех моделей на всех объектах одной операцией. Так устроены слои нейросетей и быстрые вычисления на видеокартах.

Пример 4 ★★★. Формулы тригонометрии из умножения

Поворот на $\alpha$, затем на $\beta$ — это поворот на $\alpha + \beta$: $R_\beta R_\alpha = R_{\alpha+\beta}$. Перемножив матрицы, в левом верхнем углу получим $\cos\beta\cos\alpha - \sin\beta\sin\alpha$, а должно быть $\cos(\alpha + \beta)$. Формула косинуса суммы — следствие умножения матриц.

Шаг 12. Определитель: во сколько раз меняется площадь

Единичный квадрат со сторонами $e_1, e_2$ матрица переводит в параллелограмм, натянутый на её столбцы. Определитель (determinant) — его площадь со знаком:

$$\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$$
  • $|\det A|$ — во сколько раз преобразование меняет любые площади (все квадратики сетки меняются одинаково).
  • Знак: $\det > 0$ — ориентация сохраняется, $\det < 0$ — плоскость «перевёрнута», как в зеркале.
  • $\det = 0$ — параллелограмм сплющен в отрезок: столбцы зависимы, плоскость схлопнулась в прямую или точку.

В трёх измерениях определитель — объём параллелепипеда со знаком. Для матрицы $3 \times 3$ его считают разложением по первой строке:

$$\det\begin{pmatrix} a_1 & a_2 & a_3 \\ b_1 & b_2 & b_3 \\ c_1 & c_2 & c_3 \end{pmatrix} = a_1(b_2c_3 - b_3c_2) - a_2(b_1c_3 - b_3c_1) + a_3(b_1c_2 - b_2c_1)$$

Свойства, которые пригодятся: $\det(AB) = \det A \cdot \det B$ (масштабы площадей перемножаются); $\det A^\top = \det A$; перестановка двух столбцов меняет знак; $\det I = 1$; $\det(cA) = c^n\det A$ для матрицы $n \times n$.

Пример 1 ★. Площадь параллелограмма

$\det\begin{pmatrix} 3 & 1 \\ 2 & 4 \end{pmatrix} = 12 - 2 = 10$: параллелограмм на векторах $(3, 2)$ и $(1, 4)$ имеет площадь 10, и любая фигура увеличивается в 10 раз.

Пример 2 ★. Повороты и отражения

Поворот: $\cos^2\varphi + \sin^2\varphi = 1$ — площади не меняются. Отражение $\begin{pmatrix} -1 & 0 \\ 0 & 1 \end{pmatrix}$: $\det = -1$ — площадь та же, ориентация обратная. Сдвиг $\begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$: $\det = 1$ — квадрат перекосился, но площадь сохранилась.

Пример 3 ★★. Определитель 3 × 3

$\det\begin{pmatrix} 2 & 1 & 0 \\ 1 & 3 & 1 \\ 0 & 1 & 2 \end{pmatrix} = 2(6 - 1) - 1(2 - 0) + 0 = 8$.

Пример 4 ★★★. Зависимые признаки

Площадь в м² и в квадратных футах: второй столбец — первый, умноженный на 10.764. Для $X$ из двух таких столбцов $\det(X^\top X) = 0$: в $X^\top X$ второй столбец тоже пропорционален первому. Именно эту матрицу нужно обращать в методе наименьших квадратов (шаг 18) — и обратить её нельзя.

Шаг 13. Обратная матрица: отменить преобразование

Если преобразование ничего не сплющивает ($\det A \ne 0$), его можно отменить. Матрица отмены — обратная $A^{-1}$: $A^{-1}A = AA^{-1} = I$. Для матрицы $2 \times 2$:

$$\begin{pmatrix} a & b \\ c & d \end{pmatrix}^{-1} = \frac{1}{ad - bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$$

Рецепт: поменять местами числа на главной диагонали, сменить знаки на побочной и разделить на определитель. Видно, почему при $\det = 0$ обратной нет — делить не на что, — а при маленьком $\det$ элементы $A^{-1}$ огромны: почти сплющенную плоскость приходится сильно «раздувать» обратно.

  • $(AB)^{-1} = B^{-1}A^{-1}$ — «сначала снимаем ботинки, потом носки»: отменяем в обратном порядке.
  • $(A^\top)^{-1} = (A^{-1})^\top$; $\det A^{-1} = 1/\det A$.
  • На практике систему $Aw = c$ не решают через $A^{-1}c$: это медленнее и менее точно, чем метод Гаусса (np.linalg.solve).

Пример 1 ★. Обратная 2 × 2

$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$, $\det A = 3$, $A^{-1} = \frac13\begin{pmatrix} 2 & -1 \\ -1 & 2 \end{pmatrix}$. Проверка: первая строка $A$ на первый столбец $A^{-1}$: $\frac13(4 - 1) = 1$; на второй: $\frac13(-2 + 2) = 0$.

Пример 2 ★. Обратные без вычислений

Растяжение $\operatorname{diag}(2, 0.5)$ отменяет $\operatorname{diag}(0.5, 2)$. Поворот на $\varphi$ отменяет поворот на $-\varphi$, и это просто транспонированная матрица: $R^{-1} = R^\top$. Отражение отменяет само себя.

Пример 3 ★★. Решить систему

$2u + v = 3$, $u + 2v = 3$: $(u, v) = A^{-1}(3, 3) = \frac13(6 - 3,\; -3 + 6) = (1, 1)$.

Пример 4 ★★★. Почти вырожденная матрица

$A = \begin{pmatrix} 1 & 1 \\ 1 & 1.001 \end{pmatrix}$: $\det = 0.001$, $A^{-1} = \begin{pmatrix} 1001 & -1000 \\ -1000 & 1000 \end{pmatrix}$. Маленькие ошибки во входе умножатся на тысячу — подробнее в шаге 15.

Шаг 14. Системы линейных уравнений и метод Гаусса

Система линейных уравнений $Aw = c$ спрашивает: «какой вектор $w$ преобразование $A$ переводит в $c$?». У неё две картинки:

  • По строкам: каждое уравнение $a_{i1}w_1 + a_{i2}w_2 = c_i$ — прямая (в $\mathbb R^3$ — плоскость); решение — их общая точка.
  • По столбцам: $w_1 A^{(1)} + w_2 A^{(2)} = c$ — подобрать коэффициенты, чтобы комбинация столбцов дала $c$ (шаг 2). Решение есть, если $c$ лежит в оболочке столбцов.

Исход всегда один из трёх: единственное решение ($\det A \ne 0$: прямые пересекаются в точке), нет решений (прямые параллельны), бесконечно много (прямые совпадают). Решают системы методом Гаусса: элементарными операциями со строками (прибавить к строке другую, умноженную на число; поменять строки; умножить строку на ненулевое число) приводят систему к треугольному виду, а затем находят неизвестные с конца. Эти операции не меняют множество решений, потому что их можно отменить.

Пример 1 ★. Две прямые

$x + y = 4$, $x - y = 0$. Сложив, $2x = 4$: $x = 2$, $y = 2$. По столбцам: $2\cdot(1, 1) + 2\cdot(1, -1) = (4, 0)$.

Пример 2 ★★. Гаусс для 3 × 3

$x + y + z = 6$, $2x + y - z = 1$, $x - y + 2z = 5$. Из второй строки вычитаем удвоенную первую: $-y - 3z = -11$; из третьей — первую: $-2y + z = -1$. Из новой третьей вычитаем удвоенную вторую: $7z = 21$, $z = 3$. Обратный ход: $-y - 9 = -11$, $y = 2$; $x = 6 - 2 - 3 = 1$. Решение $(1, 2, 3)$ — пройдите его по шагам на виджете.

Пример 3 ★★. Противоречие

$x + y + z = 6$ и $2x + 2y + 2z = 10$. Вычитая удвоенную первую, получим $0 = -2$ — решений нет: плоскости параллельны.

Пример 4 ★★★. Семейство решений

Если третье уравнение — сумма первых двух ($3x + 2y = 7$), после исключения оно превращается в $0 = 0$. Неизвестная $z = t$ остаётся свободной: $y = 11 - 3t$, $x = 2t - 5$. Решения образуют прямую в пространстве; при $t = 3$ — снова $(1, 2, 3)$.

Метод Гаусса для $n$ уравнений требует порядка $\frac23 n^3$ операций: система из 1000 уравнений — около $7 \cdot 10^8$ умножений, доли секунды. Чтобы не делить на очень маленькие числа, строки переставляют, выбирая наибольший по модулю ведущий элемент (частичный выбор главного элемента) — так и устроен np.linalg.solve.

Шаг 15. Ранг, вырожденность и обусловленность

Ранг матрицы — число линейно независимых столбцов (оно же — строк), то есть размерность пространства столбцов. У матрицы признаков $X$ размера $n \times p$ полный ранг, если $\operatorname{rank} X = p$: ни один признак не выражается через остальные. Иначе говорят о мультиколлинеарности: веса линейной модели определены неоднозначно (шаг 3), матрица $X^\top X$ вырождена.

Хуже точной зависимости — почти зависимость. Определитель тут плохой индикатор (он зависит от масштаба), а правильная мера — число обусловленности $\kappa(A)$: во сколько раз относительная ошибка во входе может вырасти в ответе. Для симметричной матрицы $\kappa = \lambda_{\max}/\lambda_{\min}$ (шаг 24), в общем случае — отношение крайних сингулярных чисел (шаг 26). Практическое правило: при $\kappa \approx 10^k$ теряется около $k$ верных десятичных знаков.

Пример 1 ★. Ранг

$\operatorname{rank}\begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix} = 1$: второй столбец — удвоенный первый. $\operatorname{rank}\begin{pmatrix} 1 & 0 & 1 \\ 0 & 1 & 1 \end{pmatrix} = 2$: столбцов три, но в $\mathbb R^2$ больше двух независимых не бывает.

Пример 2 ★★. Тысячекратное усиление

$x + y = 2$, $x + 1.001y = 2.001$: решение $(1, 1)$. Изменим правую часть второго уравнения на 0.001 — до 2.002: решение $(0, 2)$. Вход изменился на 0.05 %, ответ — полностью. $\kappa(A) \approx 4000$: прямые почти параллельны, и точку пересечения «носит» вдоль них.

Пример 3 ★★. Признаки-двойники

Площадь в м² и площадь в м², округлённая до целых, — почти один признак. Линейная регрессия может выдать для них веса $+250$ и $-248$ (их сумма осмысленна, а каждый по отдельности — шум), и при новом обучении на чуть других данных — совсем другие числа. Лечение — убрать дубль, регуляризация (шаг 20) или PCA (шаг 28).

Пример 4 ★★★. А деревья?

Дерево в каждом узле выбирает один признак, поэтому мультиколлинеарность не ломает ни прогнозы, ни обучение бустинга. Но она путает интерпретацию: важность делится между двойниками случайным образом — то один выигрывает разбиение, то другой (урок ).

Шаг 16. Ортонормированные базисы и процесс Грама — Шмидта

Базис $q_1, \dots, q_n$ называют ортонормированным, если векторы единичной длины и попарно перпендикулярны: $q_i \cdot q_j = 0$ при $i \ne j$, $q_i \cdot q_i = 1$. В таком базисе всё становится простым:

  • Координаты — это скалярные произведения: $v = (v\cdot q_1)q_1 + \dots + (v \cdot q_n)q_n$. Не нужно решать систему, как в шаге 3.
  • Матрица $Q$ со столбцами $q_i$ — ортогональная: $Q^\top Q = I$, то есть $Q^{-1} = Q^\top$. Она сохраняет длины и углы: $\|Qv\| = \|v\|$. Это повороты и отражения.
  • Проекция на оболочку нескольких $q_i$ — сумма проекций на каждый: $\sum_i (v\cdot q_i)q_i$.

Из любого независимого набора можно сделать ортонормированный — процесс Грама — Шмидта: берём векторы по очереди, вычитаем из каждого проекции на уже построенные и нормируем то, что осталось.

$$q_1 = \frac{a_1}{\|a_1\|}, \qquad e_2 = a_2 - (a_2\cdot q_1)\,q_1, \quad q_2 = \frac{e_2}{\|e_2\|}, \qquad \dots$$

Записанный в матрицах, процесс даёт QR-разложение $X = QR$: $Q$ — ортонормированные столбцы, $R$ — верхнетреугольная матрица коэффициентов. Через него решают метод наименьших квадратов надёжнее, чем через $X^\top X$ (шаг 18): у $X^\top X$ обусловленность равна квадрату обусловленности $X$, и цифры теряются вдвое быстрее.

Пример 1 ★. Координаты в повёрнутом базисе

$q_1 = \frac{1}{\sqrt2}(1, 1)$, $q_2 = \frac{1}{\sqrt2}(-1, 1)$. Для $v = (3, 1)$: $v \cdot q_1 = \frac{4}{\sqrt2} = 2\sqrt2$, $v \cdot q_2 = -\frac{2}{\sqrt2} = -\sqrt2$. Проверка: $2\sqrt2 q_1 - \sqrt2 q_2 = (2, 2) - (-1, 1) = (3, 1)$.

Пример 2 ★★. Грам — Шмидт по шагам

$a_1 = (3, 1)$, $a_2 = (2, 2)$. $q_1 = (3, 1)/\sqrt{10} \approx (0.949, 0.316)$. $a_2 \cdot q_1 = 8/\sqrt{10} \approx 2.530$; вычитаем проекцию $\frac{8}{10}(3, 1) = (2.4, 0.8)$: $e_2 = (-0.4, 1.2)$, $\|e_2\| \approx 1.265$, $q_2 \approx (-0.316, 0.949)$. Проверка: $q_1 \cdot q_2 = 0$. Матрица $R = \begin{pmatrix} 3.162 & 2.530 \\ 0 & 1.265 \end{pmatrix}$, и $QR$ возвращает $\begin{pmatrix} 3 & 2 \\ 1 & 2 \end{pmatrix}$.

Пример 3 ★★★. Центрирование — это шаг Грама — Шмидта

Возьмём столбцы матрицы квартир $\mathbf 1$ и $x = (1, \dots, 6)$. Вычесть из $x$ его проекцию на $\mathbf 1$ — значит вычесть среднее: $x - 3.5\cdot\mathbf 1 = (-2.5, \dots, 2.5)$. Это центрирование признака, и после него столбцы ортогональны. Регрессия на центрированный признак распадается на две независимые задачи: сдвиг = среднее $y$, наклон = проекция $y$ на центрированный $x$. Отсюда формула $k = \frac{\sum (x_i - \bar x)(y_i - \bar y)}{\sum (x_i - \bar x)^2}$ (шаг 18) и хорошая обусловленность (шаг 25).

Шаг 17. Проекция на плоскость: главная картинка метода наименьших квадратов

Проекция на прямую (шаг 6) обобщается на любое подпространство. Пусть столбцы матрицы $X$ ($n \times p$, полного ранга) натягивают подпространство — пространство столбцов. Проекция $\hat y = Xw$ вектора $y$ на него — ближайшая к $y$ точка, и остаток $r = y - Xw$ перпендикулярен каждому столбцу:

$$X^\top (y - Xw) = 0 \quad\Longleftrightarrow\quad X^\top X\,w = X^\top y \quad\Longrightarrow\quad \hat y = \underbrace{X(X^\top X)^{-1}X^\top}_{P}\,y$$
$X^\top X w = X^\top y$
нормальные уравнения («нормаль» — перпендикуляр): $p$ уравнений на $p$ весов
$P$
матрица проекции $n \times n$: симметрична ($P^\top = P$) и идемпотентна ($P^2 = P$ — спроецированное повторно не меняется)

Пример 1 ★. Три квартиры

$X = \begin{pmatrix} 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{pmatrix}$, $y = (2, 4, 3)$. $X^\top X = \begin{pmatrix} 3 & 6 \\ 6 & 14 \end{pmatrix}$, $X^\top y = (9, 19)$. Определитель $42 - 36 = 6$, решение $w = \frac16(14\cdot 9 - 6 \cdot 19,\; -6\cdot 9 + 3\cdot 19) = (2, 0.5)$. Прогнозы $\hat y = (2.5, 3, 3.5)$, остаток $r = (-0.5, 1, -0.5)$, $\|r\|^2 = 1.5$.

Пример 2 ★★. Проверить перпендикулярность

$r \cdot \mathbf 1 = -0.5 + 1 - 0.5 = 0$ и $r \cdot x = -0.5 + 2 - 1.5 = 0$. Остаток перпендикулярен обоим столбцам, а значит, и всей плоскости. Для сравнения: лучшая константа (проекция на одну прямую $\mathbf 1$) даёт $\|r\|^2 = 2$ — плоскость шире прямой, и ближайшая точка в ней ближе.

Пример 3 ★★. Если $y$ уже в плоскости

Поставьте на виджете $y = (1, 2, 3)$ — это столбец $x$. Проекция совпадает с $y$, остаток нулевой: прямая проходит через все точки. Так бывает, только если ответы точно линейно зависят от признаков.

Пример 4 ★★★. Матрица проекции

Для трёх квартир $P = \frac16\begin{pmatrix} 5 & 2 & -1 \\ 2 & 2 & 2 \\ -1 & 2 & 5 \end{pmatrix}$. Её собственные числа (шаг 21) — $1, 1, 0$: векторы плоскости она не меняет, перпендикуляр к плоскости уничтожает. След (сумма диагонали) $\frac{5 + 2 + 5}{6} = 2$ — число параметров модели. В статистике его называют числом степеней свободы модели; для деревьев и бустинга аналогом служит след их «сглаживающей» матрицы (шаг 31).

Шаг 18. Метод наименьших квадратов

Подберём прямую $\hat y = b + kx$ к шести квартирам так, чтобы сумма квадратов остатков была минимальной. Это метод наименьших квадратов (МНК, least squares) — основа линейной регрессии. Мы уже знаем геометрический ответ (проекция), выведем его ещё и через производные.

Шаг 1. Что минимизируем

$L(w) = \|y - Xw\|^2 = (y - Xw)^\top (y - Xw)$ — квадрат длины вектора остатков, функция двух переменных $b$ и $k$.

Шаг 2. Раскрываем скобки

$L(w) = y^\top y - 2\,w^\top X^\top y + w^\top X^\top X\,w$ — квадратичная функция весов: «чаша» (шаг 24).

Шаг 3. Градиент

По правилам урока ($\nabla(a^\top w) = a$, $\nabla(w^\top A w) = 2Aw$ для симметричной $A$): $\nabla L = -2X^\top y + 2X^\top X w = -2X^\top r$.

Шаг 4. Условие минимума

$\nabla L = 0 \iff X^\top r = 0 \iff X^\top X\,w = X^\top y$ — те же нормальные уравнения, что дала геометрия в шаге 17. Минимум, а не максимум: матрица $X^\top X$ «неотрицательна» ($w^\top X^\top X w = \|Xw\|^2 \ge 0$), чаша смотрит вверх.

Шаг 5. Решаем для квартир

$X^\top X = \begin{pmatrix} 6 & 21 \\ 21 & 91 \end{pmatrix}$ (число квартир, сумма площадей, сумма квадратов площадей), $X^\top y = (36, 158)$. Определитель $546 - 441 = 105$. Решение: $b = \frac{91\cdot36 - 21\cdot158}{105} = -0.4$, $k = \frac{6\cdot158 - 21\cdot36}{105} = \frac{192}{105} \approx 1.829$. Сумма квадратов остатков 5.486.

Шаг 6. Насколько хорошо

Константа (среднее 6) оставляла $\|r\|^2 = 64$, прямая — 5.486. Доля объяснённого разброса $R^2 = 1 - \frac{5.486}{64} \approx 0.914$. По Пифагору $64 = 58.514 + 5.486$: разброс вокруг среднего = объяснённый прямой + оставшийся.

Пример 1 ★★. Формула наклона

С центрированным признаком (шаг 16) наклон — проекция центрированного $y$ на центрированный $x$: $k = \frac{\sum (x_i - \bar x)(y_i - \bar y)}{\sum (x_i - \bar x)^2} = \frac{32}{17.5} \approx 1.829$, а сдвиг подбирается так, чтобы прямая прошла через точку средних: $b = \bar y - k\bar x = 6 - 1.829 \cdot 3.5 = -0.4$.

Пример 2 ★★. Остатки в среднем нулевые

Остатки МНК-прямой: $(0.571, 0.743, -2.086, 0.086, 0.257, 0.429)$. Их сумма — ноль (перпендикулярность столбцу единиц), и сумма произведений на площади — тоже ноль. Любая модель со сдвигом, обученная по МНК, имеет нулевой средний остаток на обучающей выборке.

Пример 3 ★★★. МНК и выброс

Третья квартира (цена 3 при площади 3) даёт самый большой остаток $-2.09$, и прямая «тянется» к ней квадратом этого остатка. Если вместо суммы квадратов минимизировать сумму модулей (L1, шаг 7), получится медианная регрессия — устойчивая к выбросам, но без формулы: её решают численно.

Шаг 19. Признаки-конструкторы: полиномы и переобучение

«Линейная» в линейной регрессии — по весам, а не по признакам. В столбцы матрицы можно положить любые функции от $x$: $1, x, x^2, x^3, \dots$ — и МНК без изменений подберёт полином. Матрица из степеней называется матрицей Вандермонда.

Две беды становятся видны сразу:

  • Переобучение. Чем больше столбцов, тем шире пространство столбцов и тем ближе проекция к $y$: сумма квадратов на обучении только падает. При шести точках полином пятой степени проходит через все — ошибка 0. Но честная оценка — ошибка на объекте, которого модель не видела (скользящий контроль с исключением по одному, LOO), — растёт (урок ).
  • Плохая обусловленность. Столбцы $x^4$ и $x^5$ почти параллельны (обе быстро растущие кривые), и $\kappa(X^\top X)$ взлетает до $10^{11}$. Помогает стандартизация $x$ — числа $z^k$ при $|z| \le 1.5$ остаются умеренными — и ортогональные многочлены.

Шаг 20. Гребневая регрессия: λ лечит вырожденность

Добавим к сумме квадратов штраф за длину весов (L2, шаг 7):

$$\min_w\; \|y - Xw\|^2 + \lambda\|w\|^2 \quad\Longrightarrow\quad (X^\top X + \lambda I)\,w = X^\top y$$

Это гребневая регрессия (ridge regression, регуляризация Тихонова). Добавка $\lambda I$ поднимает все собственные числа матрицы $X^\top X$ на $\lambda$ (шаг 21): нулевые становятся положительными — матрица всегда обратима, а обусловленность падает с $\frac{\lambda_{\max}}{\lambda_{\min}}$ до $\frac{\lambda_{\max} + \lambda}{\lambda_{\min} + \lambda}$. Цена — веса «сжимаются» к нулю, модель смещается. Сдвиг (вес при $\mathbf 1$) обычно не штрафуют.

Пример 1 ★. Один признак

С одним столбцом: $w = \frac{x\cdot y}{x \cdot x + \lambda}$. При $\lambda = 0$ — обычная проекция, при $\lambda \to \infty$ — ноль. Сравните с листом XGBoost $-\frac{G}{H + \lambda}$ (урок ): лист — это гребневая регрессия на одном столбце-индикаторе (шаг 32).

Пример 2 ★★. Полином пятой степени

На виджете — полином пятой степени по стандартизованной площади. При $\lambda = 10^{-4}$ он почти проходит через все точки, а ошибка LOO 113. С ростом $\lambda$ кривая выпрямляется: при $\lambda = 1$ сумма квадратов 6.35, LOO 7.47, $\kappa$ упала с 4576 до 114; лучшая LOO 4.21 — при $\lambda \approx 4.2$. Честно: прямая (LOO 1.665) всё равно лучше — регуляризация спасает переобученную модель, но не заменяет правильный выбор признаков.

Пример 3 ★★★. Ловушка фиктивных переменных снова

С индикаторами трёх районов и столбцом единиц (шаг 3) $X^\top X$ вырождена. С $\lambda > 0$ решение единственное: из всех наборов весов с одинаковыми прогнозами штраф выбирает самый короткий. Поэтому в моделях с регуляризацией one-hot без выброшенного столбца — нормальная практика.

Шаг 21. Собственные векторы: направления, которые матрица не поворачивает

Почти каждый вектор под действием матрицы и растягивается, и поворачивается. Но у многих матриц есть особые направления, вдоль которых вектор только растягивается:

$$A v = \lambda v, \qquad v \ne 0$$
$v$
собственный вектор (eigenvector): направление, которое $A$ не поворачивает (может развернуть на 180° при $\lambda < 0$)
$\lambda$
собственное число (eigenvalue): во сколько раз $A$ растягивает вдоль $v$

Собственный вектор определён с точностью до множителя: если $v$ собственный, то и $2v$, и $-v$. Поэтому говорят о собственных направлениях.

Пример 2 ★★. Матрица проекции

Для матрицы проекции $P$ (шаг 17) векторы плоскости — собственные с $\lambda = 1$ ($Pv = v$), перпендикуляр — с $\lambda = 0$ ($Pv = 0$). Других собственных чисел у проекций не бывает: из $P^2 = P$ следует $\lambda^2 = \lambda$.

Пример 3 ★★★. Сдвиг — «дефектная» матрица

У сдвига $\begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ одно собственное направление: $(x, y) \mapsto (x + y, y)$ не поворачивает вектор только при $y = 0$. Собственных векторов меньше, чем размерность, — из них нельзя составить базис. У симметричных матриц так не бывает никогда (шаг 24).

Шаг 22. Как найти собственные числа: $\det(A - \lambda I) = 0$

Перепишем $Av = \lambda v$ как $(A - \lambda I)v = 0$. Ненулевое решение у однородной системы есть, только если матрица $A - \lambda I$ сплющивает пространство (шаг 14), то есть её определитель равен нулю. Получаем уравнение на $\lambda$ — характеристическое:

$$\det(A - \lambda I) = 0 \quad\overset{2\times 2}{\Longleftrightarrow}\quad \lambda^2 - \underbrace{(a + d)}_{\operatorname{tr}A}\,\lambda + \underbrace{(ad - bc)}_{\det A} = 0$$

Для матрицы $2 \times 2$ это квадратное уравнение: его корни — собственные числа, и по теореме Виета сумма собственных чисел равна следу $\operatorname{tr}A = a + d$ (сумма диагонали), а произведение — определителю. Дискриминант решает, какие корни: два вещественных, один кратный или пара комплексных (тогда матрица что-то вращает). Собственный вектор для найденного $\lambda$ — любое ненулевое решение $(A - \lambda I)v = 0$.

Пример 1 ★. Симметричная матрица

$\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$: $\lambda^2 - 4\lambda + 3 = 0$, корни 3 и 1. Для $\lambda = 3$: $\begin{pmatrix} -1 & 1 \\ 1 & -1 \end{pmatrix}v = 0$, $v = (1, 1)$. Для $\lambda = 1$: $v = (1, -1)$. Проверка Виета: $3 + 1 = 4 = \operatorname{tr}$, $3 \cdot 1 = 3 = \det$.

Пример 2 ★★. Несимметричная

$\begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}$: $\lambda^2 - 7\lambda + 10 = 0$, корни 5 и 2. Для $\lambda = 5$: $-v_1 + v_2 = 0$, $v = (1, 1)$. Для $\lambda = 2$: $2v_1 + v_2 = 0$, $v = (1, -2)$. Векторы не перпендикулярны — у несимметричных матриц так бывает.

Пример 3 ★★. Поворот

$\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$: $\lambda^2 + 1 = 0$, $\lambda = \pm i$. Вещественных собственных направлений нет. Комплексные собственные числа $\alpha \pm \beta i$ означают вращение с растяжением в $\sqrt{\alpha^2 + \beta^2}$ раз — так в уроке появлялись фокусы и центры фазовых портретов.

Пример 4 ★★★. Кратный корень

$\begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$: $(\lambda - 1)^2 = 0$. Система $(A - I)v = 0$ — это $v_2 = 0$: одно направление. А у $I$ тоже $(\lambda - 1)^2 = 0$, но собственный — любой вектор. Кратный корень ещё не говорит, сколько направлений.

Шаг 23. Диагонализация и степени матрицы

Если у матрицы $n \times n$ есть $n$ независимых собственных векторов, в их базисе она — просто растяжение по осям. Записав собственные векторы столбцами матрицы $V$, а числа — на диагональ $\Lambda$:

$$A = V\Lambda V^{-1}, \qquad A^k = V\Lambda^k V^{-1}$$

Применить матрицу $k$ раз — значит возвести каждое собственное число в степень $k$. Отсюда главный закон линейных итераций $x_{k+1} = Ax_k$: разложите $x_0$ по собственным векторам, $x_0 = c_1v_1 + c_2v_2$, тогда $x_k = c_1\lambda_1^kv_1 + c_2\lambda_2^kv_2$. Компонента с наибольшим $|\lambda|$ побеждает: направление $x_k$ стремится к главному собственному вектору со скоростью $|\lambda_2/\lambda_1|^k$. На этом основан степенной метод поиска главного собственного вектора — и PageRank (урок ).

Пример 1 ★. Диагональная матрица

$\operatorname{diag}(2, 0.5)^{10} = \operatorname{diag}(1024, 0.00098)$. Любой вектор с ненулевой первой координатой после 10 применений смотрит почти точно вдоль оси $x$.

Пример 2 ★★. Числа Фибоначчи

$\begin{pmatrix} F_{k+1} \\ F_k \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} F_k \\ F_{k-1} \end{pmatrix}$. Собственные числа — корни $\lambda^2 - \lambda - 1 = 0$: $\varphi = \frac{1 + \sqrt5}{2} \approx 1.618$ (золотое сечение) и $-0.618$. Вторая степень быстро гаснет, поэтому $F_k \approx \varphi^k/\sqrt5$: $F_{20} = 6765$, а $\varphi^{20}/\sqrt5 \approx 6765.00003$. Отношение соседних чисел стремится к $\varphi$.

Пример 3 ★★. Погода как цепь Маркова

После солнечного дня солнце завтра с вероятностью 0.9, после дождливого — 0.5. Матрица переходов (столбцы — «откуда») $P = \begin{pmatrix} 0.9 & 0.5 \\ 0.1 & 0.5 \end{pmatrix}$, собственные числа 1 и 0.4. Начав с дождя, $(0, 1)$: через день $(0.5, 0.5)$, через два — $(0.7, 0.3)$, через десять — $(0.83325, 0.16675)$. Предел — собственный вектор с $\lambda = 1$: $(5/6, 1/6)$, стационарное распределение (урок ); отклонение тает как $0.4^k$.

Пример 4 ★★★. Градиентный спуск — линейная итерация

Для квадратичных потерь $L = \frac12 (w - w^*)^\top H (w - w^*)$ ошибка спуска $e_k = w_k - w^*$ меняется линейно: $e_{k+1} = (I - \eta H)\,e_k$. Собственные числа матрицы шага — $1 - \eta\lambda_i$, где $\lambda_i$ — собственные числа гессиана. Спуск сходится, когда все $|1 - \eta\lambda_i| < 1$, то есть $\eta < 2/\lambda_{\max}$ — та самая граница из уроков и , а скорость задаёт самое медленное направление $\lambda_{\min}$ (шаг 25).

Шаг 24. Симметричные матрицы и квадратичные формы

Симметричные матрицы ($A^\top = A$) — главные в машинном обучении: гессианы, $X^\top X$, ковариационные матрицы. У них всё устроено идеально — это спектральная теорема:

У симметричной матрицы все собственные числа вещественны, а собственные векторы можно выбрать ортонормированными. Значит, $A = Q\Lambda Q^\top$ с ортогональной $Q$: симметричная матрица — это растяжение вдоль перпендикулярных осей (возможно, с отражением при $\lambda < 0$).

Симметричная матрица задаёт квадратичную форму $f(x) = x^\top A x$; для $A = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$ это $ax_1^2 + 2bx_1x_2 + cx_2^2$. В координатах собственного базиса $u = Q^\top x$ перекрёстный член исчезает: $f = \lambda_1u_1^2 + \lambda_2u_2^2$. Отсюда классификация:

  • все $\lambda_i > 0$ — положительно определённая форма: чаша, линии уровня — эллипсы с осями вдоль собственных векторов и полуосями $1/\sqrt{\lambda_i}$; минимум в нуле;
  • $\lambda_i$ разных знаков — неопределённая: седло, линии уровня — гиперболы;
  • какие-то $\lambda_i = 0$, остальные $> 0$ — полуопределённая: жёлоб с целой прямой минимумов.

Быстрая проверка для $2 \times 2$ (критерий Сильвестра): форма положительно определена, если $a > 0$ и $\det A = ac - b^2 > 0$. Гессиан функции в критической точке — тоже квадратичная форма: положительно определён — минимум, неопределён — седло (урок ).

Пример 1 ★. Без перекрёстного члена

$x_1^2 + 3x_2^2$: матрица $\operatorname{diag}(1, 3)$, оси эллипсов — координатные, вдоль $x_1$ форма растёт медленнее (полуось в $\sqrt3$ раз длиннее).

Пример 2 ★★. Повёрнутая чаша

$2x_1^2 + 2x_1x_2 + 2x_2^2$: матрица $\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$, $\lambda = 3$ и 1, оси эллипсов — диагонали $(1, 1)$ и $(1, -1)$. Вдоль $(1, -1)$ форма растёт втрое медленнее.

Пример 3 ★★. Седло

$x_1^2 + 4x_1x_2 + x_2^2$: матрица $\begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}$, $\det = -3 < 0$, $\lambda = 3$ и $-1$. Вдоль $(1, 1)$ форма растёт, вдоль $(1, -1)$ — убывает. Хотя оба диагональных коэффициента положительны, форма — не чаша.

Пример 4 ★★★. $X^\top X$ всегда «чаша»

$w^\top X^\top X w = (Xw)\cdot(Xw) = \|Xw\|^2 \ge 0$ — матрица $X^\top X$ положительно полуопределена при любых данных, а при полном ранге $X$ — определена. Поэтому сумма квадратов в МНК — выпуклая чаша с единственным минимумом, и градиентный спуск не застрянет в чужой яме. Собственные числа $X^\top X$ — это «кривизны» чаши; от их отношения зависит скорость спуска.

Шаг 25. Обусловленность и градиентный спуск: зачем стандартизировать признаки

Соберём шаги 23 и 24. Для МНК $L(w) = \|y - Xw\|^2$ гессиан постоянный: $H = 2X^\top X$. Градиентный спуск сходится при $\eta < 2/\lambda_{\max}$, а за шаг ошибка вдоль самого пологого направления умножается на $1 - \eta\lambda_{\min}$. Лучший постоянный темп $\eta = \frac{2}{\lambda_{\min} + \lambda_{\max}}$ даёт множитель $\frac{\kappa - 1}{\kappa + 1}$, где $\kappa = \lambda_{\max}/\lambda_{\min}$ — обусловленность. Число шагов растёт пропорционально $\kappa$.

Для квартир $X^\top X = \begin{pmatrix} 6 & 21 \\ 21 & 91 \end{pmatrix}$ с собственными числами 95.9 и 1.09: $\kappa \approx 87.6$. Чаша — длинный узкий овраг вдоль направления, в котором сдвиг и наклон компенсируют друг друга. А после центрирования площади ($x - 3.5$) столбцы ортогональны (шаг 16), $X^\top X = \operatorname{diag}(6,\; 17.5)$ и $\kappa \approx 2.92$; после стандартизации ($z = (x - 3.5)/1.708$) $X^\top X = 6I$, $\kappa = 1$ — идеально круглая чаша.

Пример 1 ★★. Число шагов

Спуск из $w = (0, 0)$ до относительной точности $10^{-6}$. Сырая площадь: при $\eta = 1/\lambda_{\max}$ — 1130 шагов, при лучшем $\eta \approx 0.0103$ — 606. Центрированная: 33 и 20 шагов. Стандартизованная: с лучшим темпом — один шаг (все направления одинаковы, и шаг $\eta = 1/\lambda$ попадает точно в минимум).

Пример 2 ★★★. Почему деревьям всё равно

Стандартизация — линейная замена переменных, она меняет форму чаши МНК. Дерево же ищет пороги перебором и не делает градиентных шагов по весам признаков: монотонное преобразование признака сохраняет порядок объектов, а значит, и все возможные разбиения. Бустинг делает градиентные шаги по прогнозам, а не по признакам; его «гессиан» по прогнозам диагонален (урок ), и вопрос обусловленности решается шагом Ньютона в листьях (шаг 32).

Шаг 26. Сингулярное разложение: поворот — растяжение — поворот

Собственные векторы есть не у всякой матрицы, и бывают только у квадратных. Но у любой матрицы $A$ размера $m \times n$ есть сингулярное разложение (singular value decomposition, SVD):

$$A = U\Sigma V^\top$$
$V$
ортогональная $n \times n$: поворот (или отражение) исходного пространства; столбцы $v_i$ — правые сингулярные векторы
$\Sigma$
«диагональная» $m \times n$ с сингулярными числами $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$: растяжение вдоль осей
$U$
ортогональная $m \times m$: поворот в пространстве результата; $Av_i = \sigma_i u_i$

Геометрически: любая матрица переводит единичную окружность в эллипс; $\sigma_i$ — полуоси эллипса, $u_i$ — их направления, $v_i$ — векторы окружности, которые в них переходят. Сингулярные числа — корни из собственных чисел симметричной матрицы $A^\top A$, а $v_i$ — её собственные векторы.

  • $\sigma_1 = \max_{\|x\| = 1}\|Ax\|$ — наибольшее растяжение (норма матрицы); $\kappa(A) = \sigma_1/\sigma_n$ — обусловленность (шаг 15).
  • Ранг — число ненулевых $\sigma_i$; $|\det A| = \sigma_1\cdots\sigma_n$ для квадратной.
  • У симметричной положительно определённой матрицы SVD совпадает с собственным разложением.
  • Псевдообратная $A^+ = V\Sigma^+U^\top$ ($\Sigma^+$ — обратить ненулевые $\sigma_i$) решает МНК даже для вырожденной $X$: из всех решений даёт самое короткое (np.linalg.lstsq, np.linalg.pinv).

Пример 1 ★. Диагональная матрица

$\operatorname{diag}(3, 1)$: $U = V = I$, $\sigma = 3, 1$. У $\operatorname{diag}(-3, 1)$ сингулярные числа те же — минус уходит в отражение $U$.

Пример 2 ★★. Несимметричная

$A = \begin{pmatrix} 3 & 0 \\ 4 & 5 \end{pmatrix}$: $A^\top A = \begin{pmatrix} 25 & 20 \\ 20 & 25 \end{pmatrix}$, собственные числа 45 и 5, значит $\sigma_1 = \sqrt{45} \approx 6.708$, $\sigma_2 = \sqrt5 \approx 2.236$. Правые векторы — диагонали: $A\frac{(1, 1)}{\sqrt2} = \frac{(3, 9)}{\sqrt2}$ длины 6.708. Проверка: $\sigma_1\sigma_2 = 15 = \det A$; $\kappa = 3$. Заметьте: собственные числа $A$ — 3 и 5, а сингулярные — другие.

Пример 3 ★★★. Вырожденная матрица

$\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$: $\sigma = 2, 0$ — ранг 1; окружность сплющивается в отрезок длины 4 вдоль $(1, 1)$. Система $Aw = (2, 2)$ имеет бесконечно много решений $w_1 + w_2 = 2$; псевдообратная выбирает самое короткое — $(1, 1)$.

Шаг 27. Малоранговое приближение: оставить главное

SVD можно записать как сумму простейших слагаемых: $A = \sigma_1u_1v_1^\top + \sigma_2u_2v_2^\top + \dots$ Каждое слагаемое $u\,v^\top$ — матрица ранга 1 («таблица умножения»: строка $i$, столбец $j$ — $u_iv_j$). Теорема Эккарта — Янга: лучшее приближение $A$ матрицей ранга $k$ (по сумме квадратов разностей) — первые $k$ слагаемых, а ошибка равна $\sqrt{\sigma_{k+1}^2 + \sigma_{k+2}^2 + \dots}$.

Картинка 40 × 40 — это матрица из 1600 чисел. Ранг-$k$ приближение хранит $k(40 + 40 + 1)$ чисел. Обратите внимание, что лучше всего приближаются горизонтальные и вертикальные структуры (прямоугольник, градиент фона): они почти ранга 1. Диагональная линия и кольцо требуют многих слагаемых — как косая граница требует многих разбиений дерева (шаг 8).

Пример 1 ★. Таблица умножения

$u = (1, 2, 3)$, $v = (1, 10)$: $uv^\top = \begin{pmatrix} 1 & 10 \\ 2 & 20 \\ 3 & 30 \end{pmatrix}$ — 6 чисел задаются пятью, а матрица $1000 \times 1000$ ранга 1 — двумя тысячами вместо миллиона.

Пример 2 ★★. Сжатие картинки

Для картинки виджета: ранг 1 хранит 5 % чисел и даёт относительную ошибку 46 %, ранг 5 — 25 % чисел и 21 %, ранг 10 — 51 % и 12 %, ранг 15 — 76 % и 6.2 %. Точный ранг картинки — 23. Самое большое сингулярное число 15.9, второе — уже 5.5: основная «энергия» в первом слагаемом.

Пример 3 ★★★. Рекомендательные системы

Таблица «пользователь × фильм» из оценок огромна и почти пуста. Предположение «вкусы описываются несколькими факторами» — это предположение о малом ранге: оценка ≈ $u_i \cdot v_j$, где $u_i$ — вектор вкусов пользователя, $v_j$ — вектор свойств фильма. Подобрав их по известным оценкам (матричная факторизация), предсказывают неизвестные. Те же идеи стоят за эмбеддингами категорий и слов.

Шаг 28. Ковариация и метод главных компонент

Пусть $X_c$ — матрица признаков с центрированными столбцами (из каждого вычтено среднее). Тогда ковариационная матрица $C = \frac{1}{n - 1}X_c^\top X_c$ — симметричная $p \times p$: на диагонали дисперсии признаков, вне диагонали — ковариации. Корреляция двух признаков — это косинус угла между их центрированными столбцами: $\rho = \frac{x_c\cdot y_c}{\|x_c\|\|y_c\|}$.

Метод главных компонент (principal component analysis, PCA) ищет направление $u$ ($\|u\| = 1$), вдоль которого данные разбросаны сильнее всего. Дисперсия проекций на $u$ равна $u^\top C u$ — квадратичная форма (шаг 24), и её максимум достигается на собственном векторе с наибольшим собственным числом. Значит:

  • главные компоненты — собственные векторы ковариационной матрицы (или правые сингулярные векторы $X_c$), упорядоченные по убыванию $\lambda$;
  • $\lambda_k$ — дисперсия вдоль $k$-й компоненты; доля объяснённой дисперсии — $\lambda_k/\sum\lambda_i$;
  • проекция на первые $k$ компонент — лучшее $k$-мерное приближение облака точек по сумме квадратов перпендикулярных расстояний.

Пример 1 ★★. Квартиры

Для шести квартир (площадь, цена): $C = \begin{pmatrix} 3.5 & 6.4 \\ 6.4 & 12.8 \end{pmatrix}$, корреляция $\frac{6.4}{\sqrt{3.5\cdot12.8}} \approx 0.956$. Собственные числа 16.06 и 0.24: первая компонента объясняет 98.5 % дисперсии. Облако почти одномерно — его можно описать одним числом «размер квартиры».

Пример 2 ★★★. PCA — не регрессия

Наклон первой компоненты для квартир — 1.963, а наклон МНК-прямой — 1.829. МНК минимизирует вертикальные отрезки (ошибки в цене), PCA — перпендикулярные (обе переменные равноправны). Переключите на виджете показ обеих линий: при слабой корреляции они расходятся сильно.

Пример 3 ★★★. PCA и деревья

Дерево режет пространство перпендикулярно осям (шаг 8). Если главная структура данных — вдоль диагонали, поворот признаков в главные компоненты может сократить число разбиений (на этой идее построены «леса поворотов», rotation forest). Но это не правило: PCA выбирает направления по разбросу признаков, не глядя на ответ, и важное для прогноза направление может оказаться среди «мелких» компонент. Проверяйте на валидации.

Шаг 29. Дерево — проекция на «ступеньки»

Посмотрим на бустинг глазами линейной алгебры. «Параметры» бустинга — сами прогнозы на обучающих объектах: точка $F \in \mathbb R^n$. Для квадратичных потерь $\frac12\|y - F\|^2$ антиградиент по прогнозам — остатки $r = y - F$ (уроки , ). Дерево должно приблизить вектор $r$ — но дерево умеет выдавать только ступенчатые векторы: одинаковые числа у объектов одного листа.

Пусть разбиение на листья уже выбрано. Каждому листу $j$ сопоставим столбец-индикатор $\ell_j$: 1, если объект попал в лист, иначе 0. Все ступенчатые векторы — линейные комбинации индикаторов, $h = L\theta$, где $L = [\ell_1, \dots, \ell_J]$ — матрица $n \times J$, $\theta$ — значения листьев. Лучшие значения — проекция $r$ на пространство столбцов $L$, нормальные уравнения:

$$L^\top L\,\theta = L^\top r, \qquad L^\top L = \operatorname{diag}(n_1, \dots, n_J), \qquad L^\top r = (G_1, \dots, G_J) \;\Longrightarrow\; \theta_j = \frac{G_j}{n_j}$$

Индикаторы разных листьев не пересекаются, поэтому ортогональны, $L^\top L$ — диагональная (числа объектов в листьях $n_j$), и система решается делением: значение листа — среднее остатков в нём ($G_j$ — сумма остатков листа). Это та самая формула из уроков и , полученная как проекция.

Пример 1 ★. Пень с порогом 3.5

$r = (-4, -2, -3, 1, 3, 5)$. Индикаторы $\ell_1 = (1, 1, 1, 0, 0, 0)$, $\ell_2 = (0, 0, 0, 1, 1, 1)$, $L^\top L = \operatorname{diag}(3, 3)$, $L^\top r = (-9, 9)$, листья $-3$ и $3$. Проекция $h = (-3, -3, -3, 3, 3, 3)$, остаток после дерева $(-1, 1, 0, -2, 0, 2)$ — суммы в каждом листе нулевые: он перпендикулярен индикаторам.

Пример 2 ★★. Пифагор и падение потерь

$\|r\|^2 = 64$, $\|h\|^2 = 6\cdot 9 = 54$, $\|r - h\|^2 = 1 + 1 + 0 + 4 + 0 + 4 = 10$: $64 = 54 + 10$. Дерево уменьшает сумму квадратов ровно на $\|h\|^2$ — квадрат длины проекции.

Пример 3 ★★. Три листа

Пороги 3.5 и 4.5 (листья $\{1,2,3\}$, $\{4\}$, $\{5,6\}$): $h = (-3, -3, -3, 1, 4, 4)$, $\|h\|^2 = 60$, остаётся 4. Больше листьев — шире подпространство — ближе проекция. Предел — каждый объект в своём листе: $h = r$, остаток 0, полное запоминание обучающей выборки.

Пример 4 ★★★. Матрица дерева

На обучающих объектах дерево с фиксированным разбиением действует как матрица проекции $P = L(L^\top L)^{-1}L^\top$: внутри каждого листа она усредняет. $P^2 = P$ — дерево, обученное на собственный остаток, ничего не найдёт: остаток уже ортогонален его ступенькам. Поэтому следующее дерево бустинга обязано выбрать другое разбиение (шаг 31).

Шаг 30. Выигрыш разбиения — квадрат длины проекции

Перебирая пороги (урок ), дерево выбирает, на какое подпространство проецировать. Раз сумма квадратов падает ровно на $\|Pr\|^2$, лучшее разбиение — то, на которое проекция антиградиента длиннее:

$$\|Pr\|^2 = \sum_j n_j\theta_j^2 = \sum_j \frac{G_j^2}{n_j}, \qquad \text{выигрыш} = \frac{G_L^2}{n_L} + \frac{G_R^2}{n_R} - \frac{G^2}{n}$$

Последнее слагаемое — длина проекции на сам родительский лист (одну константу): выигрыш показывает, насколько разбиение длиннее «не делить». С шагом Ньютона длины считаются со взвешиванием по гессианам (шаг 32), $n_j$ заменяется на $H_j$, а λ добавляется в знаменатель — получается формула выигрыша XGBoost $\frac12\Bigl[\frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda}\Bigr] - \gamma$ (урок ; в нём $G$ — сумма градиентов $g = -r$, знак не важен из-за квадрата, а множитель $\frac12$ — от $\frac12$ в потерях).

Пример 1 ★★. Все пороги для квартир

Для $r = (-4, -2, -3, 1, 3, 5)$ (сумма 0, поэтому $G = 0$): порог 1.5 — $\frac{16}{1} + \frac{16}{5} = 19.2$; 2.5 — $\frac{36}{2} + \frac{36}{4} = 27$; 3.5 — $\frac{81}{3} + \frac{81}{3} = 54$; 4.5 — $\frac{64}{4} + \frac{64}{2} = 48$; 5.5 — $\frac{25}{5} + \frac{25}{1} = 30$. Лучший порог 3.5, как и в уроке .

Пример 2 ★★★. λ укорачивает проекцию

С $\lambda = 1$ для порога 3.5: $\frac{81}{3 + 1} + \frac{81}{3 + 1} = 40.5$ вместо 54. Штраф сильнее бьёт по маленьким листьям: у порога 1.5 лист из одного объекта даёт $\frac{16}{1 + 1} = 8$ вместо 16. Так λ отговаривает дерево от листьев «под один объект».

Шаг 31. Бустинг — цепочка проекций

Теперь весь алгоритм. На шаге $m$ дерево проецирует текущий остаток на своё лучшее подпространство, $h_m = P_m r_{m-1}$, и прогноз сдвигается на $\nu h_m$:

$$r_m = r_{m-1} - \nu P_m r_{m-1} = (I - \nu P_m)\,r_{m-1}, \qquad \|r_m\|^2 = \|r_{m-1}\|^2 - (2\nu - \nu^2)\,\|P_m r_{m-1}\|^2$$

Вторая формула — снова Пифагор: компонента остатка в подпространстве дерева умножается на $1 - \nu$, перпендикулярная не меняется. При $0 < \nu < 2$ множитель $2\nu - \nu^2$ положителен, и сумма квадратов строго убывает на каждом шаге — вот откуда граница $\nu < 2$ для квадратичных потерь (урок ). Такой жадный алгоритм в обработке сигналов называют согласованным преследованием (matching pursuit): из «словаря» (всех возможных деревьев) на каждом шаге берётся элемент, лучше всего совпадающий с остатком.

Пример 1 ★★. Первый шаг с разными ν

$\|r_0\|^2 = 64$, $\|P_1 r_0\|^2 = 54$. При $\nu = 1$: $64 - 54 = 10$. При $\nu = 0.5$: $64 - 0.75\cdot54 = 23.5$. При $\nu = 0.1$: $64 - 0.19\cdot54 = 53.74$.

Пример 2 ★★. Повторы разбиений

С $\nu = 1$ одно и то же разбиение дважды подряд не выбирается: после полной проекции остаток ортогонален ступенькам (шаг 29), и следующий пень берёт порог 5.5. С $\nu = 0.1$ компонента вдоль ступенек убывает медленно ($\times 0.9$ за шаг), и порог 3.5 выбирается три раза подряд. Пни для квартир, сумма квадратов: $\nu = 1$ — 10 → 5.2 → 4.24 → 3.04 → … → 0.34 к 10-му дереву; $\nu = 0.5$ — 23.5 → 9.44 → 4.88 → … → 0.47; $\nu = 0.1$ — 53.7 → 45.4 → … → 13.8.

Пример 3 ★★★. Одно дерево много раз

Если бы все деревья были одинаковыми ($P_m = P$), то $r_M = (I - \nu P)^M r_0$, а прогноз $F_M = F_0 + [I - (I - \nu P)^M]\,r_0$. Собственные числа $P$ — 0 и 1, поэтому компонента в подпространстве убывает как $(1 - \nu)^M$, а перпендикулярная остаётся. Для «сглаживающих» моделей с собственными числами между 0 и 1 эта формула — частичная сумма ряда Неймана (урок ): малый $\nu M$ отрезает компоненты с маленькими собственными числами — так ранняя остановка работает как регуляризация.

Шаг 32. Лист Ньютона — взвешенная проекция с λ

Для произвольных потерь XGBoost раскладывает их до второго порядка в каждом объекте (урок ): $\ell(y_i, F_i + w) \approx \ell_i + g_iw + \frac12h_iw^2$. Выделим полный квадрат:

$$g_iw + \tfrac12h_iw^2 = \tfrac12 h_i\bigl(w - z_i\bigr)^2 + \text{const}, \qquad z_i = -\frac{g_i}{h_i}$$

Значит, подбор листа — это взвешенный МНК: приблизить «рабочие ответы» $z_i$ (шаг Ньютона для каждого объекта по отдельности) константой с весами $h_i$. Взвешенная проекция на $\mathbf 1$ — взвешенное среднее (шаг 6, пример 4), а штраф $\frac12\lambda w^2$ — гребневая регрессия (шаг 20):

$$w^* = \frac{\sum h_i z_i}{\sum h_i + \lambda} = -\frac{\sum g_i}{\sum h_i + \lambda} = -\frac{G}{H + \lambda}$$

Объекты, в которых модель уже уверена, имеют маленькую кривизну $h_i = p_i(1 - p_i)$ и большой «рабочий ответ» $z_i$, но малый вес — и почти не влияют на лист. Для квадратичных потерь все $h_i = 1$, и формула превращается в простое среднее шага 29.

Пример 1 ★★. Первый шаг логистического бустинга

Лист из четырёх объектов с метками $(1, 1, 1, 0)$, все $F_i = 0$: $p_i = 0.5$, $g = (-0.5, -0.5, -0.5, 0.5)$, все $h_i = 0.25$, рабочие ответы $z = (2, 2, 2, -2)$. Веса равны, лист — простое среднее $z$: $w = 1$ (при $\lambda = 1$ — 0.5). Точный оптимум логистических потерь — логарифм шансов $\ln 3 \approx 1.099$: один шаг Ньютона почти попал.

Пример 2 ★★★. Смешанный лист

Метки $(1, 1, 0, 0)$, прогнозы $F = (2, 0.5, -0.5, 1)$: $h = (0.105, 0.235, 0.235, 0.197)$, $z = (1.14, 1.61, -1.61, -3.72)$. Взвешенное среднее $w = -\frac{G}{H} = -\frac{0.612}{0.772} \approx -0.793$ (точный оптимум $-0.75$), с $\lambda = 1$ — $-0.345$. Первый объект уверенно верен ($p = 0.88$) и весит меньше всех.

Пример 3 ★★★. Чистый лист

Все метки — единицы, прогнозы уже уверенные ($p$ от 0.92 до 0.98): $G = -0.171$, $H = 0.161$, шаг Ньютона $w \approx 1.06$. Точного оптимума нет — потери убывают при $w \to \infty$ (урок , шаг 27). С $\lambda = 1$ шаг $0.147$: в знаменателе $H + \lambda$ λ доминирует над крошечным $H$ и не даёт листу «улететь».

Шаг 33 (продвинутый). Ансамбль — линейная модель на индикаторах листьев

Соберём все индикаторы листьев всех деревьев в одну большую матрицу $\Phi$ размера $n \times (\text{всего листьев})$ — каждый объект кодируется нулями и единицами «в каких листьях он оказался». Прогноз ансамбля:

$$F(x) = F_0 + \sum_m \nu\, h_m(x) = F_0 + \Phi(x)\,\theta, \qquad \theta = \nu\cdot(\text{значения всех листьев})$$

Ансамбль деревьев — линейная модель на признаках-индикаторах, которые деревья построили сами. Бустинг подбирает её жадно и пошагово: каждое дерево добавляет новые столбцы и сразу назначает им веса, а старые веса больше не трогает. Отсюда две практические идеи:

  • Переобучить все листья вместе — решить МНК (лучше гребневый) по всем столбцам $\Phi$ сразу. Это лучшая проекция на пространство, которое построили деревья; бустинг в общем случае до неё не доходит.
  • Деревья как генератор признаков: индикаторы листьев бустинга подают в логистическую регрессию (известная схема Facebook 2014 года «GBDT + LR»). В XGBoost индексы листьев возвращает predict(..., pred_leaf=True), в LightGBM — pred_leaf=True.

Пример 1 ★★. Три пня с ν = 0.5

Бустинг выбирает пороги 3.5, 4.5, 5.5 и оставляет сумму квадратов 4.88. В $\Phi$ шесть столбцов, но ранг 4: два индикатора каждого пня в сумме дают $\mathbf 1$. Пороги делят квартиры на четыре области $\{1, 2, 3\}$, $\{4\}$, $\{5\}$, $\{6\}$, и проекция на их индикаторы оставляет только разброс внутри первой области: $(2 - 3)^2 + (4 - 3)^2 + 0 = 2$.

Пример 2 ★★★. Почему не всегда переобучать

Совместная подгонка уменьшает ошибку на обучении (4.88 → 2.0), но и легче переобучается: малый $\nu$ и жадность бустинга — встроенная регуляризация (шаг 31). На практике совместную подгонку делают с λ и проверяют на валидации (урок ).

Разбор по косточкам

Векторы

Стрелка и список чисел; сложение и умножение на число покоординатно. Признаки, ответы, прогнозы, остатки — векторы.

Линейные комбинации и базис

Оболочка — всё, куда можно дойти; независимость, базис, размерность, координаты; ловушка фиктивных переменных.

Скалярное произведение

$\sum a_ib_i = \|a\|\|b\|\cos\alpha$; ноль — перпендикулярность; Коши — Буняковский и направление градиента; косинусное сходство; масштаб признаков.

Проекция на вектор

$\frac{a\cdot b}{a\cdot a}a$; остаток ⟂; проекция на $\mathbf 1$ — среднее (лучшая константа); с весами — взвешенное среднее.

Нормы

L2, L1, L∞; MSE, MAE — нормы остатков; L2-штраф сжимает, L1-штраф обнуляет (углы ромба).

Гиперплоскости

$w\cdot x = b$, нормаль, знаковое расстояние; разбиение дерева — гиперплоскость с нормалью $e_j$; косая граница — лестница.

Матрицы

Таблица данных и преобразование; $Xw$ по строкам (скалярные произведения) и по столбцам (комбинация столбцов).

Преобразования и произведение

Столбцы — образы базиса; $AB$ — сначала $B$, потом $A$; $AB \ne BA$.

Определитель и обратная

det — масштаб площади со знаком; $\det = 0$ — сплющивание; $A^{-1}$ — отмена; маленький det — огромные элементы $A^{-1}$.

Системы и метод Гаусса

Строки — пересечение прямых, столбцы — комбинация; одно решение, ни одного или бесконечно много.

Ранг и обусловленность

Мультиколлинеарность; $\kappa$ — усиление ошибок; деревьям безразлична, но путает важности.

Ортогональность и МНК

Ближайшая точка — там, где остаток ортогонален.

Ортонормированный базис

Координаты — скалярные произведения; $Q^\top Q = I$; Грам — Шмидт и QR; центрирование.

Проекция на подпространство

$X^\top X w = X^\top y$; $P = X(X^\top X)^{-1}X^\top$, $P^2 = P$, след = число параметров.

Признаки и переобучение

Полиномы — те же МНК; ошибка на обучении падает, LOO растёт; $\kappa$ взлетает без стандартизации.

Гребневая регрессия

$(X^\top X + \lambda I)w = X^\top y$: всегда обратима, сжимает веса; лист XGBoost — гребневая регрессия на индикаторе.

Собственные векторы

$Av = \lambda v$: направления без поворота.

Характеристический многочлен

$\lambda^2 - \operatorname{tr}A\,\lambda + \det A = 0$; сумма — след, произведение — определитель; комплексные корни — вращение.

Степени матрицы

$A^k = V\Lambda^kV^{-1}$; побеждает наибольшее $|\lambda|$; Фибоначчи, цепь Маркова, степенной метод, спуск $e_{k+1} = (I - \eta H)e_k$.

Квадратичные формы

Спектральная теорема $A = Q\Lambda Q^\top$; чаша, седло, жёлоб; Сильвестр; $X^\top X \succeq 0$.

Обусловленность и спуск

$\eta < 2/\lambda_{\max}$, шагов $\sim\kappa$; центрирование и стандартизация делают чашу круглой.

SVD и PCA

$A = U\Sigma V^\top$: поворот, растяжение, поворот — для любой матрицы.

Малый ранг

Эккарт — Янг: первые $k$ слагаемых; сжатие, рекомендации, эмбеддинги; осевые структуры — малого ранга.

Ковариация и PCA

Корреляция — косинус центрированных столбцов; главные компоненты — собственные векторы ковариации; PCA ≠ регрессия.

Линейная алгебра бустинга

Прогнозы — точка в $\mathbb R^n$; антиградиент — вектор; дерево — проекция.

Дерево — проекция на ступеньки

Индикаторы листьев ортогональны; лист — среднее; Пифагор: потери падают на $\|h\|^2$.

Выигрыш разбиения

$\sum G_j^2/n_j - G^2/n$; с гессианами и λ — формула XGBoost.

Цепочка проекций

$r_m = (I - \nu P_m)r_{m-1}$; убывание при $\nu < 2$; matching pursuit; ряд Неймана.

Лист Ньютона

Взвешенная проекция рабочих ответов $-g_i/h_i$ с весами $h_i$; λ — гребневая регуляризация.

Индикаторы листьев

Ансамбль — линейная модель на $\Phi$; совместная подгонка листьев; GBDT + LR.

Практика: частые ошибки и советы

  • Путать * и @ в numpy. A * B — поэлементное произведение, A @ B — матричное.
  • Считать $AB = BA$. Произведение матриц некоммутативно; $(AB)^{-1} = B^{-1}A^{-1}$ и $(AB)^\top = B^\top A^\top$ — с обратным порядком.
  • Не следить за размерами. $X$ ($n \times p$) умножается на вектор длины $p$; $X^\top r$ — вектор длины $p$; $XX^\top$ — матрица $n \times n$, а $X^\top X$ — $p \times p$.
  • Обращать матрицу, чтобы решить систему. Надёжнее и быстрее np.linalg.solve; для МНК — np.linalg.lstsq (QR/SVD), а не явное $(X^\top X)^{-1}$.
  • Судить о вырожденности по определителю. $\det$ зависит от масштаба ($\det(0.1 I_{10}) = 10^{-10}$ у прекрасно обусловленной матрицы); смотрите на $\kappa$ (np.linalg.cond).
  • Считать расстояния по нестандартизованным признакам. Признак с большими числами перевешивает остальные; для kNN, кластеризации, SVM и нейросетей признаки стандартизуют.
  • Сравнивать по скалярному произведению без нормировки. Длинные векторы дают большие произведения; для «похожести» используют косинус.
  • Оставлять все индикаторы категорий вместе со сдвигом в линейной модели без регуляризации. Столбцы зависимы, веса не определены.
  • Использовать np.linalg.eig для симметричной матрицы. np.linalg.eigh быстрее, гарантирует вещественные числа (по возрастанию) и ортонормированные векторы.
  • Проверяйте размеры на каждом шаге — половина ошибок в линейной алгебре ловится так.
  • Задача «найти лучшее приближение» почти всегда сводится к проекции: ищите, что должно быть перпендикулярно остатку.
  • Перед градиентными методами (линейные модели, нейросети) стандартизуйте признаки; перед деревьями и бустингом это не нужно.
  • Мультиколлинеарность лечите удалением дублей, регуляризацией или PCA; для интерпретации важностей — группируйте связанные признаки.

Задача 6 ★★★. Остатки $r = (-3, -1, 0, 2, 2)$ у объектов с признаком $x = (1, 2, 3, 4, 5)$. Найдите значения листьев и выигрыш $\|h\|^2$ для порогов 2.5 и 3.5. Какой выберет дерево? Как изменится выигрыш лучшего порога при $\lambda = 2$?

Решение

Порог 2.5: листья $\frac{-4}{2} = -2$ и $\frac{4}{3}$, выигрыш $\frac{16}{2} + \frac{16}{3} \approx 13.33$. Порог 3.5: листья $\frac{-4}{3}$ и $\frac{4}{2} = 2$, выигрыш тоже $\frac{16}{3} + \frac{16}{2} \approx 13.33$ — ничья (сумма остатков 0, и обе стороны получили по $\pm 4$). При $\lambda = 2$: $\frac{16}{4} + \frac{16}{5} = 7.2$ для обоих — снова ничья; дерево возьмёт первый найденный порог.

Итоги

  1. Вектор — стрелка и список чисел; признаки, ответы, прогнозы, остатки и градиенты — векторы, шаг бустинга — сложение векторов.
  2. Линейные комбинации образуют оболочку; независимый набор, порождающий пространство, — базис; прогнозы линейной модели — оболочка столбцов матрицы признаков.
  3. Скалярное произведение $\sum a_ib_i = \|a\|\|b\|\cos\alpha$ даёт длины, углы, расстояния и косинусное сходство; ноль — перпендикулярность; масштаб признаков меняет расстояния, но не деревья.
  4. Проекция — ближайшая точка, остаток перпендикулярен; проекция на $\mathbf 1$ — среднее, то есть лучшая константа.
  5. Нормы L2, L1, L∞ — функции потерь и штрафы; L1-штраф обнуляет веса благодаря углам ромба.
  6. Матрица — таблица данных ($Xw$ — прогнозы) и преобразование (столбцы — образы базиса); произведение — композиция; определитель — масштаб площади; $\det = 0$ — необратимость.
  7. Системы решает метод Гаусса; ранг считает независимые столбцы; обусловленность $\kappa$ показывает, во сколько раз усиливаются ошибки.
  8. МНК — проекция: $X^\top X w = X^\top y$, остаток ⟂ столбцам; больше признаков — меньше ошибка на обучении, но возможно переобучение; гребневая регрессия $(X^\top X + \lambda I)$ лечит вырожденность.
  9. Собственные векторы — направления без поворота; $\lambda^2 - \operatorname{tr}A\,\lambda + \det A = 0$; степени матрицы управляются наибольшим $|\lambda|$; у симметричных матриц оси перпендикулярны, а квадратичная форма — чаша, седло или жёлоб.
  10. Скорость градиентного спуска определяет $\kappa$ гессиана; центрирование и стандартизация делают чашу круглой.
  11. SVD $U\Sigma V^\top$ есть у любой матрицы; первые $k$ слагаемых — лучшее приближение ранга $k$; PCA — собственные векторы ковариационной матрицы.
  12. Бустинг: дерево проецирует антиградиент на ступеньки листьев (лист — среднее), выигрыш — квадрат длины проекции, шаги — цепочка проекций с убыванием при $\nu < 2$, лист Ньютона — взвешенная проекция с гребневым λ, ансамбль — линейная модель на индикаторах листьев.
