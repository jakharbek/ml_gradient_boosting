# Упражнения к уроку 9.3

Решения: [`solutions.py`](solutions.py) — `python lessons/lesson_9_3/exercises/solutions.py`.

## 1. Статистики вручную ★☆☆

Объекты одной категории в порядке случайной перестановки имеют $y = 3, 1, 4, 1, 5$; $a = 1$, $p = 2$.
Посчитайте наивную статистику (одна на всю категорию) и упорядоченную для каждого из пяти объектов.

## 2. Кросс-валидационное кодирование ★★★

Реализуйте кодирование по фолдам: обучающая выборка делится на 5 частей, объект кодируется средним $y$
(со сглаживанием) по остальным четырём частям. Тест кодируется по всей обучающей выборке.
Добавьте этот вариант в сравнение из ноутбука (раздел 1) для информативной категории с $K = 200$ и для шумовой.
