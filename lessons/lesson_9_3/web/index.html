Зачем это нужно

CatBoost (Прохоренкова и соавторы, Яндекс, 2018) построен вокруг одной проблемы — утечки целевой переменной. Она возникает, когда признак объекта вычислен с участием его собственного ответа. Самый частый источник утечки — кодирование категорий средним $y$.

Кодирование категорий средним y

Категорию с сотнями значений (город, модель телефона, ID продавца) неудобно раскрывать в one-hot. Естественная идея — заменить категорию средним $y$ по её объектам (target statistic, TS). С априорным сглаживанием:

$$\hat x_i = \frac{\sum_{j:\, c_j = c_i} y_j + a\,p}{\#\{j: c_j = c_i\} + a},$$

где $p$ — среднее $y$ по всем данным, $a$ — сила сглаживания.

Где утечка

Если посчитать $\hat x_i$ по всей обучающей выборке, в сумму входит и сам $y_i$. У категории из 5 объектов $\hat x_i$ на ~1/6 состоит из собственного ответа. На обучении признак «знает» ответ, на тесте — нет. Модель учится доверять признаку, который на новых данных бесполезен.

Упорядоченные статистики

CatBoost перемешивает объекты в случайном порядке («искусственное время») и кодирует объект только по объектам до него: $\hat x_i = \frac{\sum_{j < i,\, c_j = c_i} y_j + a p}{\#\{j < i: c_j = c_i\} + a}$. Собственный ответ не участвует никогда. Для теста используются все обучающие объекты.

Цена: шум для ранних и редких

Первый объект категории получает просто $p$, второй — среднее по одному соседу, и так далее. Для редких категорий кодировка шумная. Если категория действительно информативна, этот шум стоит качества.

Нет бесплатного обеда. Мы сравнили встроенную обработку категорий CatBoost с наивным кодированием средним (1000 объектов, среднее по трём повторам, ноутбук урока). Категория-шум из 200 значений: встроенная — 0.292 (как без категории), наивное — 0.328, утечка налицо. Информативная категория из 200 значений: встроенная — 0.559, наивное — 0.436, без категории — 1.055. Упорядоченные статистики защищают от утечки, но на редких информативных категориях проигрывают. Универсального рецепта нет: кодирование по фолдам (упражнение 2) тоже убирает утечку (0.306 на шумовой категории), но на редкой информативной так же уступает наивному (0.476 против 0.449). Способ кодирования выбирают по валидации — подробнее в уроке .

Упорядоченный бустинг

Та же утечка есть и в самом бустинге. Остаток $r_i = y_i - F(x_i)$ считается моделью, которая обучалась на $y_i$. Поэтому на обучающих объектах остатки систематически меньше, чем на новых — это сдвиг прогнозов (prediction shift). Упорядоченный бустинг (boosting_type="Ordered") считает остаток объекта по модели, обученной только на объектах до него в перестановке. Чтобы это было выполнимо, CatBoost хранит несколько вспомогательных моделей.

В наших замерах (задача Фридмана, 500 деревьев, ноутбук урока) упорядоченный бустинг помог на 300 объектах (MSE 3.59 против 3.90), но проиграл на 1000 (1.79 против 1.58) и 5000 (1.23 против 1.17) и был в 3–4 раза медленнее. CatBoost 1.2 по умолчанию выбирает Plain.

Симметричные деревья

По умолчанию (grow_policy="SymmetricTree") CatBoost строит симметричные (oblivious) деревья: на каждом уровне все узлы делятся по одному и тому же условию $x_f \le t$. Условие выбирается по сумме выигрышей во всех узлах уровня.

Прогноз — это d сравнений и таблица

Ответы на $d$ условий — это $d$ бит, а номер листа — двоичное число из них. Прогноз не требует обхода дерева: $d$ независимых сравнений и чтение из таблицы $2^d$ значений. Это очень быстро и хорошо векторизуется.

Регуляризация

Одно условие на весь уровень — сильное ограничение: дерево не может подстроиться под отдельный угол пространства. Одно такое дерево приближает данные хуже обычного, но в бустинге это работает как регуляризация. В ноутбуке урока бустинг на симметричных деревьях на задаче Фридмана дал лучшую ½MSE 0.72 против 0.95 у обычных деревьев той же глубины (глубина 3; при глубине 5 — 0.75 против 1.09). На одномерной волне и на спирали разницы не было. В самом CatBoost на тех же данных (500 деревьев, глубина 5): SymmetricTree — MSE 1.34, Depthwise — 1.74, Lossguide — 1.75.

Другие режимы

grow_policy="Depthwise" — обычный рост по уровням, "Lossguide" — по листьям, как в LightGBM (урок ).

В коде

CatBoost не собран для Python в браузере, поэтому код ниже — для Jupyter (он же есть в ноутбуке урока).

import catboost as cb
import pandas as pd

df = pd.DataFrame({"x": x, "город": city})           # категория — строки
model = cb.CatBoostRegressor(iterations=300, learning_rate=0.1, depth=4, verbose=0)
model.fit(df, y, cat_features=["город"])            # упорядоченные статистики внутри
print(model.get_all_params()["grow_policy"])        # SymmetricTree
print(model.get_feature_importance(prettified=True))

Итоги

  1. Кодирование категории средним $y$ по всей выборке — утечка: признак содержит ответ.
  2. Упорядоченные статистики убирают утечку, но шумят для редких категорий; на информативных редких категориях они могут проиграть.
  3. Упорядоченный бустинг лечит сдвиг прогнозов; в наших замерах он помог только на очень малых данных.
  4. Симметричные деревья: один сплит на уровень, быстрый прогноз, сильная регуляризация.
