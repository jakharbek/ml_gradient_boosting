# Данные урока 1.2

Все наборы детерминированы: их можно пересоздать в Python или получить в веб-уроке
с теми же параметрами (генератор Mulberry32 одинаков в JS и Python).

## `prices_with_outlier.csv` — Линейные данные с выбросами

Прямая с шумом и 10% выбросов — для сравнения среднего и медианы в примере mean_vs_median.py.

- Столбцы: `x`, `y`; строк: 30.
- Как получить в Python: `datasets.regression_1d(kind='linear', n=30, noise=0.8, seed=5, outliers=0.1)`

## `sine_outliers.csv` — Синус с двумя выбросами

Данные виджета «Чему учится первое дерево бустинга»: псевдо-остатки разных потерь.

- Столбцы: `x`, `y`; строк: 30.
- Как получить в Python: `datasets.regression_1d(kind='sine', n=30, noise=0.25, seed=4, outliers=0.1)`
