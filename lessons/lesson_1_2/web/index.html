Зачем это нужно

«Хорошая модель» — это модель с маленькой ошибкой. Но ошибку можно мерить по-разному, и от выбора меры зависит, какую модель мы получим.

Для бустинга функция потерь — не просто оценка качества, а руль: из неё берутся стартовая константа $F_0$, остатки, на которых учатся деревья, и значения в листьях. Поменяйте потери — и тот же алгоритм начнёт предсказывать медиану вместо среднего или 90-й процентиль вместо «типичного» значения.

Функция потерь и эмпирический риск

Функция потерь $L(y, F)$ говорит, насколько плох прогноз $F$, если правильный ответ $y$. Для регрессии она обычно зависит от остатка $r = y - F$.

Качество модели на выборке — средние потери, эмпирический риск:

$$R(F) = \frac{1}{n} \sum_{i=1}^{n} L\big(y_i,\ F(x_i)\big)$$

Обучение из урока — это минимизация $R$ по параметрам модели. Четыре главные функции потерь для регрессии:

Потери$L(y, F)$, где $r = y - F$Смысл
Квадратичные (L2, MSE)$\tfrac12 r^2$большие ошибки штрафуются квадратично
Абсолютные (L1, MAE)$|r|$все ошибки — пропорционально величине
Хьюбера$\tfrac12 r^2$ при $|r|\le\delta$, иначе $\delta(|r| - \tfrac12\delta)$L2 для малых ошибок, L1 для больших
Квантильные (pinball)$\alpha r$ при $r \ge 0$, иначе $(\alpha-1) r$недопрогноз и перепрогноз стоят по-разному

Множитель ½ в квадратичных потерях — только для удобства: производная $\tfrac12 r^2$ по $F$ равна $-(y-F)$, то есть ровно остатку со знаком минус. В урочной MSE множителя нет — отличается лишь масштаб.

Лучшая константа

Самая простая модель — одно число $c$ для всех объектов. Какое $c$ лучшее? Зависит от потерь! Именно эта константа станет стартом бустинга $F_0$.

$$c^{*} = \arg\min_{c} \sum_{i=1}^{n} L(y_i, c)$$

В виджете точки — ответы $y_i$. Кривая внизу — суммарные потери как функция $c$. Перетащите точку далеко вверх и сравните, как реагируют среднее и медиана.

Почему именно среднее и медиана

Шаг 1. Квадратичные потери → среднее

Минимум гладкой функции — там, где производная равна нулю:

$$\frac{d}{dc}\sum_i \tfrac12 (y_i - c)^2 = -\sum_i (y_i - c) = 0 \;\Rightarrow\; n c = \sum_i y_i \;\Rightarrow\; c^{*} = \bar y$$

Сумма остатков относительно среднего равна нулю: положительные и отрицательные ошибки уравновешены по величине.

Шаг 2. Абсолютные потери → медиана

Производная $|y_i - c|$ по $c$ равна $+1$, если $c > y_i$, и $-1$, если $c < y_i$. Сумма производных:

$$\frac{d}{dc}\sum_i |y_i - c| = \#\{y_i < c\} - \#\{y_i > c\}$$

Она равна нулю, когда точек слева и справа поровну — это медиана. Здесь важен только счёт точек, а не их удалённость. Поэтому выброс, улетевший на +100, сдвигает медиану не сильнее, чем на +1.

Шаг 3. Квантильные потери → квантиль

Каждая точка выше $c$ тянет вверх с силой $\alpha$, каждая ниже — вниз с силой $1-\alpha$:

$$\frac{d}{dc}\sum_i L_\alpha = -\alpha\,\#\{y_i > c\} + (1-\alpha)\,\#\{y_i < c\} = 0$$

Равновесие наступает, когда доля точек ниже $c$ равна $\alpha$: это α-квантиль. При $\alpha = 0.5$ — снова медиана.

Шаг 4. Что это значит для бустинга

Бустинг начинает с лучшей константы: $F_0 = \bar y$ для L2, $F_0 = \mathrm{median}(y)$ для L1 и Хьюбера, квантиль для квантильных потерь, а для классификации — логарифм шансов (урок ). И в каждом листе дерева позже решается та же задача: какую константу прибавить к объектам этого листа (урок ).

Остаток $r = y - F$

Знак говорит о направлении ошибки: $r > 0$ — модель занизила прогноз, $r < 0$ — завысила.

Штраф за остаток

Функция $L$ превращает остаток в «стоимость». Форма функции решает, насколько дорого стоят большие ошибки по сравнению с маленькими.

Как потеря управляет обучением
Градиент потери

Производная $\partial L/\partial F$ показывает, куда и насколько сильно сдвигать прогноз. У L2 она растёт с ошибкой, у L1 — постоянна по модулю.

Псевдо-остатки

Антиградиент $-\partial L/\partial F$ — то, чему учится каждое дерево бустинга.

Выбор потерь в бустинге

Устойчивость к выбросам, предсказание квантилей и интервалов.

Потери и метрики — не одно и то же

Потеря — то, что оптимизирует алгоритм (должна быть дифференцируемой или почти). Метрика — то, чем отчитываемся (может быть любой: точность, R², бизнес-прибыль). Хорошо, когда они согласованы.

В коде

import numpy as np
from gbcourse import get_loss

y = np.array([3.1, 3.4, 3.9, 4.2, 4.4, 5.0, 5.3, 6.1])
for outlier in (None, 40.0):
    yy = y if outlier is None else np.append(y, outlier)
    print("выброс:", outlier)
    for name, kw in [("squared", {}), ("absolute", {}), ("huber", {"delta": 1.0}), ("quantile", {"alpha": 0.9})]:
        loss = get_loss(name, **kw)
        print(f"   {name:9s} F0 = {loss.init(yy):7.3f}")

Обратите внимание: у Хьюбера в gbcourse стартовая константа — медиана (так же делает scikit-learn), а оптимум в листьях считается специальным шагом Фридмана.

Итоги

  1. Потеря $L(y,F)$ задаёт цену ошибки; обучение минимизирует средние потери.
  2. L2 сильно штрафует большие ошибки и чувствительна к выбросам; L1 — устойчива; Хьюбер — компромисс; квантильная — несимметрична.
  3. Лучшая константа: среднее (L2), медиана (L1), α-квантиль (квантильная).
  4. Эта константа — старт бустинга $F_0$; та же задача решается потом в каждом листе.
