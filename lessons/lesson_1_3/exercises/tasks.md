# Упражнения к уроку 1.3

Решения: [`solutions.py`](solutions.py) — `python lessons/lesson_1_3/exercises/solutions.py`.

## 1. Граница устойчивости ★☆☆

Для $f(\theta) = \tfrac{a}{2}\theta^2$ выведите, при каких η градиентный спуск сходится.
Проверьте численно при a = 3 для η = 0.6, 0.66, 0.67, 0.7.

## 2. Цена зигзага ★★☆

В задаче о прямой (данные `datasets.regression_1d(kind="linear", n=30, noise=0.6, seed=3)`)
посчитайте, сколько шагов спуска с η = 0.02 нужно, чтобы MSE превышала оптимум меньше чем на 1e-4 —
для исходного и для центрированного x.

## 3. Затухающий темп для |θ| ★★☆

Спуск по $|\theta|$ с постоянным η «дребезжит» около нуля. Реализуйте темп $\eta_k = \eta_0/(1 + k/10)$
и сравните |θ| после 200 шагов при постоянном и затухающем темпе (η₀ = 0.3, θ₀ = 2.05).

## 4. Спуск для константы ★☆☆

Покажите, что спуск $c \leftarrow c + \eta\,\overline{(y - c)}$ при η = 1 находит среднее за один шаг,
а при η = 0.5 остаток до среднего каждый шаг уменьшается вдвое.
