# Упражнения к уроку 1.3

Решения: [`solutions.py`](solutions.py) — `python lessons/lesson_1_3/exercises/solutions.py`.

Задачи идут от простого к сложному. Сначала решайте на листке, потом проверяйте кодом.

## 1. Три шага руками ★☆☆

$f(\theta) = (\theta - 3)^2$, $\theta_0 = 0$, $\eta = 0.25$. Найдите $\theta_1, \theta_2, \theta_3$ и множитель,
на который уменьшается расстояние до минимума за шаг.

## 2. Граница устойчивости ★☆☆

Для $f(\theta) = \tfrac{a}{2}\theta^2$ выведите, при каких η градиентный спуск сходится.
Проверьте численно при a = 3 для η = 0.6, 0.66, 0.67, 0.7.

## 3. Спуск для константы ★☆☆

Покажите, что спуск $c \leftarrow c + \eta\,\overline{(y - c)}$ при η = 1 находит среднее за один шаг,
а при η = 0.5 остаток до среднего каждый шаг уменьшается вдвое.

## 4. Производная Хьюбера численно ★★☆

Для потерь Хьюбера с $\delta = 1$ и $y = 5$ посчитайте $\partial L/\partial F$ формулой и центральными конечными
разностями в точках $F = 4.5$, $F = 2$ и $F = 6.8$.

## 5. Цена зигзага ★★☆

В задаче о прямой (данные `datasets.regression_1d(kind="linear", n=30, noise=0.6, seed=3)`)
посчитайте, сколько шагов спуска с η = 0.02 нужно, чтобы ½·MSE превышала оптимум меньше чем на 1e-4 —
для исходного и для центрированного x.

## 6. Затухающий темп для |θ| ★★☆

Спуск по $|\theta|$ с постоянным η «дребезжит» около нуля. Реализуйте темп $\eta_k = \eta_0/(1 + k/10)$
и сравните |θ| после 200 шагов при постоянном и затухающем темпе (η₀ = 0.3, θ₀ = 2.05).

## 7. Ньютон для редкого класса ★★★

Из 100 клиентов 10 не вернули кредит. Найдите минимум log-loss по логиту тремя способами, стартуя с $F = 0$:
спуском с $\eta = 1$, спуском с темпом $\eta = 1/f''(0)$ и шагом Ньютона. Сколько шагов нужно каждому, чтобы
ошибка стала меньше $10^{-6}$? Почему спуск с фиксированным темпом $1/f''(0)$ хуже Ньютона, хотя совпадает с ним
на первом шаге?
