# Урок 1.3. Производная, градиент и градиентный спуск

> Всё, что нужно для слова «градиентный»: наклон функции, шаг против градиента и цена слишком большого шага

**Модуль:** [1. Введение: что такое градиентный бустинг](../lesson_1/README.md) · **Уровень:** Начальный · **Время:** ~45 мин

**Нужно знать:** [1.2 Функции потерь и лучшая константа](../lesson_1_2/README.md)

Производная как наклон, градиент как направление быстрейшего роста, градиентный спуск и роль длины шага, шаг Ньютона со второй производной.

## После урока вы сможете

- объяснить производную как наклон касательной и градиент как вектор частных производных
- выполнить несколько шагов градиентного спуска вручную и объяснить роль темпа обучения
- распознать расходимость и «зигзаг» при неудачном шаге
- понимать шаг Ньютона $-f'/f''$ — основу XGBoost

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_1_3/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
