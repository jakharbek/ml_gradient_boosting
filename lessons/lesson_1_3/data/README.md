# Данные урока 1.3

Все наборы детерминированы: их можно пересоздать в Python или получить в веб-уроке
с теми же параметрами (генератор Mulberry32 одинаков в JS и Python).

## `line_fit.csv` — Точки для подгонки прямой

На этих данных в виджете 2D-спуска (шаг 12) подбираются наклон и сдвиг прямой — с признаком как есть, центрированным и стандартизованным, — а в виджете стохастического спуска (шаг 13) те же параметры по мини-пакетам.

- Столбцы: `x`, `y`; строк: 30.
- Как получить в Python: `datasets.regression_1d(kind='linear', n=30, noise=0.6, seed=3)`

## `wave_12.csv` — Волна с трендом: 12 точек

Обучающие точки виджета «Спуск по прогнозам» (шаг 14); новые точки — тот же генератор с n=200, seed=103.

- Столбцы: `x`, `y`; строк: 12.
- Как получить в Python: `datasets.regression_1d(kind='wave', n=12, noise=0.3, seed=3)`
