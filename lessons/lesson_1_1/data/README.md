# Данные урока 1.1

Все наборы детерминированы: их можно пересоздать в Python или получить в веб-уроке
с теми же параметрами (генератор Mulberry32 одинаков в JS и Python).

## `wave_40.csv` — Волна с трендом: 40 точек

Данные виджетов «Откуда берутся данные», «Подберите модель руками» и «Обобщение» (обучающие точки).

- Столбцы: `x`, `y`; строк: 40.
- Как получить в Python: `datasets.regression_1d(kind='wave', n=40, noise=0.4, seed=11)`

## `wave_50.csv` — Волна с трендом: 50 точек для обучения и теста

Данные виджета «Обучение и тест»: их делят на обучение и тест 30 разными способами (datasets.train_test_split с seed = 0…29).

- Столбцы: `x`, `y`; строк: 50.
- Как получить в Python: `datasets.regression_1d(kind='wave', n=50, noise=0.5, seed=21)`
