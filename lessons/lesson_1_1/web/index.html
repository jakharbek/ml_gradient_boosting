Зачем это нужно

Градиентный бустинг — метод обучения с учителем. Прежде чем разбирать его, договоримся о словах: что мы даём алгоритму, что получаем и что значит «модель обучилась».

Эти понятия будут встречаться в каждом уроке. Если они уже знакомы, пролистайте до виджета — он показывает главную мысль урока: обучение — это подбор параметров, при которых ошибка минимальна.

Данные: объекты, признаки, ответы

Пусть мы хотим оценивать стоимость квартир. Каждая строка таблицы — объект (квартира). Столбцы — признаки (features): площадь, этаж, район. Последний столбец — целевая переменная (target) — то, что хотим предсказывать.

$$\text{объект } i:\quad x_i = (x_{i1}, \dots, x_{id}) \in \mathbb{R}^d, \qquad y_i \text{ — ответ}, \qquad \text{выборка } \{(x_i, y_i)\}_{i=1}^{n}$$

Здесь $n$ — число объектов, $d$ — число признаков. «С учителем» — потому что для обучающих объектов правильные ответы $y_i$ известны: «учитель» их подсказал.

Регрессия: ответ — число

Цена, спрос, температура, время доставки. Ошибка — насколько прогноз далёк от ответа. Бустинг для регрессии разбираем в модулях 4 и 5.

Классификация: ответ — класс

Вернёт ли клиент кредит (да/нет), что на картинке (кошка/собака/птица). Модель обычно выдаёт вероятность каждого класса.

Бинарная: два класса

Ответ кодируют числами 0 и 1; модель предсказывает $p = P(y = 1 \mid x)$.

Многоклассовая: K классов

Модель выдаёт K вероятностей, в сумме равных 1.

Ранжирование: ответ — порядок

Поисковая выдача, рекомендации: важны не сами числа, а правильный порядок объектов.

Типы признаков
Числовые

Площадь, возраст. Деревьям важен только их порядок — поэтому бустингу не нужно их масштабировать.

Категориальные

Район, марка машины. Их нужно превратить в числа — это отдельное искусство.

Пропуски

Значение неизвестно. Современные библиотеки бустинга умеют обрабатывать их сами.

Модель — это функция с параметрами

Модель — правило, которое по признакам выдаёт прогноз: $\hat y = F(x)$. Обычно это семейство функций с настраиваемыми числами — параметрами $\theta$:

$$\hat y = F(x;\ \theta)$$

Константа

$F(x) = c$. Один параметр $c$. Игнорирует признаки — но с неё начинается бустинг.

Прямая

$F(x) = a x + b$. Два параметра. Хороша, если зависимость линейна.

Ступенька (пень)

$F(x) = c_1$ при $x \le t$, иначе $c_2$. Три параметра: порог $t$ и два уровня. Это простейшее дерево решений.

Бустинг

$F(x) = F_0 + \nu \sum_m h_m(x)$ — сумма сотен ступенек. Параметров тысячи, их подбирает алгоритм.

Параметры модель подбирает сама при обучении (уровни и пороги деревьев). Гиперпараметры задаёт человек до обучения: число деревьев, глубина, темп обучения. Настройке гиперпараметров посвящён модуль 11.

Обучение = подбор параметров по ошибке

Как понять, что параметры хорошие? Посчитать, насколько прогнозы отличаются от ответов на обучающих объектах. Самая популярная мера — среднеквадратичная ошибка (MSE):

$$\mathrm{MSE}(\theta) = \frac{1}{n} \sum_{i=1}^{n} \big(y_i - F(x_i;\theta)\big)^2$$

Попробуйте сами: подберите параметры трёх моделей так, чтобы MSE стала минимальной. Потом нажмите «Найти лучшие параметры» — компьютер решит ту же задачу точно.

Вы только что сделали то, что делает любой алгоритм машинного обучения: крутили параметры, глядя на ошибку. Алгоритмы делают это автоматически — перебором (как дерево ищет порог, урок ) или спуском по градиенту (урок ).

Заметьте: чем гибче модель, тем меньше её лучшая MSE на обучении. Значит ли это, что гибкая модель всегда лучше? Нет — и в этом главный подвох машинного обучения.

Обучение и тест: честная оценка

Нас интересует качество на новых объектах, которых модель не видела. Поэтому данные делят на части:

  • обучающая выборка (train) — по ней подбираются параметры;
  • тестовая выборка (test) — откладывается и используется один раз, в конце, для честной оценки;
  • часто ещё валидационная (validation) — для выбора гиперпараметров и ранней остановки.

Ошибка на обучении почти всегда оптимистична. Модель, которая запомнила обучающие ответы, может ошибаться на новых данных сильнее простой константы. Этот эффект — переобучение — разбираем в уроке .

В коде

Разделим данные на обучение и тест и сравним три модели: константу, прямую и дерево. Код выполняется в браузере.

import numpy as np
from gbcourse import datasets, RegressionTree
from gbcourse.metrics import mse

X, y = datasets.regression_1d(kind="wave", n=200, noise=0.4, seed=11)
X_tr, X_te, y_tr, y_te = datasets.train_test_split(X, y, test_size=0.3, seed=0)

# 1) константа: лучший прогноз без признаков — среднее
c = y_tr.mean()
# 2) прямая: метод наименьших квадратов
a, b = np.polyfit(X_tr[:, 0], y_tr, deg=1)
# 3) дерево глубины 3 (g = −y, h = 1 → в листьях средние)
tree = RegressionTree(max_depth=3).fit(X_tr, -y_tr)

for name, pred_tr, pred_te in [
    ("константа", np.full_like(y_tr, c), np.full_like(y_te, c)),
    ("прямая", a * X_tr[:, 0] + b, a * X_te[:, 0] + b),
    ("дерево", tree.predict(X_tr), tree.predict(X_te)),
]:
    print(f"{name:10s}  MSE обучение = {mse(y_tr, pred_tr):.3f}   тест = {mse(y_te, pred_te):.3f}")

Итоги

  1. Данные — объекты с признаками $x$ и ответами $y$. Регрессия предсказывает число, классификация — класс.
  2. Модель — функция $F(x;\theta)$; параметры $\theta$ подбирает алгоритм, гиперпараметры — человек.
  3. Обучить модель = найти параметры, минимизирующие ошибку на обучающих данных.
  4. Качество оценивают на отложенных данных: ошибка на обучении оптимистична.
