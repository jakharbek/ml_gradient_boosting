# Урок 3.3. Аддитивные модели и пошаговое построение

> Бустинг как жадная минимизация потерь по одному слагаемому — и главный вопрос, ответ на который называется градиентным бустингом

**Модуль:** [3. Ансамбли: сила многих слабых моделей](../lesson_3/README.md) · **Уровень:** Средний · **Время:** ~45 мин

**Нужно знать:** [3.2 AdaBoost: бустинг через веса объектов](../lesson_3_2/README.md), [1.2 Функции потерь и лучшая константа](../lesson_1_2/README.md)

Аддитивная модель и прямое пошаговое построение (FSAM); с квадратичными потерями это обучение на остатках, с экспоненциальными — ровно AdaBoost; потери через отступ; почему для произвольных потерь нужен градиент.

## После урока вы сможете

- записать аддитивную модель и шаг прямого пошагового построения
- вывести, что пошаговая минимизация квадратичных потерь = обучение на остатках
- вывести AdaBoost из экспоненциальных потерь
- сравнить потери через отступ yF и объяснить, зачем нужен градиентный подход
