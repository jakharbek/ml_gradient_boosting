Зачем это нужно

AdaBoost придумали как алгоритм с весами. Через пять лет Фридман, Хасти и Тибширани (2000) увидели в нём другое: жадную минимизацию функции потерь, по одному слагаемому за шаг.

Этот взгляд открыл дверь: раз бустинг минимизирует потери, их можно заменить на любые другие. Надо лишь понять, как делать шаг для произвольной функции потерь. Ответ — градиентный бустинг, и этот урок подводит к нему вплотную.

Аддитивная модель

Модель, собранная из простых кирпичиков с коэффициентами, называется аддитивной:

$$F_M(x) = \sum_{m=1}^{M} \beta_m\, b(x;\ \gamma_m)$$
$b(x;\gamma)$
базовая функция с параметрами $\gamma$ — например, дерево (пороги и значения листьев)
$\beta_m$
коэффициент при $m$-й функции

Подбирать все $\beta_m, \gamma_m$ одновременно слишком сложно. Поэтому поступают жадно.

Прямое пошаговое построение (FSAM)

$$(\beta_m, \gamma_m) = \arg\min_{\beta, \gamma} \sum_{i=1}^{n} L\big(y_i,\; F_{m-1}(x_i) + \beta\, b(x_i; \gamma)\big), \qquad F_m = F_{m-1} + \beta_m b(\cdot; \gamma_m)$$

Уже добавленные слагаемые не трогаем, на каждом шаге подбираем лучшее новое. Это Forward Stagewise Additive Modeling. Посмотрим, во что оно превращается при разных потерях.

Квадратичные потери → обучение на остатках

$$L\big(y_i, F_{m-1}(x_i) + \beta b(x_i)\big) = \big(\underbrace{y_i - F_{m-1}(x_i)}_{r_{im}} - \beta b(x_i)\big)^2$$

Шаг FSAM — просто подогнать новое слагаемое к остаткам $r_{im}$ методом наименьших квадратов. Это ровно «бустинг на остатках» из модуля 4.

Экспоненциальные потери → AdaBoost (1)

Классы $y \in \{-1, +1\}$, потери $L(y, F) = e^{-yF}$. Вынесем то, что не зависит от нового слагаемого:

$$\sum_i e^{-y_i (F_{m-1}(x_i) + \beta b(x_i))} = \sum_i \underbrace{e^{-y_i F_{m-1}(x_i)}}_{w_i^{(m)}}\, e^{-\beta y_i b(x_i)}$$

Вот и веса объектов AdaBoost! Вес — это экспоненциальная потеря объекта на текущем ансамбле.

Экспоненциальные потери → AdaBoost (2)

Для $b(x) \in \{-1, +1\}$: $e^{-\beta y b} = e^{-\beta}$ при верном ответе и $e^{\beta}$ при ошибке. Значит:

$$\sum_i w_i e^{-\beta y_i b(x_i)} = e^{-\beta}\sum_i w_i + (e^{\beta} - e^{-\beta}) \sum_i w_i [b(x_i) \ne y_i]$$

При любом $\beta > 0$ лучшая $b$ минимизирует взвешенную ошибку — это шаг 1 AdaBoost.

Экспоненциальные потери → AdaBoost (3)

Производная по $\beta$ равна нулю при

$$\beta_m = \frac12 \ln\frac{1 - \varepsilon_m}{\varepsilon_m}$$

— в точности $\alpha_m$ AdaBoost. А новые веса $w^{(m+1)}_i = w^{(m)}_i e^{-\beta_m y_i b_m(x_i)}$ — шаг 3. AdaBoost = FSAM с экспоненциальными потерями.

А если потери другие?

Для L2 и экспоненциальных потерь шаг FSAM решается явно. Для абсолютных, Хьюбера, логистических, своих бизнес-потерь — нет: задача $\arg\min_{\beta,\gamma}$ по деревьям в общем случае неразрешима. Нужен универсальный способ сделать хороший шаг. Фридман (2001) предложил: шагать по антиградиенту. Об этом — модуль 5.

Потери через отступ

В бинарной классификации удобно смотреть на отступ (margin) $yF(x)$: положительный — верный ответ, и чем он больше, тем увереннее; отрицательный — ошибка.

Экспоненциальные $e^{-yF}$

При уверенной ошибке растут экспоненциально — отсюда взрыв весов испорченных меток в AdaBoost.

Логистические $\log(1 + e^{-2yF})$

При ошибке растут лишь линейно: один испорченный объект не может перетянуть на себя всю модель. Это log-loss, основа классификации в градиентном бустинге (урок ).

Не принимайте теорию на веру. В коде ниже градиентный бустинг с маленьким темпом и неглубокими деревьями обучается с обеими потерями при разной доле испорченных меток. На этих данных разница оказывается небольшой: маленький шаг и ограниченное число деревьев сами сдерживают разгон. Взрыв весов опасен прежде всего в классическом AdaBoost с полным шагом. Главные доводы за log-loss — корректные вероятности и связь с правдоподобием.

Минимум ожидаемых экспоненциальных и логистических потерь достигается в одной и той же точке $F^*(x) = \tfrac12 \ln\frac{P(y=1|x)}{P(y=-1|x)}$ — половине логарифма шансов. Поэтому обе дают согласованные вероятности; различаются они поведением на ошибках.

В коде

import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from gbcourse import datasets, Mulberry32

X, y = datasets.classification_2d(kind="moons", n=600, noise=0.25, seed=33)
X_tr, X_te, y_tr, y_te = datasets.train_test_split(X, y, test_size=0.4, seed=0)
rng = Mulberry32(1)
for frac in (0.0, 0.1, 0.2):
    flip = np.array([rng.random() < frac for _ in y_tr])
    yy = np.where(flip, 1 - y_tr, y_tr)
    acc = {}
    for loss in ("exponential", "log_loss"):
        m = GradientBoostingClassifier(loss=loss, n_estimators=300, learning_rate=0.1, max_depth=2).fit(X_tr, yy)
        acc[loss] = m.score(X_te, y_te)
    print(f"шум {frac:.0%}: экспоненциальные {acc['exponential']:.3f}, логистические {acc['log_loss']:.3f}")

Итоги

  1. Бустинг строит аддитивную модель жадно: по одному слагаемому, минимизируя потери.
  2. С квадратичными потерями шаг — подгонка к остаткам; с экспоненциальными — ровно AdaBoost.
  3. Экспоненциальные потери взрываются на ошибках, логистические растут линейно.
  4. Для произвольных потерь шаг FSAM неразрешим явно — нужен градиент. Это и есть градиентный бустинг.
