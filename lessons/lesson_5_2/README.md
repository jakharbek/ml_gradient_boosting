# Урок 5.2. Алгоритм Фридмана (GBM/TreeBoost) по строчкам

> Каноническая формулировка градиентного бустинга 2001 года: откуда в ней каждая строка и почему значения листьев считаются отдельно от структуры дерева

**Модуль:** [5. Бустинг как градиентный спуск в пространстве функций](../lesson_5/README.md) · **Уровень:** Продвинутый · **Время:** ~50 мин

**Нужно знать:** [5.1 Функциональный градиент и псевдо-остатки](../lesson_5_1/README.md)

Общий Gradient_Boost с линейным поиском шага, специализация TreeBoost с оптимальным значением каждого листа, shrinkage; значения листьев для L2, L1, Хьюбера, квантилей и log-loss; сравнение «среднего псевдо-остатков» и линейного поиска.

## После урока вы сможете

- прочитать и воспроизвести алгоритм Gradient_Boost и TreeBoost Фридмана
- объяснить, зачем значения листьев пересчитываются линейным поиском
- вывести значения листьев для L2 (среднее), L1 (медиана), квантильных (квантиль)
- сопоставить строки алгоритма с кодом gbcourse и scikit-learn
