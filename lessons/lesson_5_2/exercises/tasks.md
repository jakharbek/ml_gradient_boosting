## 1. Один шаг на всё дерево ★★☆

Реализуйте Gradient_Boost (алгоритм 1) для L1: дерево по знакам остатков, затем **один** множитель
$\rho_m = \arg\min_\rho \sum|y_i - F_{m-1}(x_i) - \rho h(x_i)|$ (найдите перебором). Сравните MAE на тесте с TreeBoost.

## 2. Лист для Пуассона ★★☆

Выведите $\gamma = \arg\min_\gamma \sum_{i\in R}\big(e^{F_i + \gamma} - y_i(F_i + \gamma)\big)$ и сравните с
`get_loss("poisson").leaf_value`.
