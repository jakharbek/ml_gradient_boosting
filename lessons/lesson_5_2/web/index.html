Зачем это нужно

Статья Джерома Фридмана «Greedy Function Approximation: A Gradient Boosting Machine» (2001) — первоисточник градиентного бустинга. Её алгоритм до сих пор лежит в основе GradientBoostingRegressor из scikit-learn и, с модификациями, всех современных библиотек.

В уроке мы вывели направление шага. Здесь соберём полный алгоритм и разберём тонкость, которую легко пропустить: дерево строится по псевдо-остаткам, а значения его листьев — по исходным потерям.

Алгоритм 1. Gradient_Boost

$$\begin{aligned} &1.\ F_0(x) = \arg\min_\rho \textstyle\sum_{i=1}^n L(y_i, \rho) \\ &2.\ \text{для } m = 1, \dots, M: \\ &3.\quad \tilde y_i = -\Big[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\Big]_{F = F_{m-1}},\ i = 1..n \\ &4.\quad \mathbf a_m = \arg\min_{\mathbf a, \beta} \textstyle\sum_i \big(\tilde y_i - \beta\, h(x_i; \mathbf a)\big)^2 \\ &5.\quad \rho_m = \arg\min_\rho \textstyle\sum_i L\big(y_i,\ F_{m-1}(x_i) + \rho\, h(x_i; \mathbf a_m)\big) \\ &6.\quad F_m(x) = F_{m-1}(x) + \rho_m\, h(x; \mathbf a_m) \end{aligned}$$

Строка 1. Старт — лучшая константа

Для L2 — среднее, для L1 — медиана, для log-loss — логарифм шансов (урок ). Это самая первая «модель».

Строка 3. Псевдо-остатки

Антиградиент потерь в текущих прогнозах (урок ). Считается независимо для каждого объекта.

Строка 4. Базовая функция по наименьшим квадратам

Какой бы ни была $L$, базовый ученик подгоняется к псевдо-остаткам квадратичной ошибкой. Это удобно: для деревьев есть быстрый алгоритм (модуль 2), и он один для всех потерь.

Строка 5. Линейный поиск

Направление найдено, теперь — длина шага, оптимальная уже для исходных потерь $L$. Это одномерная задача, решаемая аналитически или численно.

Строка 6. Шаг

Модель пополняется новым слагаемым. На практике добавляют множитель ν (shrinkage): $F_m = F_{m-1} + \nu \rho_m h_m$ — урок .

Алгоритм 2. TreeBoost: свой шаг в каждом листе

Если базовый ученик — дерево с листьями $R_{1m}, \dots, R_{Jm}$, то один общий множитель $\rho_m$ — слишком грубо. Дерево само по себе — сумма $J$ индикаторов, и каждому можно подобрать свой коэффициент:

$$\gamma_{jm} = \arg\min_\gamma \sum_{x_i \in R_{jm}} L\big(y_i,\ F_{m-1}(x_i) + \gamma\big), \qquad F_m(x) = F_{m-1}(x) + \nu \sum_{j=1}^{J} \gamma_{jm}\,[x \in R_{jm}]$$

Задача для каждого листа — та самая «лучшая константа», только для остатков $y_i - F_{m-1}(x_i)$ объектов листа:

Потери$\gamma_{jm}$ — значение листа
L2среднее остатков в листе (= среднее псевдо-остатков, пересчёт не нужен)
L1медиана остатков $y_i - F_{m-1}(x_i)$ в листе
Квантильные (α)α-квантиль остатков в листе
Хьюбер$\tilde r + \frac{1}{n_j}\sum \operatorname{sign}(r_i - \tilde r)\min(\delta, |r_i - \tilde r|)$, $\tilde r$ — медиана (приближённый шаг Фридмана)
Log-lossодин шаг Ньютона: $\sum r_i / \sum p_i(1-p_i)$ (урок )

Для L1 псевдо-остатки — это ±1, и их среднее в листе — число между −1 и 1, никак не связанное с реальным размером ошибки. Медиана же настоящих остатков сдвигает прогноз ровно на «типичную» ошибку листа. Структура дерева говорит где исправлять, линейный поиск — насколько.

Разбор по косточкам

Структура: разбиения по псевдо-остаткам

Разбиения выбираются критерием наименьших квадратов для $\tilde y$ — одинаково для любых потерь.

Значения: оптимум исходных потерь в каждом листе
Лучшая константа

Та же задача, что и для $F_0$, но для остатков объектов листа.

Альтернатива — шаг Ньютона для всего дерева

XGBoost сразу строит дерево по $g$ и $h$, и значение листа $-G/(H+\lambda)$ получается «бесплатно». Структура и значения там согласованы.

Где это в коде

gbcourse/boosting.py: построение дерева в fit, пересчёт листьев в _line_search; в scikit-learn — _update_terminal_regions.

В коде

import numpy as np
from gbcourse import datasets, RegressionTree

X, y = datasets.regression_1d(kind="wave", n=300, noise=0.3, seed=53, outliers=0.1)
X_tr, X_te, y_tr, y_te = datasets.train_test_split(X, y, test_size=0.3, seed=0)

def boost_l1(line_search, M=200, nu=0.1):
    F, F_te = np.full(len(y_tr), np.median(y_tr)), np.full(len(y_te), np.median(y_tr))
    for m in range(M):
        r = np.sign(y_tr - F)                                    # псевдо-остатки L1
        tree = RegressionTree(max_depth=2).fit(X_tr, -r)         # структура по ним
        if line_search:                                          # значения листьев — медианы остатков
            for leaf in tree.leaves:
                leaf.value = np.median(y_tr[leaf.rows] - F[leaf.rows])
            tree.refresh_values()
        F += nu * tree.predict(X_tr)
        F_te += nu * tree.predict(X_te)
    return np.mean(np.abs(y_te - F_te))

print("MAE на тесте, листья = среднее знаков:   ", round(boost_l1(False), 4))
print("MAE на тесте, листья = медиана остатков: ", round(boost_l1(True), 4))

Итоги

  1. Gradient_Boost: псевдо-остатки → базовая функция по наименьшим квадратам → линейный поиск шага → обновление.
  2. TreeBoost: для каждого листа свой оптимальный шаг $\gamma_{jm}$ — лучшая константа исходных потерь в листе.
  3. Для L2 пересчёт не нужен, для L1 — медиана, для квантилей — квантиль, для log-loss — шаг Ньютона.
