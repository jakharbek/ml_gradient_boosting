# Урок 5.1. Функциональный градиент и псевдо-остатки

> Прогнозы на обучающих объектах — это вектор параметров. Градиент по нему указывает, куда двигаться, а дерево превращает этот шаг в функцию, которая работает и на новых данных

**Модуль:** [5. Бустинг как градиентный спуск в пространстве функций](../lesson_5/README.md) · **Уровень:** Средний · **Время:** ~50 мин

**Нужно знать:** [5 Бустинг как градиентный спуск в пространстве функций](../lesson_5/README.md), [1.3 Производная, градиент и градиентный спуск](../lesson_1_3/README.md)

Эмпирический риск как функция вектора прогнозов, его градиент, «свободный» спуск и почему он лишь запоминает, проекция антиградиента на деревья, псевдо-остатки для разных потерь.

## После урока вы сможете

- записать градиент эмпирического риска по вектору прогнозов
- объяснить, почему свободный градиентный шаг по прогнозам не обобщается
- интерпретировать дерево как проекцию антиградиента на множество деревьев
- вычислить псевдо-остатки для L2, L1, Хьюбера, квантильных и логистических потерь

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
