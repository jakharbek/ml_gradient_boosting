Зачем это нужно

Это центральный урок курса: здесь градиентный бустинг выводится из градиентного спуска, а не придумывается. После него любая новая функция потерь превращается в алгоритм бустинга механически.

Прогнозы как параметры

Эмпирический риск зависит от модели только через её прогнозы на обучающих объектах. Обозначим их вектором:

$$\mathbf F = \big(F(x_1), \dots, F(x_n)\big) \in \mathbb R^n, \qquad R(\mathbf F) = \frac1n \sum_{i=1}^{n} L\big(y_i, F_i\big)$$

Теперь $R$ — обычная функция $n$ переменных. Её градиент считается покомпонентно, и каждая компонента зависит только от своего объекта:

$$\frac{\partial R}{\partial F_i} = \frac1n \,\frac{\partial L(y_i, F_i)}{\partial F_i} = \frac1n\, g_i$$

Антиградиент (с точностью до множителя $\frac1n$, который уходит в длину шага) называют псевдо-остатками:

$$r_i = -g_i = -\frac{\partial L(y_i, F)}{\partial F}\Big|_{F = F_{m-1}(x_i)}$$

Свободный шаг: почему не годится

Можно было бы просто делать градиентный спуск по вектору $\mathbf F$: $F_i \leftarrow F_i + \nu r_i$. Для L2 он сходится к $F_i = y_i$ — модель запоминает все обучающие ответы вместе с шумом. И главное: этот спуск меняет прогнозы только в обучающих точках. Для нового $x$ он не говорит ничего.

Нужна функция, определённая везде. Решение Фридмана: вместо вектора $r$ сделать шаг функцией из заданного класса — деревом $h$, которое ближе всего к $r$ на обучающих точках:

$$h_m = \arg\min_{h \in \text{деревья}} \sum_{i=1}^{n} \big(r_i - h(x_i)\big)^2$$

Это проекция антиградиента на множество деревьев. Дерево не может в точности повторить шумный вектор $r$, но улавливает его систематическую часть — ту, что повторится и на новых данных.

Насколько дерево повторяет градиент

Качество проекции удобно мерить косинусом угла между вектором псевдо-остатков $r$ и прогнозами дерева $h$ на обучающих точках:

$$\cos\angle(r, h) = \frac{\sum_i r_i h(x_i)}{\|r\|\,\|h\|}$$

Если косинус положителен, шаг деревом — направление убывания риска (производная по направлению отрицательна). В начале обучения, когда в остатках много структуры, косинус большой; к концу остатки становятся шумом, и дерево повторяет их всё хуже. Это естественный сигнал: дальнейшие шаги мало что дают.

Для L2 и дерева, построенного методом наименьших квадратов, $\langle r, h\rangle = \|h\|^2 > 0$: значения листьев — средние $r$ в листьях, поэтому шаг деревом всегда уменьшает риск (при достаточно малом ν).

Среднее псевдо-остатков — не всегда лучший шаг для самих потерь; Фридман пересчитывает листья линейным поиском.

Второй порядок: шаг Ньютона

Если знать кривизну $h_i = \partial^2 L/\partial F^2$, можно выбрать шаг точнее — так работает XGBoost.

В коде

import numpy as np
from gbcourse import datasets, RegressionTree

X, y = datasets.regression_1d(kind="sine", n=40, noise=0.3, seed=52)
X_te, y_te = datasets.regression_1d(kind="sine", n=1000, noise=0.3, seed=53)
nu, steps = 0.3, 60
F_free = np.full_like(y, y.mean())                 # свободный спуск: только в обучающих точках
F_tree, F_tree_te = F_free.copy(), np.full(len(y_te), y.mean())
for m in range(steps):
    F_free += nu * (y - F_free)
    r = y - F_tree
    h = RegressionTree(max_depth=2).fit(X, -r)     # проекция антиградиента на деревья
    F_tree += nu * h.predict(X)
    F_tree_te += nu * h.predict(X_te)
print("MSE обучения: свободный", np.mean((y - F_free)**2).round(4), " деревом", np.mean((y - F_tree)**2).round(4))
print("MSE на новых точках: свободный спуск их не меняет —", np.mean((y_te - y.mean())**2).round(4),
      "; деревом", np.mean((y_te - F_tree_te)**2).round(4))

Итоги

  1. Риск зависит от вектора прогнозов на обучающих объектах; его антиградиент — псевдо-остатки.
  2. Свободный спуск по этому вектору запоминает данные и не определён на новых $x$.
  3. Дерево — проекция антиградиента на класс деревьев: шаг, который обобщается.
  4. Для L2 псевдо-остатки = остатки, для других потерь — своя формула; остальное неизменно.
