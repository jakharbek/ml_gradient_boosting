# Урок 2.2. Критерии разбиения: MSE, Джини, энтропия

> Что значит «хорошее» разбиение для регрессии и классификации — и почему в бустинге всегда используется критерий регрессии

**Модуль:** [2. Деревья решений — кирпичик бустинга](../lesson_2/README.md) · **Уровень:** Средний · **Время:** ~55 мин

**Нужно знать:** [2.1 Решающий пень: одно лучшее разбиение](../lesson_2_1/README.md)

Неоднородность узла и её уменьшение; дисперсия (MSE) для регрессии; индекс Джини, энтропия и доля ошибок для классификации; эквивалентность Джини и дисперсии для меток 0/1; взвешенные критерии.

## После урока вы сможете

- определить неоднородность (impurity) узла и выигрыш разбиения как её взвешенное уменьшение
- вычислить индекс Джини и энтропию для узла с заданными долями классов
- показать, что для меток 0/1 уменьшение Джини пропорционально уменьшению дисперсии
- объяснить, почему деревья в градиентном бустинге — всегда регрессионные
- посчитать вручную взвешенную неоднородность и её уменьшение для двух и трёх классов
- объяснить выигрыш как зазор между кривой неоднородности и хордой

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_2_2/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
