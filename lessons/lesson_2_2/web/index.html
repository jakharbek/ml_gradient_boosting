Зачем это нужно

В уроке лучшим считалось разбиение с наименьшей суммой квадратов ошибок. Для классификации часто используют другие меры — Джини и энтропию. Что их объединяет и какую выбрать?

Спойлер, важный для всего курса: в градиентном бустинге деревья всегда регрессионные, даже в классификации, потому что они предсказывают градиенты — вещественные числа. Но понимать Джини и энтропию нужно: они живут в случайных лесах, в одиночных деревьях и в документации всех библиотек.

Общая идея: неоднородность узла

Все критерии устроены одинаково. Есть мера неоднородности (impurity) узла $I(\text{узел})$: ноль, если все объекты «одинаковые», и много — если перемешаны. Хорошее разбиение сильнее всего уменьшает взвешенную неоднородность:

$$\Delta I = I(\text{родитель}) - \frac{n_L}{n}\, I(\text{левый}) - \frac{n_R}{n}\, I(\text{правый})$$
ЗадачаМера неоднородностиФормула ($p_k$ — доля класса $k$ в узле)
РегрессияДисперсия (MSE)$\frac1n\sum_i (y_i - \bar y)^2$
КлассификацияИндекс Джини$1 - \sum_k p_k^2$
КлассификацияЭнтропия$-\sum_k p_k \log_2 p_k$
КлассификацияДоля ошибок$1 - \max_k p_k$

Для регрессии $\Delta I \cdot n$ — это в точности выигрыш $\Delta$ из прошлого урока. Посмотрим, как ведут себя меры для двух классов:

По шагам: считаем критерий руками

Возьмём восемь квартир из обзора модуля и новый ответ: продали ли квартиру за месяц. Продали №2, 4, 6, 7, 8 (класс 1), не продали №1, 3, 5 (класс 0). Оценим вопрос «до центра ≤ 6.5 км?» по индексу Джини. Для двух классов он равен $2p(1-p)$, где $p$ — доля класса 1.

Шаг 1. Неоднородность родителя

В корне 5 единиц из 8: $p = 5/8 = 0.625$.

$G = 2 \cdot 0.625 \cdot 0.375 = 0.469$. Узел сильно перемешан — близко к максимуму 0.5.

Шаг 2. Левый узел

Ближе 6.5 км — квартиры №2, 4, 6, 8. Все проданы: $p_L = 4/4 = 1$.

$G_L = 2 \cdot 1 \cdot 0 = 0$. Узел чистый.

Шаг 3. Правый узел

Дальше 6.5 км — №1, 3, 5, 7 с метками 0, 0, 0, 1: $p_R = 1/4 = 0.25$.

$G_R = 2 \cdot 0.25 \cdot 0.75 = 0.375$.

Шаг 4. Взвешиваем по размеру

Узлы вносят вклад пропорционально числу объектов — иначе крошечный чистый лист выглядел бы большой победой:

$\dfrac{4}{8} \cdot 0 + \dfrac{4}{8} \cdot 0.375 = 0.188$.

Шаг 5. Уменьшение неоднородности

$\Delta I = 0.469 - 0.188 = 0.281$. Это и есть оценка вопроса. Дерево посчитает её для всех порогов всех признаков и возьмёт наибольшую.

Теперь то же самое — для любого порога и любой меры. Найдите в виджете порог, после которого обе группы чистые.

Критерии на одних и тех же данных

Восемь точек двух классов. Для каждого порога посчитаем уменьшение неоднородности по разным критериям. Обычно они выбирают один и тот же или соседний порог — различия заметны лишь в тонких случаях.

Она «плоская»

Разбиение может сделать узлы заметно чище, но не изменить мажоритарный класс ни в одном из них — тогда доля ошибок не уменьшится, и алгоритм не увидит пользы.

Пример

Родитель: 80 объектов класса 0 и 20 класса 1. Слева 40/0, справа 40/20. Ошибок было 20, стало 0 + 20 = 20 — выигрыш ноль. А Джини: $0.32 \to 0.4 \cdot 0 + 0.6 \cdot 0.444 = 0.267$ — выигрыш есть.

Джини и энтропия строго выпуклые

У выпуклой функции взвешенное среднее значений в детях меньше значения в родителе при любом «неравном» разбиении. Поэтому они поощряют любое очищение узлов.

Геометрия выигрыша: кривая и хорда

У выигрыша есть наглядный смысл. Нарисуем меру неоднородности как кривую от доли $p$. Левый и правый узлы — две точки на ней. Родитель по доле $p$ лежит между ними (это взвешенное среднее долей детей). Неоднородность родителя — точка на кривой. Взвешенная неоднородность детей — точка на хорде, соединяющей детей. Выигрыш — вертикальный зазор между ними.

В виджете по умолчанию — пример из разбора ниже: слева чистый узел ($p_L = 0$), справа $p_R = 0.33$. Для Джини зазор есть: 0.052. Переключите меру на «Долю ошибок» — зазор исчезнет. Её график состоит из двух прямых, и пока оба ребёнка по одну сторону от 0.5, хорда совпадает с самой линией.

Функция, график которой лежит выше любой своей хорды, называется строго вогнутой (выпуклой вверх). Джини и энтропия такие, поэтому поощряют любое очищение узлов. Доля ошибок — нет.

Джини = дисперсия для меток 0 и 1

Закодируем классы числами 0 и 1. Среднее меток в узле — доля единиц $p$, дисперсия меток:

$$\mathrm{Var}(y) = \frac1n\sum_i (y_i - p)^2 = p(1-p), \qquad \text{Gini} = 1 - p^2 - (1-p)^2 = 2p(1-p)$$

Джини ровно вдвое больше дисперсии! Значит, регрессионное дерево, обученное на метках 0/1, выбирает те же разбиения, что дерево классификации с критерием Джини, а в листьях у него — доли класса 1. Именно так в курсе строятся деревья классификации (виджет модуля 2).

Вся классификация сводится к регрессии: предсказывая число «вероятность класса 1», мы можем пользоваться одним и тем же регрессионным деревом. Бустинг делает следующий шаг: регрессионные деревья предсказывают градиенты функции потерь (урок ).

Больше двух классов

Формулы из таблицы в начале урока записаны сразу для любого числа классов. Пример: в узле 20 объектов — 10 класса A, 6 класса B и 4 класса C. Доли: 0.5, 0.3, 0.2.

  • Джини: $1 - (0.5^2 + 0.3^2 + 0.2^2) = 1 - 0.38 = 0.62$.
  • Энтропия: $-(0.5\log_2 0.5 + 0.3\log_2 0.3 + 0.2\log_2 0.2) = 0.5 + 0.521 + 0.464 = 1.485$ бита.
  • Доля ошибок: $1 - 0.5 = 0.5$ — если назвать всех классом A, ошибёмся в половине случаев.

У индекса Джини есть простое прочтение. Вытащим из узла объект наугад и назовём его класс тоже наугад — с вероятностями, равными долям классов. Джини — вероятность ошибиться в такой игре. В чистом узле ошибиться нельзя, и Джини равен нулю.

Регрессия на тех же числах

Для числового ответа мера неоднородности — дисперсия, то есть SSE, делённая на число объектов. Проверим на ценах восьми квартир из обзора модуля:

  • Родитель: $\text{SSE} = 51.74$, дисперсия $51.74 / 8 = 6.47$.
  • После вопроса «площадь ≤ 56»: слева $4.91 / 4 = 1.23$, справа $8.11 / 4 = 2.03$.
  • Взвешенно: $\frac{4}{8} \cdot 1.23 + \frac{4}{8} \cdot 2.03 = 1.63$. Уменьшение: $6.47 - 1.63 = 4.84$.

Умножим на число объектов: $4.84 \cdot 8 = 38.72$ — в точности выигрыш $\Delta$ из урока 2.1. «Уменьшение взвешенной дисперсии» и «уменьшение суммы квадратов» — один и тот же критерий в разных единицах.

Какой критерий в бустинге

Классический GBM: дисперсия псевдо-остатков

Дерево аппроксимирует псевдо-остатки $r_i$ методом наименьших квадратов — критерий MSE (в scikit-learn — friedman_mse, эквивалентный для невзвешенных данных).

XGBoost/LightGBM/CatBoost: gain второго порядка

$\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G^2}{H+\lambda}$ — та же «сумма в квадрате, делённая на размер», только размер измеряется суммой гессианов. При $h_i = 1$ это снова наш критерий.

Джини и энтропия — нет

Они требуют меток классов в листьях, а деревья бустинга предсказывают вещественные числа.

В коде

import numpy as np
from gbcourse import datasets

X, y = datasets.toy_classification()          # y = [0,0,0,1,0,1,1,1]
x = X[:, 0]
gini = lambda p: 2 * p * (1 - p)
entropy = lambda p: 0.0 if p in (0, 1) else -(p * np.log2(p) + (1 - p) * np.log2(1 - p))
var = lambda p: p * (1 - p)

for t in np.arange(1.5, 8, 1.0):
    L, R = y[x <= t], y[x > t]
    wl, wr = len(L) / len(y), len(R) / len(y)
    dec = {name: f(y.mean()) - wl * f(L.mean()) - wr * f(R.mean()) for name, f in [("Джини", gini), ("энтропия", entropy), ("дисперсия", var)]}
    print(f"t = {t}: " + ", ".join(f"{k} {v:.4f}" for k, v in dec.items()))

Упражнения

1. Вопрос про площадь ★☆☆. Те же восемь квартир и метки (продали №2, 4, 6, 7, 8). Посчитайте уменьшение индекса Джини для вопроса «площадь ≤ 56».

Решение

Слева №1–4 с метками 0, 1, 0, 1: $p_L = 0.5$, $G_L = 0.5$. Справа №5–8 с метками 0, 1, 1, 1: $p_R = 0.75$, $G_R = 0.375$.

После: $0.5 \cdot 0.5 + 0.5 \cdot 0.375 = 0.4375$. Уменьшение: $0.469 - 0.438 = 0.031$ — почти бесполезный вопрос.

2. Тот же вопрос, доля ошибок ★★☆. Посчитайте для «площадь ≤ 56» уменьшение доли ошибок и объясните результат.

Решение

Родитель: $\min(0.625, 0.375) = 0.375$. Слева $\min(0.5, 0.5) = 0.5$, справа $\min(0.75, 0.25) = 0.25$. После: $0.5 \cdot 0.5 + 0.5 \cdot 0.25 = 0.375$. Уменьшение — ноль.

Число неверно названных квартир не изменилось: было 3 из 8 (называем всех «продали»), стало 2 слева и 1 справа. Доля ошибок не видит, что правый узел стал чище.

3. Максимум энтропии ★★☆. Чему равна наибольшая энтропия узла с четырьмя классами и когда она достигается?

Решение

При равных долях $p_k = 0.25$: $-4 \cdot 0.25 \log_2 0.25 = 2$ бита. В общем случае для $K$ классов максимум равен $\log_2 K$ — столько вопросов «да/нет» нужно, чтобы угадать класс. У Джини максимум $1 - 1/K$.

4. Джини через дисперсию ★★★. Покажите на метках 0, 0, 0, 1, что индекс Джини вдвое больше дисперсии меток.

Решение

Среднее $p = 0.25$. Дисперсия: $\frac{1}{4}\left(3 \cdot 0.25^2 + 0.75^2\right) = \frac{0.1875 + 0.5625}{4} = 0.1875$. Джини: $2 \cdot 0.25 \cdot 0.75 = 0.375 = 2 \cdot 0.1875$.

Итоги

  1. Любой критерий — уменьшение взвешенной неоднородности узла.
  2. Регрессия — дисперсия (MSE); классификация — Джини или энтропия; доля ошибок слишком груба.
  3. Для меток 0/1 Джини = 2 × дисперсия: дерево классификации — это регрессионное дерево на метках.
  4. В бустинге деревья регрессионные: MSE псевдо-остатков (GBM) или gain с $G$ и $H$ (XGBoost).
  5. Выигрыш — зазор между кривой неоднородности и хордой, соединяющей детей; у Джини и энтропии он есть при любом очищении узлов, у доли ошибок — не всегда.
  6. Для $K$ классов формулы те же; максимум Джини $1 - 1/K$, энтропии $\log_2 K$.
