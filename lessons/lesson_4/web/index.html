Зачем этот модуль

Все кирпичики собраны: функции потерь, деревья, идея последовательного исправления ошибок. Пора сложить из них градиентный бустинг — сначала в самом простом виде, для регрессии с квадратичными потерями.

В этой форме «градиентная» часть ещё не видна: антиградиент квадратичных потерь — это просто остаток $y - F$. Поэтому алгоритм читается как здравый смысл: «посмотри, где ошибся, и исправь немного». Обобщение на любые потери — в модуле 5.

Алгоритм в четыре строки

$$\begin{aligned} &1.\quad F_0(x) = \bar y \\ &2.\quad \text{для } m = 1, \dots, M: \\ &\qquad r_{i} = y_i - F_{m-1}(x_i) \qquad \text{(остатки)}\\ &\qquad h_m = \text{дерево, обученное на } \{(x_i, r_i)\} \\ &\qquad F_m(x) = F_{m-1}(x) + \nu\, h_m(x) \end{aligned}$$
$F_0 = \bar y$ — лучшая константа для квадратичных потерь

Без признаков лучше среднего не угадать. Всё дальнейшее — поправки к нему.

$r_i = y_i - F_{m-1}(x_i)$ — что ещё не объяснено

Остатки — «работа», оставшаяся после $m-1$ деревьев. Каждый шаг уменьшает их.

$h_m$ — неглубокое дерево на остатках

Дерево находит, в каких областях признаков остатки систематически положительны или отрицательны, и выдаёт в каждом листе средний остаток.

$\nu$ — принимаем лишь долю исправления

Маленькие шаги медленнее, но обобщают лучше: ни одно дерево не успевает «перетянуть» модель под шум.

$M$ — сколько шагов делать

Слишком много деревьев — переобучение. Число выбирают по валидации.

Песочница

Главный инструмент модуля. Ползунок «Итерация m» показывает модель после $m$ деревьев; нижние графики — остатки, на которых учится $m$-е дерево, и кривые потерь на обучении и валидации (30% точек отложены, полые кружки).

Вопросы для самопроверки, на которые отвечает песочница:

  • Почему первое дерево почти повторяет форму данных, а сотое — «плоское» и мелкое?
  • При каких ν и глубине кривая валидации начинает расти? Что это значит?
  • Что происходит на данных «Ступеньки» с деревьями глубины 1?

Уроки модуля

В коде

import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import GradientBoostingRegressor
from gbcourse import datasets

X, y = datasets.regression_1d(kind="wave", n=100, noise=0.35, seed=42)
nu, M = 0.1, 150
F = np.full_like(y, y.mean())            # 1. F0 = среднее
trees = []
for m in range(M):
    r = y - F                            # 2. остатки
    h = DecisionTreeRegressor(max_depth=2).fit(X, r)   # 3. дерево на остатках
    F = F + nu * h.predict(X)            # 4. маленький шаг
    trees.append(h)

sk = GradientBoostingRegressor(n_estimators=M, learning_rate=nu, max_depth=2).fit(X, y)
print("расхождение с sklearn:", np.abs(F - sk.predict(X)).max())

Итоги

  1. Бустинг с L2: старт со среднего, затем деревья на остатках с маленьким шагом ν.
  2. Каждое дерево исправляет то, что не объяснили предыдущие.
  3. Качество управляется темпом ν, числом деревьев M и сложностью деревьев.
