# Модуль 8. XGBoost изнутри: бустинг второго порядка

> Одна регуляризованная цель, её квадратичное приближение — и из него сразу и значения листьев, и критерий разбиения

**Уровень:** Продвинутый · **Время:** ~30 мин

**Нужно знать:** [6.2 Значения листьев: шаг Ньютона](../lesson_6_2/README.md), [7.3 Сложность деревьев и штрафы на листья](../lesson_7_3/README.md)

Чем XGBoost отличается от классического бустинга Фридмана: разложение потерь до второго порядка, штрафы внутри цели, формулы веса листа и выигрыша разбиения из одной задачи, быстрый поиск разбиений. Наша реализация в режиме newton совпадает с XGBoost до точности float32.

## После урока вы сможете

- сравнить классический GBM и XGBoost по трём пунктам: критерий разбиения, значения листьев, регуляризация
- увидеть дерево второго порядка как взвешенную регрессию на «рабочий отклик» z = −g/h с весами h
- ориентироваться в уроках модуля

## Уроки модуля

1. [8.1 Разложение Тейлора: градиент и гессиан](../lesson_8_1/README.md) — Приближения нулевого, первого и второго порядка для потерь одного объекта; таблица g и h для основных функций потерь; зачем нужен гессиан (единицы измерения шага); что делают библиотеки, когда h = 0 (L1, квантили) или h скачет (Хьюбер, Пуассон).
2. [8.2 Регуляризованная цель: веса листьев и выигрыш разбиения](../lesson_8_2/README.md) — Вывод формул XGBoost шаг за шагом: цель итерации, квадратичное приближение, группировка по листьям, оптимальные веса $w^* = -G/(H+\lambda)$, качество структуры $-\frac12\sum G^2/(H+\lambda) + \gamma T$ и выигрыш разбиения. Разбор первой итерации вручную и сверка с XGBoost, включая множитель 2 в его выигрыше.
3. [8.3 Поиск разбиений: точный перебор, гистограммы и пропуски](../lesson_8_3/README.md) — Точный жадный перебор по отсортированным значениям с накопленными суммами G и H; гистограммный поиск по квантильным корзинам (max_bin), вычитание гистограмм; обработка пропусков с выбором направления по умолчанию. Скорость и точность tree_method exact / approx / hist.
