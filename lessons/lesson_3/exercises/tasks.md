## 1. Бустинг поглубже ★☆☆

Повторите сравнение из ноутбука для бустинга глубины 3 (ν = 0.1, до 300 деревьев). При каком числе

## 2. Мелкий лес ★★☆

Ограничьте глубину деревьев бэггинга двумя. Как изменилась ошибка при B = 300? Объясните через
смещение и разброс, почему усреднение не спасает мелкие деревья.

## 3. Сколько нужно моделей ★☆☆

По формуле $\rho\sigma^2 + (1-\rho)\sigma^2/B$ найдите, при каком B разброс среднего отличается от
предела $\rho\sigma^2$ меньше чем на 10% (для ρ = 0.3).
