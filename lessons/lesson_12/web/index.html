Зачем этот модуль

Модель из 500 деревьев точна, но непрозрачна. А объяснять нужно: чтобы найти ошибку в данных или утечку, чтобы убедить заказчика, чтобы ответить клиенту, почему ему отказали в кредите. Интерпретация отвечает на три разных вопроса — и для каждого свой инструмент.

Разложение прогноза на вклады

Главная идея модуля видна уже на одном объекте. Прогноз раскладывается в сумму: базовое значение (средний прогноз) плюс вклад каждого признака:

$$F(x) = \varphi_0 + \sum_{j=1}^{d} \varphi_j(x).$$

Вклады $\varphi_j$ — значения Шепли из теории кооперативных игр: справедливое распределение «выигрыша» $F(x) - \varphi_0$ между признаками. Как именно они считаются — в уроке .

Проверьте: база плюс сумма вкладов в точности равна прогнозу модели. Средний модуль вкладов по многим объектам — глобальная важность признака. Для шумовых $x_5$ и $x_6$ она почти нулевая, а у $x_3$ и $x_1$ — наибольшая.

Уроки модуля

Важность признаков

Встроенные важности, перестановочная, SHAP; ловушки коррелированных признаков и признаков с большим числом значений.

Значения Шепли и SHAP

Коалиции признаков, аксиомы, TreeSHAP; сводные графики и графики зависимости.

PDP, ICE и монотонные ограничения

Средний эффект признака и его разнообразие по объектам; как заставить модель быть монотонной.

В коде

import numpy as np
from gbcourse import datasets, GBRegressor
from gbcourse.explain import shapley_values

X, y = datasets.friedman1(n=600, noise=1.0, seed=180, n_features=7)
model = GBRegressor(n_estimators=100, max_depth=3, learning_rate=0.1).fit(X, y)
base, phi = shapley_values(model, X[0])
print("база φ₀ =", round(base, 4))
print("вклады:", np.round(phi, 3))
print("φ₀ + Σφ =", round(base + phi.sum(), 6), "| прогноз =", round(model.predict(X[:1])[0], 6))

Итоги

  1. Вопросы «что важно», «почему этот прогноз» и «как влияет признак» требуют разных инструментов.
  2. Значения Шепли раскладывают прогноз точно: база + сумма вкладов = прогноз.
  3. Средний модуль вкладов по объектам — глобальная важность.
