# Урок 11.1. Карта гиперпараметров и стратегия настройки

> Какие параметры двигают качество, какие — нет, и в каком порядке их настраивать

**Модуль:** [11. Настройка гиперпараметров](../lesson_11/README.md) · **Уровень:** Продвинутый · **Время:** ~40 мин

**Нужно знать:** [11 Настройка гиперпараметров](../lesson_11/README.md)

Анализ чувствительности LightGBM: семь параметров по одному вокруг значений по умолчанию на двух задачах, с разбросом по разбиениям. Размер деревьев — главный рычаг, доля признаков может навредить при взаимодействиях, большинство остальных эффектов в пределах шума. Пошаговая стратегия настройки и её проверка.

## После урока вы сможете

- оценивать чувствительность модели к параметру с учётом шума между разбиениями
- применять пошаговую стратегию настройки бустинга
- выбирать разумные стартовые значения

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_11_1/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
