Зачем это нужно

На каждой итерации бустинг решает одну и ту же задачу: насколько сдвинуть прогноз $F_i$ объекта, чтобы уменьшить потери $L(y_i, F_i + w)$. Для квадратичной потери это просто, для остальных — нет. XGBoost делает все потери «квадратичными»: заменяет каждую её параболой в окрестности текущего прогноза.

Три приближения

Зафиксируем объект: $y$ известен, текущий прогноз $F$. Как функция от шага $w$:

$$L(y, F + w) \approx \underbrace{L(y, F)}_{\text{0-й порядок}} + \underbrace{g\,w}_{\text{1-й}} + \underbrace{\tfrac12 h\,w^2}_{\text{2-й}}, \qquad g = \frac{\partial L}{\partial F},\quad h = \frac{\partial^2 L}{\partial F^2}.$$
  • Первый порядок — касательная прямая. Она говорит, куда идти ($-g$), но не говорит, сколько: у прямой нет минимума.
  • Второй порядок — парабола. При $h > 0$ у неё есть минимум $w^* = -g/h$ — это шаг Ньютона.

g и h для основных потерь

Везде $F$ — «сырой» прогноз модели (для классификации — логит, для Пуассона — логарифм среднего).

Параболы нет — есть только касательная, шаг Ньютона не определён. Библиотеки строят структуру дерева по суррогату (XGBoost для reg:absoluteerror берёт $h = 1$), а затем пересчитывают значения листьев точно: медиана или квантиль остатков в листе. То есть возвращаются к линейному поиску Фридмана из урока .

h скачет: потери Хьюбера

У Хьюбера $h = 1$ внутри $|r| \le \delta$ и $h = 0$ снаружи: у выбросов «кривизны» нет совсем. Псевдо-Хьюбер — гладкая версия: $h$ убывает плавно, и формулы второго порядка работают везде.

h очень мал: уверенные прогнозы и Пуассон

При $h \to 0$ шаг $-g/h$ может стать огромным. Страховки — штраф λ в знаменателе и max_delta_step в XGBoost, который обрезает значение листа. Для count:poisson XGBoost по умолчанию ставит max_delta_step=0.7.

Зачем нужен h: единицы измерения шага

Если выбросить второй порядок, лист получит значение $-G/n$ — средний антиградиент. Но у градиента те же единицы, что у $y$, а прогноз $F$ может жить в другой шкале. Для Пуассона $F = \log\mu$, и $g = \mu - y$ измеряется в «штуках». При среднем 50 шаг в 10 «штук» по логарифму — это катастрофа. Гессиан $h = \mu$ как раз переводит шаг в нужную шкалу: $-g/h = (y - \mu)/\mu$ — относительная ошибка.

При ν = 0.3 Ньютон приходит к девиации 0.53–0.73 при любом масштабе от 0.5 до 50. Первый порядок хорош при $s \le 2$, при $s = 5$ девиация вырастает до 80, при $s = 10$ — до 1355, а при $s = 50$ он расходится на второй итерации. Уменьшив ν до 0.03, первый порядок можно спасти при $s = 10$, но тогда он слишком медленный при малых $s$. Для первого порядка правильный темп зависит от масштаба $y$, для Ньютона — нет. (Классический GBM Фридмана решает ту же проблему иначе — линейным поиском в каждом листе.)

В коде

import numpy as np
from gbcourse.losses import get_loss

y, F, eps = np.array([3.0]), np.array([0.7]), 1e-4
for name in ["squared", "logistic", "poisson", "huber"]:
    loss = get_loss(name)
    yy = np.array([1.0]) if name == "logistic" else y
    L = lambda f: loss.pointwise(yy, np.array([f]))[0]
    g_num = (L(F[0] + eps) - L(F[0] - eps)) / (2 * eps)
    h_num = (L(F[0] + eps) - 2 * L(F[0]) + L(F[0] - eps)) / eps**2
    print(f"{name:9s} g = {loss.gradient(yy, F)[0]:+.5f} (численно {g_num:+.5f}),"
          f" h = {loss.hessian(yy, F)[0]:.5f} (численно {h_num:.5f})")

Итоги

  1. Второй порядок заменяет потери параболой $L_0 + g w + \frac12 h w^2$; её минимум — шаг Ньютона $-g/h$.
  2. Для обучения XGBoost достаточно двух функций: $g(y, F)$ и $h(y, F)$.
  3. Гессиан переводит шаг в шкалу прогноза: шаг первого порядка зависит от масштаба $y$, шаг Ньютона — нет.
  4. При $h = 0$ (L1, квантили) значения листьев пересчитывают точным линейным поиском.
