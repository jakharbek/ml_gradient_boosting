Равномерный x на [0, 10]; счётчики генерируются в ноутбуке как Пуассон(s·exp(0.8·sin x)).

- Столбцы: `x`, `y`; строк: 200.
- Как получить в Python: `datasets.regression_1d(kind='wave', n=200, noise=0.0, seed=81)`
