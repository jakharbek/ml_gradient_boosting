# Модуль 14. Итоговый проект: модель оттока клиентов

> Весь курс в одной задаче: от постановки и честного разбиения по времени до настроенной, объяснённой и проверенной на сдвиг модели

**Уровень:** Экспертный · **Время:** ~120 мин

**Нужно знать:** [13.3 Бустинг в эксплуатации](../lesson_13_3/README.md), [12.2 Значения Шепли и SHAP](../lesson_12_2/README.md), [11.2 Кросс-валидация и поиск параметров: сетка, случайный поиск, Optuna](../lesson_11_2/README.md), [10.1 Категориальные признаки](../lesson_10_1/README.md)

Прогноз оттока клиентов телеком-оператора на синтетических, но реалистичных данных: категории с редкими значениями, пропуски, зависящие от цели, несбалансированные классы, взаимодействия, повышение цен во времени. Пошаговое решение с метриками на каждом шаге, объяснение модели, проверка калибровки и сдвига, критерии оценки собственного решения.

## После урока вы сможете

- спланировать и выполнить полный цикл решения задачи бустингом
- обосновать каждый шаг метриками на правильной валидации
- объяснить модель и оценить её готовность к эксплуатации

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_14/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
