# Задания итогового проекта

Решения части заданий: [`solutions.py`](solutions.py) — `python lessons/lesson_14/exercises/solutions.py`.
Главное задание — собственное решение, оцениваемое по критериям со страницы урока.

## 1. Признаки из истории клиента ★★☆

Добавьте признаки, которые можно вычислить на момент прогноза: изменение платежа за последний месяц,
число обращений в поддержку за три последних месяца, отношение платежа к трафику. Следите, чтобы ни один признак
не использовал будущие месяцы. Улучшилась ли модель на валидации и тесте?

## 2. Редкие регионы ★★☆

Объедините регионы, встречающиеся в обучении реже 100 раз, в категорию «прочие», или закодируйте регион средним
по фолдам. Сравните с встроенной обработкой.

## 3. CatBoost ★★☆

Обучите CatBoost с категориальными признаками и ранней остановкой по валидации. Сравните log-loss и AP с эталоном.

## 4. План эксплуатации ★☆☆

Напишите короткий план: какие признаки и прогнозы мониторить, какие пороги PSI считать тревожными, когда
переобучать модель. Опирайтесь на урок 13.3.

## 5. Выбор порога ★★☆

Удерживать можно 5% клиентов в месяц. Какую полноту (долю пойманных уходящих) даёт эталонная модель на тесте,
если брать 5% клиентов с наибольшей вероятностью ухода? А случайный выбор?
