Зачем этот модуль

До сих пор деревья учились на остатках $y - F$. Это работает для квадратичных потерь. Но как быть с абсолютными, квантильными, логистическими, своими бизнес-потерями? Ответ Фридмана (2001) сделал бустинг универсальным.

В этом модуле слово «градиентный» наконец получает точный смысл. После него вы сможете сами вывести алгоритм бустинга для любой дифференцируемой функции потерь.

Идея за одну минуту

Обычный градиентный спуск

Параметры $\theta$ — числа. Шаг: $\theta \leftarrow \theta - \eta\,\nabla_\theta L$.

Градиентный бустинг

«Параметры» — сами прогнозы $F(x_1), \dots, F(x_n)$. Шаг: $F \leftarrow F - \nu\, \nabla_F L$, где градиент приближён деревом.

Для квадратичных потерь $-\partial L / \partial F = y - F$ — остаток. Для других потерь антиградиент другой, и именно его («псевдо-остатки») учит дерево. Всё остальное в алгоритме не меняется.

$$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F = F_{m-1}}, \qquad h_m \approx r_{\cdot m}, \qquad F_m = F_{m-1} + \nu h_m$$

Одна процедура — разные потери

Данные с выбросами (8% точек сдвинуты на ±4…7). Переключайте функцию потерь: с квадратичными модель тянется к выбросам, с абсолютными или Хьюбера — почти не замечает их. Нижняя левая панель показывает псевдо-остатки — у L1 это просто ±1.

Модуль по косточкам

Функциональный градиент и псевдо-остатки

Почему прогнозы можно считать параметрами, почему шаг делается деревом, что такое проекция градиента.

Алгоритм Фридмана построчно

Общий алгоритм GBM и TreeBoost: псевдо-остатки для структуры дерева, линейный поиск для значений листьев.

Функции потерь для регрессии

L2, L1, Хьюбер, квантильная: градиенты, значения листьев, устойчивость, предсказательные интервалы.

В коде

import numpy as np
from gbcourse import datasets, GBRegressor

X, y = datasets.regression_1d(kind="wave", n=300, noise=0.3, seed=51, outliers=0.08)
X_tr, X_te, y_tr, y_te = datasets.train_test_split(X, y, test_size=0.3, seed=0)
clean = datasets.true_function("wave", X_te[:, 0])          # «истина» без шума и выбросов
for loss in ("squared", "absolute", "huber"):
    m = GBRegressor(loss=loss, huber_delta=1.0, n_estimators=300, learning_rate=0.1, max_depth=2).fit(X_tr, y_tr)
    print(f"{loss:9s}: MAE до истинной функции {np.mean(np.abs(clean - m.predict(X_te))):.3f}")

Итоги

  1. Бустинг — градиентный спуск, в котором «параметры» — прогнозы модели.
  2. Дерево учится на антиградиенте потерь (псевдо-остатках); для L2 это обычные остатки.
  3. Сменив потери, мы меняем три вещи: $F_0$, псевдо-остатки и значения листьев.
