# Модуль 5. Бустинг как градиентный спуск в пространстве функций

> Главная идея Фридмана: прогнозы модели — это параметры, остатки — это антиградиент, а дерево — способ сделать шаг, который обобщается

**Уровень:** Средний · **Время:** ~30 мин

**Нужно знать:** [4.3 Градиентный бустинг с нуля на Python](../lesson_4_3/README.md), [1.3 Производная, градиент и градиентный спуск](../lesson_1_3/README.md)

Почему остатки — частный случай антиградиента, что меняется для произвольных потерь, общий алгоритм Фридмана и выбор функции потерь для регрессии; план модуля.

## После урока вы сможете

- объяснить, в каком смысле бустинг — градиентный спуск
- понимать, что меняется в алгоритме при смене функции потерь
- ориентироваться в уроках модуля

## Уроки модуля

1. [5.1 Функциональный градиент и псевдо-остатки](../lesson_5_1/README.md) — Эмпирический риск как функция вектора прогнозов, его градиент, «свободный» спуск и почему он лишь запоминает, проекция антиградиента на деревья, псевдо-остатки для разных потерь.
2. [5.2 Алгоритм Фридмана (GBM/TreeBoost) по строчкам](../lesson_5_2/README.md) — Общий Gradient_Boost с линейным поиском шага, специализация TreeBoost с оптимальным значением каждого листа, shrinkage; значения листьев для L2, L1, Хьюбера, квантилей и log-loss; сравнение «среднего псевдо-остатков» и линейного поиска.
3. [5.3 Функции потерь для регрессии: L2, L1, Хьюбер, квантильная](../lesson_5_3/README.md) — Полная карточка каждой потери (F₀, псевдо-остатки, значение листа, что предсказывает), устойчивость к выбросам, квантильный бустинг и интервалы с проверкой покрытия, практические рекомендации.
