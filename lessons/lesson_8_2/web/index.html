Зачем это нужно

В этом уроке мы выведем две формулы, на которых стоит XGBoost (а вслед за ним LightGBM и CatBoost): значение листа и выигрыш разбиения. Вывод занимает пять строк, и каждая строка — отдельная косточка.

Вывод по шагам

1. Цель одной итерации

Модель $F$ уже построена, ищем новое дерево $f$:

$$\mathcal{L}(f) = \sum_{i=1}^{n} L\big(y_i, F_i + f(x_i)\big) + \Omega(f), \qquad \Omega(f) = \gamma T + \tfrac{\lambda}{2}\sum_{j=1}^{T} w_j^2.$$

Первое слагаемое — насколько хорошо, второе — насколько сложно. $T$ — число листьев, $w_j$ — их значения. (L1-штраф α для краткости опустим; с ним $G$ заменяется на $T_\alpha(G)$, см. урок .)

2. Квадратичное приближение

Раскладываем каждое слагаемое по Тейлору (урок ) и отбрасываем константу $\sum L(y_i, F_i)$:

$$\tilde{\mathcal{L}}(f) = \sum_{i=1}^{n} \Big[g_i f(x_i) + \tfrac12 h_i f(x_i)^2\Big] + \gamma T + \tfrac{\lambda}{2}\sum_{j} w_j^2.$$
3. Группировка по листьям

Дерево даёт всем объектам листа $j$ одно и то же значение: $f(x_i) = w_j$ для $i \in I_j$. Соберём слагаемые по листьям, обозначив $G_j = \sum_{i \in I_j} g_i$ и $H_j = \sum_{i \in I_j} h_i$:

$$\tilde{\mathcal{L}} = \sum_{j=1}^{T}\Big[G_j w_j + \tfrac12 (H_j + \lambda)\, w_j^2\Big] + \gamma T.$$

Цель распалась на $T$ независимых парабол — по одной на лист. Объекты больше не нужны, только суммы $G_j, H_j$.

4. Оптимальные веса листьев и качество структуры

Минимум каждой параболы и значение цели в минимуме:

$$w_j^* = -\frac{G_j}{H_j + \lambda}, \qquad \tilde{\mathcal{L}}^* = -\frac12 \sum_{j=1}^{T} \frac{G_j^2}{H_j + \lambda} + \gamma T.$$

$\tilde{\mathcal{L}}^*$ — «качество структуры» (structure score): насколько хорошо дерево с таким разбиением на листья может уменьшить цель, если листьям дать лучшие значения. Чем меньше, тем лучше.

5. Выигрыш разбиения

Лист с суммами $(G, H)$ делим на левую $(G_L, H_L)$ и правую $(G_R, H_R)$ части. Выигрыш — насколько уменьшится $\tilde{\mathcal{L}}^*$: из дерева уходит один лист и появляются два (+1 к $T$):

$$\text{gain} = \frac12\left[\frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda}\right] - \gamma.$$

Первые два слагаемых — качество новых листьев, третье — старого, γ — цена дополнительного листа. Разбиение выгодно, только если gain > 0.

Первая итерация вручную

Игрушечные данные: $x = 1, \dots, 6$, $y = (2, 4, 3, 7, 9, 11)$, квадратичная потеря, λ = 1. Старт $F_0 = \bar y = 6$, значит $g_i = F_0 - y_i = (4, 2, 3, -1, -3, -5)$, $h_i = 1$. В корне $G = 0$, $H = 6$, поэтому последнее слагаемое выигрыша равно нулю.

Выигрыш по всем порогам

Как это выглядит в XGBoost

В выгрузке дерева (get_dump(with_stats=True) или trees_to_dataframe()) у каждого узла есть два числа:

  • cover — это $H$, сумма гессианов в узле. Для квадратичной потери — просто число объектов. С ней и сравнивается min_child_weight.
  • gain — выигрыш разбиения, но без множителя ½: XGBoost хранит $\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G^2}{H+\lambda}$. С этим удвоенным числом сравнивается gamma. Так что gamma XGBoost = 2 × γ из статьи и из gbcourse.
import numpy as np
import pandas  # нужен для trees_to_dataframe()
import xgboost as xgb
from gbcourse import datasets, RegressionTree

X, y = datasets.toy_regression()
ours = RegressionTree(max_depth=1, reg_lambda=1.0).fit(X, y.mean() - y)
ref = xgb.XGBRegressor(n_estimators=1, learning_rate=1.0, max_depth=1, reg_lambda=1.0,
                       min_child_weight=0, tree_method="exact", base_score=float(y.mean())).fit(X, y)
df = ref.get_booster().trees_to_dataframe()
root = df[df.Node == 0].iloc[0]
print("порог:", ours.nodes[0].threshold, "| XGBoost:", root.Split)
print("gain:  ", ours.nodes[0].gain, "| XGBoost:", root.Gain, "(ровно вдвое больше)")
print("cover (H):", ours.nodes[0].H, "| XGBoost:", root.Cover)
print("листья:", [lf.value for lf in ours.leaves], "| XGBoost:", df[df.Feature == "Leaf"].Gain.tolist())

Итоги

  1. После квадратичного приближения цель распадается на независимые параболы по листьям.
  2. $w^* = -G/(H+\lambda)$; качество структуры $-\frac12\sum G^2/(H+\lambda) + \gamma T$.
  3. Выигрыш разбиения — уменьшение качества структуры минус γ; в XGBoost он хранится без ½.
  4. Всё дерево строится по двум суммам на узел — это делает поиск разбиений быстрым (урок ).
