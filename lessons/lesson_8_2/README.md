# Урок 8.2. Регуляризованная цель: веса листьев и выигрыш разбиения

> Из одной формулы — оптимальное значение каждого листа, оценка качества всего дерева и критерий выбора разбиения

**Модуль:** [8. XGBoost изнутри: бустинг второго порядка](../lesson_8/README.md) · **Уровень:** Продвинутый · **Время:** ~40 мин

**Нужно знать:** [8.1 Разложение Тейлора: градиент и гессиан](../lesson_8_1/README.md), [7.3 Сложность деревьев и штрафы на листья](../lesson_7_3/README.md)

Вывод формул XGBoost шаг за шагом: цель итерации, квадратичное приближение, группировка по листьям, оптимальные веса $w^* = -G/(H+\lambda)$, качество структуры $-\frac12\sum G^2/(H+\lambda) + \gamma T$ и выигрыш разбиения. Разбор первой итерации вручную и сверка с XGBoost, включая множитель 2 в его выигрыше.

## После урока вы сможете

- вывести $w^*$ и качество структуры дерева из регуляризованной цели
- посчитать выигрыш разбиения вручную по суммам G и H
- сопоставить формулы с числами в выгрузке дерева XGBoost (gain, cover)
