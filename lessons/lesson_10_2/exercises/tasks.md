## 1. Значение вне диапазона ★☆☆

В MNAR-сценарии из ноутбука (значения $x_3 > 0.6$ пропадают с вероятностью 0.75) замените пропуски на −1 —
значение вне диапазона признака. Сравните с NaN и с «среднее + индикатор». Почему результаты близки?

## 2. Пересчёт вероятностей после весов ★★☆

Вес $w$ для класса 1 равносилен повторению каждого положительного объекта $w$ раз. Покажите, что тогда
«честная» вероятность получается из прогноза модели $p$ как $p' = \frac{p}{p + w(1 - p)}$.
Проверьте на данных из ноутбука (доля 2%, $w = 49$): сравните log-loss $p'$ с моделью без весов.
