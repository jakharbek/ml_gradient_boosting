# Урок 2.3. Рекурсивное построение дерева и остановка

> Жадный алгоритм: найти лучшее разбиение, разрезать, повторить в каждой половине — и вовремя остановиться

**Модуль:** [2. Деревья решений — кирпичик бустинга](../lesson_2/README.md) · **Уровень:** Средний · **Время:** ~65 мин

**Нужно знать:** [2.1 Решающий пень: одно лучшее разбиение](../lesson_2_1/README.md), [1.4 Переобучение, смещение и разброс, валидация](../lesson_1_4/README.md)

Рекурсивная жадная схема CART, порядок роста, критерии остановки (глубина, размер листа, минимальный выигрыш, число листьев), сложность построения, отсечение ветвей.

## После урока вы сможете

- описать рекурсивный жадный алгоритм построения дерева
- объяснить, почему жадность не гарантирует оптимального дерева
- назвать критерии остановки и их влияние на смещение и разброс
- оценить вычислительную сложность построения дерева
- проследить порядок рекурсивных вызовов и сравнить три порядка роста дерева
- объяснить отсечение ветвей по «слабому звену» и выбрать размер дерева по новым данным

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_2_3/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
