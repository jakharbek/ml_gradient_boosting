## `xor.csv` — XOR: 200 точек

Задача, на которой жадность ошибается: первое разбиение почти ничего не даёт.

- Столбцы: `x0`, `x1`, `y`; строк: 200.
- Как получить в Python: `datasets.classification_2d(kind='xor', n=200, noise=0.12, seed=9)`
