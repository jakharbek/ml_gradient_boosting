## `circles.csv` — Круги, 160 точек

Данные виджета AdaBoost: внутренний круг — класс 1, кольцо — класс 0.

- Столбцы: `x0`, `x1`, `y`; строк: 160.
- Как получить в Python: `datasets.classification_2d(kind='circles', n=160, noise=0.15, seed=5)`
