# Урок 3.2. AdaBoost: бустинг через веса объектов

> Первый практичный бустинг: каждый следующий ученик смотрит на данные, где ошибки предыдущих стали «тяжелее»

**Модуль:** [3. Ансамбли: сила многих слабых моделей](../lesson_3/README.md) · **Уровень:** Средний · **Время:** ~45 мин

**Нужно знать:** [3 Ансамбли: сила многих слабых моделей](../lesson_3/README.md), [2.1 Решающий пень: одно лучшее разбиение](../lesson_2_1/README.md)

Идея усиления слабых учеников, алгоритм AdaBoost по шагам: взвешенная ошибка εₘ, вес ученика αₘ, пересчёт весов объектов; оценка ошибки на обучении; чувствительность к шуму в метках.

## После урока вы сможете

- пройти по шагам алгоритм AdaBoost и вычислить εₘ, αₘ и новые веса
- объяснить, почему вес ученика $\alpha_m = \tfrac12\ln\frac{1-\varepsilon_m}{\varepsilon_m}$ растёт с его точностью
- понимать теоретическую гарантию: ошибка на обучении падает экспоненциально
- видеть слабое место AdaBoost — чувствительность к ошибкам в метках
