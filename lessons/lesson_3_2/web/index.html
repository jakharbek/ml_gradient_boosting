Зачем это нужно

В 1990 году Шапире доказал удивительное: если есть способ хоть чуть-чуть лучше угадывать, чем монетка, из него можно собрать сколь угодно точный классификатор. AdaBoost (Фройнд и Шапире, 1995) — практичный рецепт такой сборки.

AdaBoost — прямой предок градиентного бустинга. В уроке мы увидим, что он минимизирует определённую функцию потерь, и одна замена превращает его в градиентный бустинг.

Идея: сделать трудные объекты тяжелее

Каждый объект получает вес. Сначала веса равны. Обучаем слабого ученика (пень) по взвешенным данным. Объекты, на которых он ошибся, становятся тяжелее, остальные — легче. Следующий пень вынужден сосредоточиться на трудных объектах. Итог — взвешенное голосование пней.

Алгоритм по шагам

Метки кодируем как $y_i \in \{-1, +1\}$, ученики выдают $h_m(x) \in \{-1, +1\}$.

Шаг 0. Равные веса

$$w_i^{(1)} = \frac1n, \qquad i = 1, \dots, n$$

Шаг 1. Обучить ученика на взвешенных данных

Пень выбирает разбиение с учётом весов: ошибка на тяжёлом объекте стоит дороже. Взвешенная ошибка ученика:

$$\varepsilon_m = \frac{\sum_i w_i\, [h_m(x_i) \ne y_i]}{\sum_i w_i}$$

Если $\varepsilon_m \ge 0.5$ — ученик не лучше монетки, алгоритм останавливается.

Шаг 2. Вес ученика

$$\alpha_m = \frac12 \ln\frac{1 - \varepsilon_m}{\varepsilon_m}$$

Точный ученик (малое $\varepsilon$) получает большой голос; ученик-монетка ($\varepsilon = 0.5$) — нулевой. Почему именно логарифм — выводится в уроке .

Шаг 3. Пересчитать веса объектов

$$w_i \leftarrow w_i \cdot e^{-\alpha_m y_i h_m(x_i)}, \quad \text{затем нормировать к сумме 1}$$

При верном ответе $y_i h_m(x_i) = +1$ — вес умножается на $e^{-\alpha_m} < 1$; при ошибке — на $e^{\alpha_m} > 1$. После пересчёта взвешенная ошибка текущего ученика ровно 0.5: следующий ученик не может его повторить.

Шаг 4. Итоговый классификатор

$$F_M(x) = \sum_{m=1}^{M} \alpha_m h_m(x), \qquad \hat y = \operatorname{sign} F_M(x)$$

Обратите внимание: это аддитивная модель — сумма слабых учеников с коэффициентами. Та же форма, что у градиентного бустинга.

Гарантия и подвох

Если каждый ученик хоть немного лучше монетки, $\varepsilon_m \le \tfrac12 - \gamma$, то доля ошибок на обучении убывает экспоненциально:

$$\frac1n \sum_i [\operatorname{sign} F_M(x_i) \ne y_i] \;\le\; \prod_{m=1}^{M} 2\sqrt{\varepsilon_m(1-\varepsilon_m)} \;\le\; e^{-2\gamma^2 M}$$

Подвох — шум в метках. Объект с неверной меткой все ученики «не угадывают», и его вес растёт экспоненциально. Ансамбль тратит всё больше усилий на подгонку заведомо неправильных точек. Добавьте в виджете шум в метки и посмотрите, как веса концентрируются на нескольких точках. Градиентный бустинг с логистическими потерями к этому устойчивее — урок .

Разбор по косточкам

Слабый ученик на взвешенных данных
Взвешенный критерий разбиения

В сумме каждый объект учитывается со своим весом: $\sum w_i y_i$ вместо $\sum y_i$, $\sum w_i$ вместо $n$. В gbcourse это дерево с $g_i = -w_i y_i$, $h_i = w_i$.

Голос ученика $\alpha_m$

Логарифм отношения шансов верного ответа. Это оптимальный шаг для экспоненциальных потерь.

Обновление весов

Вес объекта после $m$ шагов пропорционален $e^{-y_i F_m(x_i)}$ — то есть экспоненциальным потерям на этом объекте. Отсюда связь с функциями потерь.

Варианты: SAMME, Real AdaBoost

SAMME обобщает AdaBoost на K классов, добавляя к $\alpha$ слагаемое $\ln(K-1)$ (в scikit-learn и без множителя ½). Real AdaBoost использует вероятности вместо меток.

В коде

import numpy as np
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier
from gbcourse import datasets, AdaBoost

X, y = datasets.classification_2d(kind="circles", n=160, noise=0.15, seed=5)
ada = AdaBoost(n_estimators=30).fit(X, y)
for m in range(5):
    print(f"шаг {m + 1}: ε = {ada.errors_[m]:.3f}, α = {ada.alphas_[m]:.3f}, max вес = {ada.weights_[m + 1].max():.3f}")

sk = AdaBoostClassifier(estimator=DecisionTreeClassifier(max_depth=1), n_estimators=30).fit(X, y)
print("совпадение прогнозов с sklearn:", (ada.predict(X) == sk.predict(X)).mean())

Итоги

  1. AdaBoost поддерживает веса объектов и увеличивает их там, где ансамбль ошибается.
  2. Вес ученика $\alpha_m = \tfrac12\ln\frac{1-\varepsilon_m}{\varepsilon_m}$; итог — $\operatorname{sign}\sum \alpha_m h_m(x)$.
  3. Ошибка на обучении убывает экспоненциально, если ученики лучше монетки.
  4. Слабое место — шумные метки: их веса взрываются.
