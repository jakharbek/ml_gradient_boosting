# Урок 4.1. Бустинг на остатках вручную

> Шесть квартир, два дерева и карандаш: каждое число градиентного бустинга — своими руками

**Модуль:** [4. Градиентный бустинг для регрессии: интуиция через остатки](../lesson_4/README.md) · **Уровень:** Начальный · **Время:** ~45 мин

**Нужно знать:** [4 Градиентный бустинг для регрессии: интуиция через остатки](../lesson_4/README.md), [2.1 Решающий пень: одно лучшее разбиение](../lesson_2_1/README.md)

Полный ручной расчёт: F₀ = среднее, остатки, лучший пень на остатках, обновление модели, вторая итерация; как меняются остатки и ошибка; то же с темпом ν = 0.5; проверка в коде.

## После урока вы сможете

- вычислить вручную F₀, остатки и первый пень бустинга на маленьком наборе
- обновить модель и пересчитать остатки для второй итерации
- объяснить, почему сумма квадратов остатков убывает с каждым шагом
- проверить ручной расчёт кодом (gbcourse и scikit-learn)

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_4_1/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
