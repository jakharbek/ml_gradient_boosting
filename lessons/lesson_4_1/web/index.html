Зачем это нужно

Лучший способ понять алгоритм — выполнить его руками. Шесть точек, две итерации, все числа круглые — и после этого урока в градиентном бустинге не останется ни одного загадочного шага.

Данные

Бустинг: квадратичные потери, деревья глубины 1 (пни), темп $\nu = 1$ (потом возьмём $\nu = 0.5$).

Две итерации карандашом

Шаг 0. Стартовая константа

$$F_0 = \bar y = \frac{2 + 4 + 3 + 7 + 9 + 11}{6} = \frac{36}{6} = 6$$

Первый прогноз: 6 млн для любой квартиры. Сумма квадратов ошибок: $(-4)^2 + (-2)^2 + (-3)^2 + 1^2 + 3^2 + 5^2 = 64$.

Шаг 1а. Остатки

$$r^{(1)} = y - F_0 = (2, 4, 3, 7, 9, 11) - 6 = (-4,\ -2,\ -3,\ 1,\ 3,\ 5)$$

Слева остатки отрицательны (модель завышает цену маленьких квартир), справа — положительны. Именно эту закономерность и уловит дерево.

Шаг 1в. Обновление модели

$$F_1(x) = F_0 + \nu\, h_1(x) = 6 + 1 \cdot (\mp 3) = \begin{cases} 3, & x \le 3.5 \\ 9, & x > 3.5 \end{cases}$$

Новые остатки: $r^{(2)} = y - F_1 = (-1,\ 1,\ 0,\ -2,\ 0,\ 2)$. Сумма квадратов упала с 64 до $1 + 1 + 0 + 4 + 0 + 4 = 10$ — ровно на выигрыш 54.

Сумма квадратов: $10 - 4.8 = 5.2$. Заметьте: порог 3.5 теперь бесполезен (выигрыш 0) — это разбиение уже «использовано» первым деревом.

Что мы увидели

  • Каждое дерево уменьшает сумму квадратов ровно на свой выигрыш: $64 \to 10 \to 5.2$.
  • Второе дерево ищет то, чего не нашло первое, — оно работает с остатками, а не с исходными ценами.
  • При $\nu = 1$ модель жадно подгоняется: квартира №6 уже предсказана идеально (остаток 0), и с 6 точками дальнейшие деревья начнут подгонять шум. Поэтому на практике $\nu < 1$ — следующий урок.

Разбор по косточкам

Остаток

$r_i = y_i - F_{m-1}(x_i)$ — сколько не хватает прогнозу. Знак — направление ошибки, модуль — её размер.

Остаток = антиградиент квадратичных потерь

$-\frac{\partial}{\partial F}\tfrac12(y - F)^2 = y - F$. Для других потерь «остаток» заменится антиградиентом.

Дерево на остатках
Структура: лучший порог по уменьшению суммы квадратов

Дерево группирует объекты с похожими остатками.

Листья: средний остаток

Лучшая константа для квадратичной ошибки внутри листа.

Шаг: $F_m = F_{m-1} + \nu h_m$

ν = 1 — принять исправление целиком, ν < 1 — лишь долю.

Почему ошибка на обучении не растёт

Дерево в каждом листе прибавляет средний остаток листа — это оптимальный сдвиг для квадратичной ошибки, и он не может её увеличить (при $0 < \nu \le 2$ ошибка в каждом листе уменьшается).

В коде

import numpy as np
from sklearn.ensemble import GradientBoostingRegressor
from gbcourse import datasets, GBRegressor

X, y = datasets.toy_regression()
model = GBRegressor(n_estimators=2, learning_rate=1.0, max_depth=1).fit(X, y)
print("F0 =", model.init_)
for m, (tree,) in enumerate(model.trees_, start=1):
    root = tree.nodes[0]
    L, R = tree.nodes[root.left], tree.nodes[root.right]
    print(f"h{m}: x ≤ {root.threshold} → {L.value:+.2f}, иначе {R.value:+.2f}")
print("F2 =", model.predict(X))
print("сумма квадратов по итерациям:", [round(2 * len(y) * v, 6) for v in model.history_["train"]])

sk = GradientBoostingRegressor(n_estimators=2, learning_rate=1.0, max_depth=1).fit(X, y)
print("sklearn F2 =", sk.predict(X))

В history_ хранятся средние потери $\tfrac12\,\mathrm{MSE}$, поэтому для суммы квадратов умножаем на $2n$.

Итоги

  1. $F_0 = 6$, остатки $(-4,-2,-3,1,3,5)$, первый пень $x \le 3.5$: $\mp 3$, сумма квадратов 64 → 10.
  2. Второй пень учится на новых остатках $(-1,1,0,-2,0,2)$ и выбирает порог 5.5: сумма квадратов 10 → 5.2.
  3. Каждое дерево уменьшает ошибку ровно на свой выигрыш; уже «объяснённые» разбиения больше не выгодны.
  4. ν = 1 быстро подгоняет обучающие данные; на практике берут ν < 1.
