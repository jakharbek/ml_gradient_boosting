# Урок 2.1. Решающий пень: одно лучшее разбиение

> Как из всех возможных порогов быстро найти тот, после которого ошибка меньше всего

**Модуль:** [2. Деревья решений — кирпичик бустинга](../lesson_2/README.md) · **Уровень:** Начальный · **Время:** ~60 мин

**Нужно знать:** [2 Деревья решений — кирпичик бустинга](../lesson_2/README.md), [1.2 Функции потерь и лучшая константа](../lesson_1_2/README.md)

Разбиение x ≤ t, среднее в каждой половине, сумма квадратов ошибок; перебор границ между отсортированными значениями; накопленные суммы и формула выигрыша n_L·n_R/n·(ȳ_L − ȳ_R)²; несколько признаков.

## После урока вы сможете

- вычислить сумму квадратов ошибок для заданного порога вручную
- объяснить, почему достаточно проверять пороги посередине между соседними значениями
- найти лучший порог за один проход по отсортированным данным с накопленными суммами
- вывести формулу выигрыша разбиения $\frac{n_L n_R}{n}(\bar y_L - \bar y_R)^2$
- пройти по шагам один проход с накопленными суммами и объяснить, почему одинаковые значения признака не разделяются
- объяснить, почему лучший порог даёт выигрыш даже на шуме, и назвать защиту от этого

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
