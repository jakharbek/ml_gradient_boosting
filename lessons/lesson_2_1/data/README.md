# Данные урока 2.1

Все наборы детерминированы: их можно пересоздать в Python или получить в веб-уроке
с теми же параметрами (генератор Mulberry32 одинаков в JS и Python).

## `toy6.csv` — Шесть точек для ручного счёта

Площадь квартиры (десятки м²) и цена (млн ₽). Те же точки используются в уроке 4.1.

- Столбцы: `x`, `y`; строк: 6.
- Как получить в Python: `datasets.toy_regression()`

## `steps.csv` — Ступенчатая функция с шумом

Данные виджета поиска порога.

- Столбцы: `x`, `y`; строк: 50.
- Как получить в Python: `datasets.regression_1d(kind='step', n=50, noise=0.4, seed=2)`
