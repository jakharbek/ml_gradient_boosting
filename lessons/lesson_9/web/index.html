Зачем этот модуль

Мы уже знаем алгоритм целиком: псевдо-остатки, второй порядок, штрафы, гистограммы. На практике его запускают через одну из трёх библиотек. Все три реализуют одно и то же ядро, но принимают разные инженерные решения. От этих решений зависят скорость, поведение по умолчанию и то, как библиотека обращается с категориями.

Кто и что придумал

ГодЧтоКлючевая идея

Уроки модуля

XGBoost на практике

Два API (sklearn-обёртка и xgb.train), ранняя остановка, метрики, важности признаков, сохранение модели.

LightGBM: рост по листьям, GOSS, EFB

Почему num_leaves важнее глубины, как выборка по градиентам экономит время, как склеиваются редкие признаки.

CatBoost: категории и симметричные деревья

Утечка целевой переменной в наивном кодировании категорий и её лечение; симметричные деревья как регуляризация и быстрый прогноз.

Сравнение и выбор

Один протокол для трёх библиотек: качество, время, чувствительность к параметрам.

Словарь параметров

Одно и то же понятие называется по-разному. Значения по умолчанию проверены на установленных версиях (XGBoost 3.4, LightGBM 4.7, CatBoost 1.2): их выводит ноутбук урока.

Три значения по умолчанию, о которых стоит помнить. (1) У XGBoost темп 0.3, у LightGBM 0.1, а CatBoost подбирает темп сам по размеру данных и числу итераций. (2) LightGBM ограничивает не глубину, а число листьев (31). Дерево растёт по листьям и может стать очень глубоким: в пределе — цепочка глубины 30. (3) LightGBM по умолчанию не штрафует листья (λ = 0) и требует минимум 20 объектов в листе; XGBoost ставит λ = 1 и ограничивает только сумму гессианов в листе (min_child_weight = 1).

В коде: одна задача — три библиотеки

XGBoost и LightGBM работают прямо в браузере; CatBoost для браузера не собран, его код — в ноутбуке урока.

import numpy as np
import lightgbm as lgb
import xgboost as xgb
from gbcourse import datasets

X, y = datasets.friedman1(n=2000, noise=1.0, seed=91)
X_tr, X_te, y_tr, y_te = datasets.train_test_split(X, y, test_size=0.3, seed=0)
models = {"XGBoost": xgb.XGBRegressor(), "LightGBM": lgb.LGBMRegressor(verbose=-1)}
for name, m in models.items():
    m.fit(X_tr, y_tr)
    print(f"{name:9s} MSE на тесте {np.mean((y_te - m.predict(X_te)) ** 2):.3f}")

Итоги

  1. XGBoost, LightGBM и CatBoost реализуют один алгоритм — бустинг второго порядка на гистограммах.
  2. Отличия: форма и порядок роста деревьев, выборка строк, работа с категориями, значения по умолчанию.
  3. Переходя между библиотеками, сверяйте не названия, а смысл параметров и их значения по умолчанию.
