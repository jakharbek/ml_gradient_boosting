## `hetero.csv` — Шум растёт с x

Гетероскедастичные данные: асимметричная потеря заметно сдвигает прогноз там, где шум большой.

- Столбцы: `x`, `y`; строк: 400.
- Как получить в Python: `datasets.regression_1d(kind='hetero', n=400, noise=0.5, seed=161)`
