Зачем это нужно

Чтобы бустинг предсказывал вероятности, нужны три вещи: шкала, на которой можно складывать деревья (логит), способ вернуться к вероятности (сигмоида) и функция потерь, которая честно оценивает вероятности (log-loss). Разберём каждую.

Вероятность → шансы → логарифм шансов

$$\text{шансы} = \frac{p}{1-p} \in (0, \infty), \qquad \operatorname{logit}(p) = \log\frac{p}{1-p} \in (-\infty, \infty)$$

Вероятность 0.5 — шансы 1:1 — логит 0. Вероятность 0.9 — шансы 9:1 — логит ≈ 2.2. Вероятность 0.99 — логит ≈ 4.6. Логит растягивает края отрезка [0, 1] на всю ось: на этой шкале складывать деревья безопасно.

Сигмоида — обратная к логиту функция: $\sigma(F) = \frac{1}{1 + e^{-F}}$. Её производная выражается через неё саму: $\sigma'(F) = \sigma(F)\,(1 - \sigma(F))$. Этот факт даст нам гессиан.

Log-loss из правдоподобия

Модель говорит: «объект класса 1 с вероятностью $p$». Если на самом деле $y = 1$, правдоподобие этого ответа — $p$; если $y = 0$ — $1 - p$. Кратко: $p^{y}(1-p)^{1-y}$. Максимизировать правдоподобие = минимизировать минус логарифм:

$$L(y, p) = -\big[\,y\log p + (1-y)\log(1-p)\,\big]$$

Если $p$ выражено через логит $F$, потери удобно записать прямо через $F$:

$$L(y, F) = \log\big(1 + e^{F}\big) - yF$$

Градиент по F

$$\frac{\partial L}{\partial F} = \frac{e^{F}}{1 + e^{F}} - y = \sigma(F) - y = p - y$$

Псевдо-остаток $r = y - p$ — «ответ минус вероятность». Он всегда в интервале (−1, 1).

Гессиан по F

$$\frac{\partial^2 L}{\partial F^2} = \sigma'(F) = p(1-p)$$

Максимален (0.25) при $p = 0.5$ — там, где модель не уверена; стремится к нулю при уверенных прогнозах. Понадобится для шага Ньютона (урок ).

Лучшая константа

$\sum_i (\sigma(F_0) - y_i) = 0 \Rightarrow \sigma(F_0) = \bar y$, то есть

$$F_0 = \log\frac{\bar y}{1 - \bar y}$$

Бустинг начинает с логарифма шансов доли класса 1. При 25% единиц $F_0 = \log(1/3) \approx -1.10$.

Почему не MSE на вероятностях

MSE: $(y - \sigma(F))^2$

Градиент по $F$: $-2(y - p)\,p(1-p)$. При уверенной ошибке ($p \approx 0$, $y = 1$) множитель $p(1-p) \approx 0$ — градиент почти нулевой. Модель «не замечает» своих худших ошибок.

Log-loss

Градиент $p - y$ при уверенной ошибке ≈ −1 — максимальный по модулю. Худшие ошибки исправляются первыми. Кроме того, log-loss — строго собственное правило оценки: его ожидание минимально, только когда $p$ равно истинной вероятности.

Разбор по косточкам

Шкала сложения: логит $F$

Деревья складываются в $F$; вероятность — $\sigma(F)$.

Потери: log-loss
Градиент $p - y$ → псевдо-остатки $y - p$

На них строится структура дерева.

Гессиан $p(1-p)$ → шаг Ньютона в листьях

$\gamma_j = \sum r_i / \sum p_i(1-p_i)$.

Старт: $F_0 = \operatorname{logit}(\bar y)$

Модель без признаков знает только долю классов.

Связь с экспоненциальными потерями AdaBoost

С $y \in \{-1, +1\}$ log-loss записывается как $\log(1 + e^{-2yF'})$ при $F = 2F'$ — отсюда «половина логарифма шансов» у AdaBoost.

В коде

import numpy as np
from gbcourse import get_loss, datasets

loss = get_loss("logistic")
y = np.array([1.0, 0.0, 1.0])
F = np.array([-2.0, 1.5, 0.3])
eps = 1e-5
num_g = (loss.pointwise(y, F + eps) - loss.pointwise(y, F - eps)) / (2 * eps)
num_h = (loss.pointwise(y, F + eps) - 2 * loss.pointwise(y, F) + loss.pointwise(y, F - eps)) / eps**2
print("градиент: формула", loss.gradient(y, F).round(6), " численно", num_g.round(6))
print("гессиан:  формула", loss.hessian(y, F).round(6), " численно", num_h.round(4))

X, yb = datasets.classification_2d(kind="blobs", n=200, noise=0.8, seed=62, balance=0.25)
print("доля класса 1:", yb.mean(), " F0 =", round(loss.init(yb), 4), " σ(F0) =", round(1 / (1 + np.exp(-loss.init(yb))), 4))

Итоги

  1. Логит переводит вероятность на всю числовую ось; сигмоида возвращает обратно.
  2. Log-loss — минус логарифм правдоподобия; через логит: $\log(1 + e^F) - yF$.
  3. Градиент $p - y$, гессиан $p(1-p)$, старт $F_0 = \operatorname{logit}(\bar y)$.
  4. MSE на вероятностях почти не штрафует уверенные ошибки градиентом — log-loss штрафует.
