Зачем это нужно

Случайный лес — главный конкурент бустинга и прекрасная точка сравнения. Понимая, почему лес работает, вы лучше поймёте, чем бустинг от него отличается.

К тому же две идеи леса перекочевали в бустинг почти без изменений: случайные подвыборки объектов (subsample) и признаков (colsample_*) — урок .

Бутстрэп: много выборок из одной

У нас одна обучающая выборка, а для усреднения нужны разные модели. Идея Эфрона (1979): создать «новые» выборки, вынимая $n$ объектов с возвращением. Одни объекты попадут дважды-трижды, другие — ни разу.

$$P(\text{объект не попал}) = \Big(1 - \frac1n\Big)^{n} \xrightarrow{n\to\infty} e^{-1} \approx 0.368$$

В каждую бутстрэп-выборку попадает около 63.2% различных объектов. Оставшиеся 36.8% — вне мешка (out-of-bag, OOB): на них дерево не училось, и они годятся для честной проверки.

Бэггинг = Bootstrap AGGregatING

$$\hat F_{\text{bag}}(x) = \frac1B \sum_{b=1}^{B} \hat h_b(x), \qquad \hat h_b \text{ обучено на бутстрэп-выборке } b$$

Базовые модели — глубокие деревья: у них малое смещение, а большой разброс гасит усреднение. Для классификации усредняют вероятности или голосуют.

OOB-оценка бесплатна. Для каждого объекта усредним только деревья, которые его не видели, и посчитаем ошибку. Это почти то же, что кросс-валидация, но без повторного обучения.

Случайный лес: декорреляция

Бутстрэп-деревья похожи друг на друга: сильный признак раз за разом оказывается в корне. Из урока мы знаем, что разброс среднего упирается в $\rho\sigma^2$ — корреляция мешает. Брейман (2001) предложил в каждом узле выбирать разбиение лишь среди $m$ случайных признаков из $d$:

  • регрессия: обычно $m \approx d/3$; классификация: $m \approx \sqrt d$;
  • меньше $m$ → деревья разнообразнее (ρ ↓), но каждое хуже (σ² и смещение ↑).

Разбор по косточкам

Источник разнообразия №1: бутстрэп объектов

Каждое дерево видит свою выборку. В бустинге аналог — subsample, но без возвращения.

Источник разнообразия №2: случайные признаки в узлах

max_features в лесе ↔ colsample_bynode в XGBoost.

Объединение: усреднение

Порядок деревьев не важен, их можно строить параллельно.

Чего лес не умеет
Не уменьшает смещение

Если дерево систематически ошибается (например, не видит тонкого эффекта), среднее ошибается так же.

Не экстраполирует

Как и любые деревья (урок ).

Когда выбрать лес

Нужна надёжная модель почти без настройки; много шума; важно не переобучиться по числу деревьев; параллельное обучение.

Когда выбрать бустинг

Нужна максимальная точность и есть время на настройку темпа, глубины, ранней остановки; структурированные табличные данные.

В коде

import numpy as np
from gbcourse import datasets, BaggingTrees
from gbcourse.metrics import mse

X, y = datasets.friedman1(n=300, noise=1.0, seed=31)
X_te, y_te = datasets.friedman1(n=2000, noise=1.0, seed=32)
for mf in (1.0, 0.5, 0.3, 0.1):
    rf = BaggingTrees(n_estimators=100, max_depth=None, max_features=mf, seed=0).fit(X, y)
    oob = rf.oob_predict(X)
    print(f"max_features = {mf}: OOB MSE {mse(y[~np.isnan(oob)], oob[~np.isnan(oob)]):.3f}, тест MSE {mse(y_te, rf.predict(X_te)):.3f}")

Итоги

  1. Бутстрэп создаёт разные выборки; каждая содержит ≈ 63% различных объектов.
  2. Бэггинг усредняет глубокие деревья и уменьшает разброс; число деревьев не переобучает.
  3. Случайный лес добавляет случайные признаки в узлах и снижает корреляцию деревьев.
  4. OOB-оценка — бесплатная валидация. Идеи подвыборок перешли в бустинг.
