## `friedman1.csv` — Задача Фридмана №1, 300 объектов

10 признаков, из которых информативны x0…x4. На ней видна польза случайного выбора признаков.

- Столбцы: `x0`, `x1`, `x2`, `x3`, `x4`, `x5`, `x6`, `x7`, `x8`, `x9`, `y`; строк: 300.
- Как получить в Python: `datasets.friedman1(n=300, noise=1.0, seed=31, n_features=10)`
