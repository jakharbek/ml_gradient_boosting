# Упражнения к уроку 3.1

Решения: [`solutions.py`](solutions.py) — `python lessons/lesson_3_1/exercises/solutions.py`.

## 1. OOB против кросс-валидации ★★☆

На `friedman1(n=300, noise=1.0, seed=31)` сравните OOB-оценку MSE леса из 100 деревьев с 5-fold
кросс-валидацией: значения и время.

## 2. Лес на плоскости ★☆☆

Для `classification_2d("spiral", n=400, noise=0.05, seed=3)` сравните точность леса с
`max_features=0.5` и `1.0`. Почему вариантов всего два?

## 3. Лес из мелких деревьев ★★☆

Обучите лес из 300 деревьев глубины 3 и бустинг из 300 деревьев глубины 3 (ν = 0.1) на задаче
Фридмана. Объясните разницу через смещение и разброс.
