# Урок 4.3. Градиентный бустинг с нуля на Python

> Собираем полноценный бустинг своими руками — дерево, модель, валидацию — и сверяем с scikit-learn до 15-го знака

**Модуль:** [4. Градиентный бустинг для регрессии: интуиция через остатки](../lesson_4/README.md) · **Уровень:** Средний · **Время:** ~60 мин

**Нужно знать:** [4.2 Темп обучения и число деревьев](../lesson_4_2/README.md), [2.3 Рекурсивное построение дерева и остановка](../lesson_2_3/README.md)

Реализация регрессионного дерева и бустинга на numpy шаг за шагом: fit/predict, поэтапные прогнозы, история потерь, ранняя остановка, подключаемая функция потерь; сверка с scikit-learn и разбор кода gbcourse.

## После урока вы сможете

- реализовать регрессионное дерево и градиентный бустинг на numpy
- добавить поэтапные прогнозы, историю потерь и раннюю остановку
- сделать функцию потерь подключаемой — первый шаг к общему алгоритму
- сверить реализацию с scikit-learn и читать код gbcourse

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_4_3/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
