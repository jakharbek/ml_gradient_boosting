# Упражнения к уроку 4.3

Решения: [`solutions.py`](solutions.py) — `python lessons/lesson_4_3/exercises/solutions.py`.
Реализация для доработки: [`../examples/gbm_from_scratch.py`](../examples/gbm_from_scratch.py).

## 1. Стохастичность ★★☆

Добавьте в `GradientBoosting` параметр `subsample ∈ (0, 1]`: каждое дерево обучается на случайной
доле объектов (без возвращения). Сравните валидацию при 1.0 и 0.5 на задаче Фридмана.

## 2. Ранняя остановка ★★☆

Добавьте `fit(X, y, eval_set=None, patience=None)`: обучение прекращается, если ошибка на
валидации не улучшалась `patience` итераций подряд; модель обрезается до лучшей итерации.

## 3. Быстрее ★★★

Сейчас `best_split` сортирует признаки в каждом узле. Отсортируйте их один раз для дерева и
в узлах фильтруйте глобальный порядок. Измерьте ускорение.
