Зачем этот модуль

Большинство задач бустинга в индустрии — классификация: дефолт по кредиту, клик, отток, мошенничество. Алгоритм тот же, что в модуле 5, — меняется функция потерь. Но есть тонкость: складывать надо не вероятности.

Почему нельзя складывать вероятности

Вероятность живёт на отрезке [0, 1]. Сумма деревьев — любое число. Если складывать вероятности, модель легко выдаст 1.3 или −0.2. Решение — складывать логарифм шансов (log-odds, логит), который пробегает всю числовую ось, и превращать его в вероятность сигмоидой:

$$F(x) = \log\frac{p(x)}{1 - p(x)} \in (-\infty, +\infty), \qquad p(x) = \sigma(F(x)) = \frac{1}{1 + e^{-F(x)}}$$

Потери — логистические (log-loss, бинарная кросс-энтропия). Их антиградиент по $F$ удивительно прост:

$$L = -\big[y\log p + (1-y)\log(1-p)\big], \qquad r = -\frac{\partial L}{\partial F} = y - p$$

Псевдо-остаток — «ответ минус вероятность»: +0.8, если объект класса 1 получил вероятность 0.2; −0.1, если объект класса 0 получил 0.1. Дерево учится на этих числах.

Песочница

Фон — вероятность класса 1 после $m$ деревьев, линия — граница $p = 0.5$. Включите «Показать псевдо-остатки»: точки окрасятся по $y - p$ (синий — отрицательный, красный — положительный). Именно эти числа будет приближать следующее дерево.

Модуль по косточкам

Логиты, сигмоида и log-loss

Что такое шансы и их логарифм, почему log-loss — правильная мера, $F_0 = \log\frac{\bar y}{1-\bar y}$, градиент и гессиан.

Шаг Ньютона в листьях

Значение листа $\sum r_i / \sum p_i(1-p_i)$ — вывод и ручной расчёт.

Многоклассовая классификация

Softmax, K деревьев на итерацию, градиенты $y_k - p_k$.

В коде

import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from gbcourse import datasets, GBClassifier

X, y = datasets.classification_2d(kind="moons", n=300, noise=0.25, seed=61)
ours = GBClassifier(n_estimators=150, learning_rate=0.3, max_depth=2).fit(X, y)
sk = GradientBoostingClassifier(n_estimators=150, learning_rate=0.3, max_depth=2).fit(X, y)
print("F0 = log-odds доли класса 1:", ours.init_, "=", np.log(y.mean() / (1 - y.mean())))
print("вероятности первых объектов:", ours.predict_proba(X[:3])[:, 1].round(3))
print("расхождение с sklearn:", np.abs(ours.predict_proba(X) - sk.predict_proba(X)).max())

Итоги

  1. Бустинг складывает логарифмы шансов; вероятность = сигмоида суммы.
  2. Потери — log-loss; псевдо-остатки $y - p$.
  3. Всё остальное — как в регрессии, кроме значений листьев (шаг Ньютона).
