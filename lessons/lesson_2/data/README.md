## `moons.csv` — Две луны, 160 точек

Данные виджета с двумерным деревом классификации.

- Столбцы: `x0`, `x1`, `y`; строк: 160.
- Как получить в Python: `datasets.classification_2d(kind='moons', n=160, noise=0.25, seed=4)`
