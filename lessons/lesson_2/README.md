# Модуль 2. Деревья решений — кирпичик бустинга

> Дерево от А до Я на восьми квартирах: вопросы, листья, перебор порогов, рост, остановка — и почему именно деревья стали кирпичиками бустинга

**Уровень:** Начальный · **Время:** ~90 мин

**Нужно знать:** [1.1 Обучение с учителем: данные, модель, ошибка](../lesson_1_1/README.md)

Двенадцать шагов на одном примере: прогноз как путь по вопросам, среднее в листе, перебор порогов и признаков, рекурсивный рост, переобучение, свойства дерева и мостик к бустингу.

## После урока вы сможете

- сделать прогноз дерева, пройдя путь от корня до листа, и назвать части дерева
- объяснить, почему в листе записано среднее, и посчитать ошибку SSE группы
- найти лучший вопрос вручную: перебрать пороги и признаки и сравнить выигрыши $\Delta$
- вырастить дерево рекурсией и объяснить, почему оно жадное
- показать на кривых ошибок, где дерево недообучено и где переобучено, и назвать ограничения роста
- перечислить свойства деревьев, важные для бустинга: нечувствительность к масштабу, взаимодействия, отсутствие экстраполяции, неустойчивость

## Уроки модуля

1. [2.1 Решающий пень: одно лучшее разбиение](../lesson_2_1/README.md) — Разбиение x ≤ t, среднее в каждой половине, сумма квадратов ошибок; перебор границ между отсортированными значениями; накопленные суммы и формула выигрыша n_L·n_R/n·(ȳ_L − ȳ_R)²; несколько признаков.
2. [2.2 Критерии разбиения: MSE, Джини, энтропия](../lesson_2_2/README.md) — Неоднородность узла и её уменьшение; дисперсия (MSE) для регрессии; индекс Джини, энтропия и доля ошибок для классификации; эквивалентность Джини и дисперсии для меток 0/1; взвешенные критерии.
3. [2.3 Рекурсивное построение дерева и остановка](../lesson_2_3/README.md) — Рекурсивная жадная схема CART, порядок роста, критерии остановки (глубина, размер листа, минимальный выигрыш, число листьев), сложность построения, отсечение ветвей.
4. [2.4 Дерево как слабый ученик: листья, сильные и слабые стороны](../lesson_2_4/README.md) — Значение листа как оптимальная константа для потерь; неспособность к экстраполяции; неустойчивость; лесенка вместо гладких функций; глубина = порядок взаимодействий; понятие слабого ученика.

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).

2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_2/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
