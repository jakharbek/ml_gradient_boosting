# Урок 6.2. Значения листьев: шаг Ньютона

> Лучшая добавка в лист для log-loss не имеет формулы — но одна итерация Ньютона даёт почти точный ответ: сумма остатков, делённая на сумму p(1 − p)

**Модуль:** [6. Градиентный бустинг для классификации](../lesson_6/README.md) · **Уровень:** Продвинутый · **Время:** ~45 мин

**Нужно знать:** [6.1 Бинарная классификация: логиты, сигмоида и log-loss](../lesson_6_1/README.md), [5.2 Алгоритм Фридмана (GBM/TreeBoost) по строчкам](../lesson_5_2/README.md), [1.3 Производная, градиент и градиентный спуск](../lesson_1_3/README.md)

Задача оптимального значения листа для log-loss, квадратичное приближение Тейлора, вывод γ = Σ(y − p)/Σp(1 − p), ручной расчёт первой итерации на восьми точках, сравнение с точным минимумом, связь с XGBoost.

## После урока вы сможете

- поставить задачу оптимального значения листа для log-loss
- вывести шаг Ньютона $\gamma = \sum r_i / \sum p_i(1-p_i)$ из разложения Тейлора
- выполнить вручную первую итерацию бустинга для классификации
- оценить, насколько шаг Ньютона близок к точному оптимуму
