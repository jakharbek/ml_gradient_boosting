Зачем это нужно

В TreeBoost значение листа — лучшая константная добавка для исходных потерь (урок ). Для L1 это медиана, а для log-loss явной формулы нет. Фридман предложил сделать один шаг Ньютона — и этот же приём стал сердцем XGBoost.

Задача листа

В листе $R_j$ объекты с ответами $y_i$ и текущими логитами $F_i$. Ищем добавку $\gamma$:

$$\gamma_j = \arg\min_\gamma \; \Phi(\gamma), \qquad \Phi(\gamma) = \sum_{i \in R_j} L\big(y_i, F_i + \gamma\big) = \sum_{i\in R_j} \Big[\log\big(1 + e^{F_i + \gamma}\big) - y_i (F_i + \gamma)\Big]$$

Условие минимума $\Phi'(\gamma) = \sum_i \big(\sigma(F_i + \gamma) - y_i\big) = 0$ — нелинейное уравнение без решения в общем виде.

Шаг Ньютона

Разложим $\Phi$ в ряд Тейлора около $\gamma = 0$ до второго порядка (урок ):

$$\Phi(\gamma) \approx \Phi(0) + \gamma \sum_i g_i + \frac{\gamma^2}{2}\sum_i h_i, \qquad g_i = p_i - y_i,\ h_i = p_i(1 - p_i)$$

Минимум параболы — там, где производная равна нулю:

$$\gamma_j = -\frac{\sum_{i\in R_j} g_i}{\sum_{i \in R_j} h_i} = \frac{\sum_{i\in R_j} (y_i - p_i)}{\sum_{i\in R_j} p_i (1 - p_i)}$$

Смысл: числитель — сколько «не хватает» вероятности в листе; знаменатель — насколько чувствительны вероятности к сдвигу логита. Где модель уверена ($p$ близко к 0 или 1), знаменатель мал — и нужен больший сдвиг логита.

Первая итерация вручную

Восемь точек: $x = 1..8$, $y = (0, 0, 0, 1, 0, 1, 1, 1)$. Пни, ν = 1.

Шаг 0. Старт

Доля единиц $\bar y = 0.5$, значит $F_0 = \log\frac{0.5}{0.5} = 0$ и $p_i = 0.5$ для всех. Псевдо-остатки $r_i = y_i - 0.5 = \pm 0.5$, гессианы $h_i = 0.25$.

Шаг 1. Структура пня

Разбиение ищем по псевдо-остаткам, как в регрессии. Пороги 3.5 и 5.5 дают одинаковый выигрыш 1.2 (симметрия); первый по порядку — 3.5. Слева $x \in \{1, 2, 3\}$ — все класса 0; справа пять точек, из них одна класса 0.

Шаг 2. Значения листьев

$$\gamma_{\text{лев}} = \frac{-0.5 \cdot 3}{0.25 \cdot 3} = -2, \qquad \gamma_{\text{прав}} = \frac{0.5 \cdot 4 - 0.5}{0.25 \cdot 5} = \frac{1.5}{1.25} = 1.2$$

Для сравнения, среднее псевдо-остатков дало бы −0.5 и 0.3 — в четыре раза меньше: без деления на гессиан шаг в логитах слишком робкий.

Шаг 3. Новые вероятности

$F_1 = -2$ слева: $p = \sigma(-2) \approx 0.119$. $F_1 = 1.2$ справа: $p = \sigma(1.2) \approx 0.769$. Точный оптимум для правого листа — там, где средняя вероятность равна доле единиц: $\sigma(\gamma) = 0.8$, $\gamma = \log 4 \approx 1.386$. Ньютон дал 1.2 — недолёт на 13%, зато без итераций. А для левого листа точного конечного оптимума нет вовсе (все объекты одного класса, $\gamma \to -\infty$), и шаг Ньютона разумно ограничивает прыжок.

Проверьте в песочнице модуля 6 или в ячейке ниже: GBClassifier(n_estimators=1, learning_rate=1, max_depth=1) на этих точках даёт ровно −2 и 1.2.

Разбор по косточкам

Градиент листа $G = \sum g_i$

Куда и насколько тянет лист; для log-loss $G = \sum(p_i - y_i)$.

Гессиан листа $H = \sum h_i$

Кривизна: насколько быстро меняются потери; $H = \sum p_i(1 - p_i)$. «Эффективное число объектов» листа.

Шаг $-G/H$

Минимум параболического приближения.

С регуляризацией: $-G/(H + \lambda)$

XGBoost добавляет λ в знаменатель — это спасает листья, где $H$ почти ноль (чистые уверенные листья), от гигантских значений.

Обобщение: бустинг второго порядка

Если строить по $g$ и $h$ и саму структуру дерева, получится XGBoost.

В коде

import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from gbcourse import datasets, GBClassifier

X, y = datasets.toy_classification()
m = GBClassifier(n_estimators=1, learning_rate=1.0, max_depth=1).fit(X, y)
tree = m.trees_[0][0]
root = tree.nodes[0]
print("F0 =", m.init_, "| порог:", root.threshold)
print("листья (шаг Ньютона):", tree.nodes[root.left].value, tree.nodes[root.right].value)
sk = GradientBoostingClassifier(n_estimators=1, learning_rate=1.0, max_depth=1).fit(X, y)
print("sklearn F1:", sk.decision_function(X).round(4))

# точный оптимум правого листа: σ(γ) = доля единиц 0.8
print("точный γ правого листа = log 4 =", round(np.log(4), 4))

Итоги

  1. Значение листа для log-loss — минимум нелинейной функции; явной формулы нет.
  2. Один шаг Ньютона: $\gamma = \sum(y_i - p_i) / \sum p_i(1-p_i)$ — почти точный оптимум без итераций.
  3. На восьми точках: $F_0 = 0$, порог 3.5, листья −2 и 1.2.
  4. Та же формула $-G/H$ (с $+\lambda$) — основа значений листьев XGBoost.
