# Урок 13.3. Бустинг в эксплуатации

> Модель обучена — работа только начинается: сохранение и версии, скорость прогноза, сдвиг данных, мониторинг и переобучение

**Модуль:** [13. Продвинутые задачи: ранжирование, неопределённость, эксплуатация](../lesson_13/README.md) · **Уровень:** Продвинутый · **Время:** ~40 мин

**Нужно знать:** [13.2 Калибровка вероятностей и интервалы прогноза](../lesson_13_2/README.md), [9.1 XGBoost на практике](../lesson_9_1/README.md)

Что происходит с бустингом после обучения. Форматы моделей и воспроизводимость. Скорость прогноза: пакетами против одиночных запросов. Главный риск — сдвиг данных: деревья не экстраполируют, прогноз за пределами обучающего диапазона постоянен. Обнаружение сдвига: PSI и состязательная проверка. Расхождение обучения и эксплуатации, мониторинг, чек-лист.

## После урока вы сможете

- сохранять модель переносимо и воспроизводимо
- объяснить, почему деревья не экстраполируют, и обнаруживать сдвиг данных (PSI, состязательная проверка)
- составить план мониторинга и переобучения

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_13_3/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
