Зачем это нужно

Классов бывает больше двух: категория товара, тип обращения в поддержку, диагноз. Бинарная схема обобщается естественно — логитов становится $K$, а вместо сигмоиды работает softmax.

Softmax: K логитов → K вероятностей

$$p_k(x) = \frac{e^{F_k(x)}}{\sum_{j=1}^{K} e^{F_j(x)}}, \qquad k = 1, \dots, K$$

Вероятности положительны и в сумме дают 1. Прибавьте ко всем логитам одно и то же число — вероятности не изменятся. Поэтому логиты определены с точностью до сдвига, и библиотеки часто центрируют их (scikit-learn и gbcourse начинают с $F_{k,0} = \log \pi_k - \overline{\log\pi}$, где $\pi_k$ — доли классов).

При $K = 2$ softmax сводится к сигмоиде от разности логитов: $p_1 = \sigma(F_1 - F_0)$. Бинарный бустинг — частный случай, в котором хватает одного логита.

Кросс-энтропия и её градиент

Потери — минус логарифм вероятности правильного класса. Закодируем ответ вектором $y_k = [\,y = k\,]$:

$$L = -\sum_{k} y_k \log p_k = -F_{y} + \log\sum_j e^{F_j}, \qquad \frac{\partial L}{\partial F_k} = p_k - y_k$$

Та же форма, что в бинарном случае: для каждого класса псевдо-остаток $y_k - p_k$. Правильный класс тянет свой логит вверх, остальные классы — свои логиты вниз.

Итерация: K деревьев

1. Вероятности

Для каждого объекта из текущих логитов $F_{1}, \dots, F_{K}$ считаем $p_1, \dots, p_K$.

2. K наборов псевдо-остатков

$r_{ik} = y_{ik} - p_{ik}$ для каждого класса $k$ — все по одним и тем же текущим вероятностям.

3. K деревьев

Дерево $h_{mk}$ учится на $r_{\cdot k}$. Значения листьев у Фридмана — шаг Ньютона с диагональным гессианом и множителем $(K-1)/K$:

$$\gamma_{jkm} = \frac{K-1}{K}\cdot\frac{\sum_{i \in R_{jkm}} r_{ik}}{\sum_{i\in R_{jkm}} |r_{ik}|\,(1 - |r_{ik}|)}$$

XGBoost использует гессиан $2p_k(1-p_k)$ — похожая поправка.

4. Обновление

$F_k \leftarrow F_k + \nu\, h_{mk}$ для всех $k$. Итерация стоит в $K$ раз дороже бинарной — при 100 классах это существенно.

Цвет фона — класс с наибольшей вероятностью, насыщенность — уверенность модели.

Альтернатива: один против всех

Можно обучить $K$ независимых бинарных классификаторов «класс $k$ против остальных» и нормировать их вероятности. Это проще распараллелить, но вероятности не согласованы (их сумма не 1 без нормировки), а обучение не учитывает конкуренцию классов. Softmax-бустинг — стандарт в XGBoost (multi:softprob), LightGBM (multiclass) и CatBoost (MultiClass).

В коде

import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from gbcourse import datasets, GBClassifier

X, y = datasets.classification_2d(kind="blobs3", n=300, noise=0.7, seed=65)
ours = GBClassifier(n_estimators=100, learning_rate=0.2, max_depth=2).fit(X, y)
sk = GradientBoostingClassifier(n_estimators=100, learning_rate=0.2, max_depth=2).fit(X, y)
print("деревьев в модели:", len(ours.trees_), "итераций ×", len(ours.trees_[0]), "класса")
print("начальные логиты:", np.round(ours.init_, 4), " (сумма", round(float(np.sum(ours.init_)), 10), ")")
print("расхождение вероятностей с sklearn:", np.abs(ours.predict_proba(X) - sk.predict_proba(X)).max())

Итоги

  1. K логитов, softmax даёт вероятности; логиты определены с точностью до сдвига.
  2. Кросс-энтропия, градиент $p_k - y_k$, псевдо-остатки $y_k - p_k$.
  3. На итерации — K деревьев по одним и тем же текущим вероятностям; листья — шаг Ньютона с множителем $(K-1)/K$.
