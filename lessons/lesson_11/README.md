# Модуль 11. Настройка гиперпараметров

> Какие параметры действительно важны, как они связаны между собой и сколько вычислений стоит качество

**Уровень:** Продвинутый · **Время:** ~25 мин

**Нужно знать:** [9 Библиотеки бустинга: XGBoost, LightGBM, CatBoost](../lesson_9/README.md), [7 Регуляризация градиентного бустинга](../lesson_7/README.md)

Карта ошибки LightGBM по сетке «темп × число листьев» на реальных запусках: темп почти не влияет на качество при ранней остановке, но определяет число деревьев и время; размер деревьев важен и зависит от задачи. Что это значит для стратегии настройки; карта модуля.

## После урока вы сможете

- объяснить связь темпа, числа деревьев и ранней остановки
- прочитать карту ошибки и отличить значимую разницу от шума
- ориентироваться в уроках модуля

## Уроки модуля

1. [11.1 Карта гиперпараметров и стратегия настройки](../lesson_11_1/README.md) — Анализ чувствительности LightGBM: семь параметров по одному вокруг значений по умолчанию на двух задачах, с разбросом по разбиениям. Размер деревьев — главный рычаг, доля признаков может навредить при взаимодействиях, большинство остальных эффектов в пределах шума. Пошаговая стратегия настройки и её проверка.
2. [11.2 Кросс-валидация и поиск параметров: сетка, случайный поиск, Optuna](../lesson_11_2/README.md) — Разброс оценки по одному разбиению и кросс-валидация; вложенная CV для честной итоговой оценки. Перебор по сетке против случайного поиска на реальной поверхности ошибки LightGBM (случайный поиск выигрывает при любом бюджете, когда важны не все параметры). Байесовский поиск TPE в Optuna и отсечение неудачных запусков.
