Зачем это нужно

Функция потерь определяет, что именно предсказывает модель. Бустинг с L2 предсказывает условное среднее, с L1 — медиану, с квантильными потерями — любой квантиль. Выбор потерь — это выбор вопроса, на который отвечает модель.

Устойчивость к выбросам

С L2 каждый выброс создаёт огромный псевдо-остаток, и деревья тратят листья на то, чтобы его «поймать». С L1 выброс — просто ещё один знак «+1»: его голос равен голосу обычной точки. Хьюбер ведёт себя как L2 у центра (эффективно на чистых данных) и как L1 на хвостах.

Как выбрать δ для Хьюбера? Порядка типичного размера нормальной ошибки: например, 1.35·σ шума (95% эффективности L2 на нормальном шуме). scikit-learn по умолчанию подбирает δ адаптивно — как квантиль уровня alpha=0.9 модулей текущих остатков — и пересчитывает на каждой итерации.

Предсказательные интервалы квантильным бустингом

Обучим две модели: на квантиль 0.1 и на квантиль 0.9. Между ними — интервал, который должен содержать около 80% новых наблюдений. Шум в данных растёт с $x$ — хорошая модель интервала должна расширяться.

Три ловушки квантильных интервалов:

  1. Покрытие на обучении оптимистично — проверяйте на отложенных данных (виджет считает покрытие на новых точках).
  2. Квантили могут пересекаться: модели обучаются независимо, и в отдельных точках $q_{0.1} > q_{0.9}$. Лечится сортировкой прогнозов.
  3. Гарантий нет: для строгого покрытия используют конформные методы поверх любой модели (урок ).

Как выбрать потери

Какой ответ нужен бизнесу?
Среднее (план продаж, сумма по многим объектам)

L2: ошибки усредняются, итоговая сумма несмещена.

Типичное значение (время доставки, цена «обычной» квартиры)

L1 или Хьюбер: не зависит от редких экстремумов.

Запас с заданной надёжностью (склад, мощности)

Квантильная с α = доля случаев, когда запаса должно хватить.

Есть ли в y выбросы или ошибки разметки?

Да → Хьюбер или L1. Нет → L2 обычно эффективнее.

Нестандартная цена ошибки?

Напишите свою функцию потерь: нужны градиент (и для XGBoost — гессиан).

Счётные данные (число покупок, звонков)?

Пуассоновские потери: прогноз всегда положителен, $F = \log\mu$.

В коде

import numpy as np
from gbcourse import datasets, GBRegressor

X, y = datasets.regression_1d(kind="hetero", n=400, noise=0.5, seed=54)
X_te, y_te = datasets.regression_1d(kind="hetero", n=2000, noise=0.5, seed=55)
q = {}
for a in (0.1, 0.5, 0.9):
    q[a] = GBRegressor(loss="quantile", quantile_alpha=a, n_estimators=200, learning_rate=0.1, max_depth=2).fit(X, y)
lo, hi = q[0.1].predict(X_te), q[0.9].predict(X_te)
lo, hi = np.minimum(lo, hi), np.maximum(lo, hi)          # защита от пересечения квантилей
print("покрытие интервала на новых данных:", np.mean((y_te >= lo) & (y_te <= hi)).round(3), "(цель 0.8)")
for part, mask in (("x < 3", X_te[:, 0] < 3), ("x > 7", X_te[:, 0] > 7)):
    print(f"  средняя ширина при {part}: {np.mean(hi[mask] - lo[mask]):.2f}")

То же в scikit-learn: GradientBoostingRegressor(loss="quantile", alpha=0.9); в LightGBM — objective="quantile", alpha=0.9; в XGBoost ≥ 2.0 — objective="reg:quantileerror", quantile_alpha=[0.1, 0.9] (несколько квантилей одной моделью).

Итоги

  1. Потери определяют, что предсказывает модель: среднее (L2), медиану (L1), квантиль (квантильная).
  2. L1 и Хьюбер устойчивы к выбросам; L2 эффективнее на чистых данных.
  3. Пара квантильных моделей даёт интервал; проверяйте покрытие на новых данных и следите за пересечениями.
