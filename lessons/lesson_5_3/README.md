# Урок 5.3. Функции потерь для регрессии: L2, L1, Хьюбер, квантильная

> Как выбор потерь меняет то, что предсказывает бустинг: среднее, медиану, устойчивый центр или квантиль — вплоть до предсказательных интервалов

**Модуль:** [5. Бустинг как градиентный спуск в пространстве функций](../lesson_5/README.md) · **Уровень:** Средний · **Время:** ~45 мин

**Нужно знать:** [5.2 Алгоритм Фридмана (GBM/TreeBoost) по строчкам](../lesson_5_2/README.md)

Полная карточка каждой потери (F₀, псевдо-остатки, значение листа, что предсказывает), устойчивость к выбросам, квантильный бустинг и интервалы с проверкой покрытия, практические рекомендации.

## После урока вы сможете

- для L2, L1, Хьюбера и квантильных потерь назвать F₀, псевдо-остатки, значение листа и предсказываемую величину
- выбрать функцию потерь под задачу: выбросы, асимметричная цена ошибки, интервалы
- построить предсказательный интервал двумя квантильными моделями и проверить его покрытие
- понимать ограничения: пересечение квантилей, покрытие на новых данных
