## `hetero.csv` — Растущий шум: 400 точек

y = sin(x) + 0.3x + шум, стандартное отклонение шума растёт с x. Для квантильного бустинга и интервалов.

- Столбцы: `x`, `y`; строк: 400.
- Как получить в Python: `datasets.regression_1d(kind='hetero', n=400, noise=0.5, seed=54)`
