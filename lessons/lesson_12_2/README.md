# Урок 12.2. Значения Шепли и SHAP

> Как честно разделить прогноз между признаками: коалиции, аксиомы, быстрый алгоритм для деревьев и графики, которые из этого получаются

**Модуль:** [12. Интерпретация бустинга](../lesson_12/README.md) · **Уровень:** Экспертный · **Время:** ~45 мин

**Нужно знать:** [12.1 Важность признаков: какие бывают и где обманывают](../lesson_12_1/README.md)

Значения Шепли из теории игр: игроки — признаки, выигрыш коалиции — ожидаемый прогноз при известных признаках. Разбор по определению на модели с тремя признаками (все 8 коалиций). Аксиомы, почему решение единственно. TreeSHAP и два способа «не знать» признак. Сводный график и график зависимости с раскраской по взаимодействию.

## После урока вы сможете

- вычислить значения Шепли по определению для маленькой модели
- перечислить аксиомы Шепли и объяснить их смысл для моделей
- читать сводный график SHAP и график зависимости, находить взаимодействия
