Зачем это нужно

В уроке мы разложили прогноз в сумму вкладов признаков. Но разложить можно по-разному. Если признаки взаимодействуют ($\sin(\pi x_0 x_1)$), кому засчитать общий эффект — $x_0$ или $x_1$? Шепли (1953, Нобелевская премия 2012) доказал: есть ровно один способ, удовлетворяющий четырём разумным требованиям.

Признаки как игроки

Объект $x$ зафиксирован. Коалиция $S$ — множество признаков, значения которых мы «знаем». Её ценность — ожидаемый прогноз, когда известны только признаки из $S$:

$$v(S) = \mathbb{E}\big[F(X) \mid X_S = x_S\big], \qquad v(\varnothing) = \varphi_0 = \mathbb{E}[F(X)], \qquad v(\{1..d\}) = F(x).$$

Вклад признака $j$ — его средний предельный вклад $v(S \cup \{j\}) - v(S)$ по всем порядкам, в которых признаки могли бы «присоединяться» к коалиции:

$$\varphi_j = \sum_{S \subseteq \{1..d\} \setminus \{j\}} \frac{|S|!\,(d - |S| - 1)!}{d!}\,\big[v(S \cup \{j\}) - v(S)\big].$$

Аксиомы: почему именно так

Эффективность (local accuracy)

$\varphi_0 + \sum_j \varphi_j = F(x)$: вклады полностью объясняют прогноз, без остатка.

Симметрия

Если признаки $i$ и $j$ дают одинаковый вклад в любую коалицию, их значения Шепли равны. Взаимодействие $x_0 x_1$ делится поровну, если признаки входят в него одинаково.

Нулевой игрок (dummy)

Признак, который ни в одной коалиции ничего не меняет, получает ноль. Модель не использует $x_6$ — $\varphi_6 = 0$.

Аддитивность

Для суммы моделей вклады складываются. Бустинг — сумма деревьев, поэтому значения Шепли модели — сумма значений Шепли деревьев. Именно это позволяет считать их по деревьям по отдельности.

Теорема Шепли: эти четыре требования выполняет единственное распределение — формула выше.

TreeSHAP: быстро и точно для деревьев

Ценность коалиции для дерева

Как посчитать $\mathbb{E}[f(X) \mid X_S = x_S]$ для дерева? Спускаемся от корня. В узле с признаком из $S$ идём туда, куда отправляет $x$. В узле с неизвестным признаком идём в обе ветви и усредняем их с весами — долями обучающих объектов в ветвях (cover). Так работает expected_value в gbcourse.

Полный перебор и TreeSHAP

По определению нужно $2^d$ коалиций: наш перебор в gbcourse годится для $d \lesssim 12$. TreeSHAP (Лундберг и др., 2018) получает те же числа за $O(T L D^2)$ — полиномиально по глубине, без перебора. Тест проекта сверяет наш перебор с shap.TreeExplainer до $10^{-15}$.

Два способа «не знать» признак

«Путевой» (tree_path_dependent, по умолчанию) усредняет по долям обучающих объектов в узлах — это условное ожидание по дереву. «Интервенционный» (interventional) подставляет значения признака из фоновой выборки, как будто признак изменили независимо от остальных. При коррелированных признаках результаты могут различаться. В ноутбуке урока с почти точной копией $x_0$ различия оказались невелики (средний |φ| копии 0.69 и 0.74). Важнее другое: в обоих способах вклад $x_0$ поделён между двумя столбцами — как и важность в уроке .

Сводный график и график зависимости

Посчитав вклады для многих объектов, получаем два главных графика. Сводный (beeswarm): для каждого признака — облако вкладов по объектам, цвет — значение признака. Зависимость: вклад признака против его значения, цвет — значение другого признака; разброс по вертикали при одном значении выдаёт взаимодействие.

График зависимости $x_0$ с раскраской по $x_1$: в целом вклад $x_0$ растёт с $x_0$ примерно от −4 до +2 и выходит на плато — это форма $\sin(\pi x_0 x_1)$. Разброс по вертикали при одном значении $x_0$ выдаёт взаимодействие. При малых $x_0$ объекты с большим $x_1$ (красные) получают заметно более отрицательный вклад (около −4.5…−5.8), чем с малым $x_1$ (синие, около −3…−3.5): при большом $x_1$ произведение $x_0 x_1$, а с ним и синус, сильнее зависит от $x_0$.

В коде

import itertools, math
import numpy as np
from gbcourse import datasets, GBRegressor
from gbcourse.explain import expected_value, shapley_values

X, y = datasets.friedman1(n=600, noise=1.0, seed=180, n_features=7)
Xs = X[:, [0, 1, 3]]                         # три признака: x0, x1, x3
model = GBRegressor(n_estimators=50, max_depth=2, learning_rate=0.2).fit(Xs, y)
x = Xs[0]
v = lambda S: float(np.ravel(model.init_)[0]) + sum(model.learning_rate * expected_value(st[0], x, set(S)) for st in model.trees_)
d, phi = 3, np.zeros(3)
for j in range(d):
    others = [k for k in range(d) if k != j]
    for r in range(d):
        for S in itertools.combinations(others, r):
            w = math.factorial(len(S)) * math.factorial(d - len(S) - 1) / math.factorial(d)
            phi[j] += w * (v(S + (j,)) - v(S))
print("по определению:", np.round(phi, 6))
print("shapley_values:", np.round(shapley_values(model, x)[1], 6))

Итоги

  1. Значение Шепли — средний предельный вклад признака по всем порядкам присоединения к коалиции.
  2. Это единственное распределение с эффективностью, симметрией, нулевым игроком и аддитивностью.
  3. Для деревьев TreeSHAP считает точные значения быстро; результат зависит от того, как «не знать» признак.
  4. Сводный график показывает важность и направление влияния, график зависимости — форму и взаимодействия.
