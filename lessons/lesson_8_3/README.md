# Урок 8.3. Поиск разбиений: точный перебор, гистограммы и пропуски

> Как библиотеки перебирают пороги на миллионах строк за доли секунды и что они делают с пропущенными значениями

**Модуль:** [8. XGBoost изнутри: бустинг второго порядка](../lesson_8/README.md) · **Уровень:** Продвинутый · **Время:** ~40 мин

**Нужно знать:** [8.2 Регуляризованная цель: веса листьев и выигрыш разбиения](../lesson_8_2/README.md)

Точный жадный перебор по отсортированным значениям с накопленными суммами G и H; гистограммный поиск по квантильным корзинам (max_bin), вычитание гистограмм; обработка пропусков с выбором направления по умолчанию. Скорость и точность tree_method exact / approx / hist.

## После урока вы сможете

- описать точный перебор порогов через накопленные суммы и оценить его сложность
- объяснить гистограммный поиск, роль max_bin и трюк с вычитанием гистограмм
- объяснить, как выбирается направление по умолчанию для пропусков
