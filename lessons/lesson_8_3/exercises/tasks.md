# Упражнения к уроку 8.3

Решения: [`solutions.py`](solutions.py) — `python lessons/lesson_8_3/exercises/solutions.py`.

## 1. Гистограмма с пропусками ★★★

Реализуйте поиск лучшего разбиения одного признака по гистограмме (`make_bins`, `bin_codes` из `gbcourse.tree`)
с учётом пропусков: для каждого порога два варианта — пропуски влево и вправо. Сверьте порог, направление
и выигрыш с `RegressionTree(max_depth=1, max_bins=32, reg_lambda=1)` на `friedman1(n=1000, seed=84)`,
где 20% значений признака $x_3$ заменены на NaN.

## 2. Потеря выигрыша ★☆☆

Для первого дерева (квадратичная потеря, λ = 1) на `friedman1(n=3000, noise=1.0, seed=84)` посчитайте,
какую долю выигрыша лучшего порога признака $x_0$ теряет гистограмма из $B$ корзин, $B = 2 … 256$.
