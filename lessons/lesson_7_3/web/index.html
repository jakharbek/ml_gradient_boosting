Зачем это нужно

Дерево можно сдерживать двумя способами: запретить ему расти (ограничения структуры) или сделать рост «дорогим» (штрафы). Второй способ — фирменная черта XGBoost и LightGBM, и он опирается на значения листьев второго порядка из урока .

min_child_weight — это минимум $H = \sum h_i$ в листе. Для L2 $h_i = 1$, и это просто минимум объектов. Для log-loss $h_i = p_i(1-p_i)$: лист из сотни объектов, где модель уже уверена ($p \approx 0.99$), имеет $H \approx 1$ — его разбиение запретит min_child_weight=2.

Штрафы на листья

XGBoost добавляет к потерям штраф за сложность каждого дерева:

$$\Omega(h) = \gamma T + \frac{\lambda}{2}\sum_{j=1}^{T} w_j^2 + \alpha \sum_{j=1}^{T} |w_j|$$

Здесь $T$ — число листьев, $w_j$ — их значения. Отсюда (урок ) получаются формулы значения листа и выигрыша разбиения:

$$w_j^* = -\frac{T_\alpha(G_j)}{H_j + \lambda}, \qquad \text{gain} = \frac12\left[\frac{T_\alpha(G_L)^2}{H_L+\lambda} + \frac{T_\alpha(G_R)^2}{H_R+\lambda} - \frac{T_\alpha(G)^2}{H + \lambda}\right] - \gamma$$

где $T_\alpha(G) = \operatorname{sign}(G)\max(|G| - \alpha, 0)$ — «мягкий порог».

λ (reg_lambda, L2): сжатие к нулю

Лист со средним псевдо-остатком $\bar r$ и $n$ объектами (L2): $w = \frac{n\bar r}{n + \lambda}$. Большие листья почти не меняются, маленькие сжимаются сильно — как «добавить λ фиктивных объектов с остатком 0». В XGBoost по умолчанию λ = 1.

α (reg_alpha, L1): обнуление слабых листьев

Если $|G| \le \alpha$, вес листа ровно ноль: лист с небольшой суммарной «тягой» ничего не меняет.

γ (gamma, min_split_gain): цена листа

Разбиение делается, только если выигрыш больше γ. Две тонкости реализации:

  • Масштаб. В статье XGBoost и в gbcourse выигрыш записан с множителем ½ (формула выше). Сами библиотеки XGBoost и LightGBM считают его без ½ и с этим удвоенным числом сравнивают gamma / min_split_gain. Поэтому γ = 5 в gbcourse соответствует gamma=10 в XGBoost — проверено в ноутбуке урока .
  • Когда отсекать. gbcourse и LightGBM отказываются от слабого разбиения сразу. XGBoost сначала растит дерево до max_depth, а потом снизу вверх срезает разбиения с выигрышем меньше γ. Слабое разбиение, за которым идут сильные, XGBoost сохранит.

Эффект на модели

Без штрафов модель с ν = 0.3 переобучается: ½MSE на новых данных 0.301 при почти нулевой ошибке обучения. Любой из трёх штрафов это исправляет: λ = 10 → 0.233, γ = 0.2 → 0.215, min_child_weight = 10 → 0.230. Заметьте, насколько по-разному они действуют: λ почти не меняет число листьев (около 15), а только сжимает их значения; γ = 0.2 оставляет в среднем 2 листа.

γ измеряется в единицах потерь. Выигрыш разбиения растёт с масштабом $y$ и числом объектов, поэтому «хорошее» γ для одних данных бессмысленно для других. На задаче Фридмана ($y$ порядка 15, 210 объектов) уже γ = 5 урезает деревья с 22 до 3 листьев и ухудшает качество: ½MSE 3.86 → 4.05, а при γ = 40 — 4.87. На этих же данных λ = 5 немного помогает (3.72). Поэтому γ подбирают по сетке в логарифмической шкале, начиная с малых значений, а в XGBoost по умолчанию γ = 0.

В коде

import numpy as np
from gbcourse import datasets, GBRegressor

X, y = datasets.friedman1(n=300, noise=2.0, seed=75)
configs = {"без штрафов": {}, "λ = 5": dict(reg_lambda=5), "γ = 20": dict(gamma=20),
           "min_child_weight = 10": dict(min_child_weight=10), "λ = 5 и γ = 20": dict(reg_lambda=5, gamma=20)}
for name, kw in configs.items():
    best, leaves = [], []
    for split in range(3):
        X_tr, X_val, y_tr, y_val = datasets.train_test_split(X, y, test_size=0.3, seed=split)
        m = GBRegressor(mode="newton", n_estimators=200, learning_rate=0.1, max_depth=5, **kw).fit(X_tr, y_tr, eval_set=(X_val, y_val))
        best.append(min(m.history_["eval"]))
        leaves.append(np.mean([t.n_leaves for (t,) in m.trees_]))
    print(f"{name:22s} лучшая ½MSE {np.mean(best):.3f}, листьев в среднем {np.mean(leaves):.1f}")

Итоги

  1. Структуру дерева ограничивают глубина, число листьев, минимум объектов и гессианов в листе.
  2. λ сжимает веса листьев к нулю (сильнее — маленькие листья), α обнуляет слабые листья, γ запрещает невыгодные разбиения.
  3. Все формулы — из регуляризованной цели XGBoost (урок 8.2).
