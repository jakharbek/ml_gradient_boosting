# Урок 7.1. Ранняя остановка и число итераций

> Как выбрать число деревьев: следить за валидацией, терпеть немного и вернуться к лучшей итерации

**Модуль:** [7. Регуляризация градиентного бустинга](../lesson_7/README.md) · **Уровень:** Средний · **Время:** ~35 мин

**Нужно знать:** [7 Регуляризация градиентного бустинга](../lesson_7/README.md), [4.2 Темп обучения и число деревьев](../lesson_4_2/README.md)

Кривая валидации, лучшая итерация, правило терпения (patience / early_stopping_rounds), шумная валидация и её риски, выбор числа деревьев кросс-валидацией, API в библиотеках.

## После урока вы сможете

- реализовать раннюю остановку с терпением и возвратом к лучшей итерации
- выбрать значение терпения с учётом шума валидации и темпа обучения
- подобрать число деревьев кросс-валидацией для финального обучения на всех данных
- использовать раннюю остановку в scikit-learn, XGBoost, LightGBM, CatBoost

## Как работать с уроком

1. Откройте `web/index.html` в браузере (или запустите `python tools/serve.py` из корня курса).
   Все графики интерактивны; ячейки Python выполняются прямо на странице.
2. Повторите всё в ноутбуке: `jupyter lab` из корня курса → откройте файл из `jupyter_notebooks/`.
3. Запустите примеры: `python lessons/lesson_7_1/examples/<файл>.py`.
4. Решите упражнения из `exercises/` и сверьтесь с решениями.
