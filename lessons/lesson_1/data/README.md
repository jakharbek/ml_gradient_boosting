# Данные урока 1

Все наборы детерминированы: их можно пересоздать в Python или получить в веб-уроке
с теми же параметрами (генератор Mulberry32 одинаков в JS и Python).

## `wave.csv` — Волна с трендом: 60 точек

Тот самый набор из анимации на главной странице: y = sin(x) + 0.3x + шум.

- Столбцы: `x`, `y`; строк: 60.
- Как получить в Python: `datasets.regression_1d(kind='wave', n=60, noise=0.35, seed=7)`
