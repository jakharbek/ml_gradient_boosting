Зачем это нужно

Прогноз без меры неуверенности опасен: «спрос 120 штук» и «спрос 120 ± 80 штук» ведут к разным решениям. Для классификации мера неуверенности — сама вероятность, если она честная. Для регрессии — интервал, который накрывает ответ с обещанной частотой. Этот урок о том, как получить и то и другое.

Калибровка вероятностей

Если вероятности модели нечестные (урок ), их можно исправить монотонным преобразованием, обученным на отложенной калибровочной выборке. Ранжирование при этом не меняется.

Метод Платта

Логистическая регрессия на логите модели: $p' = \sigma(a F(x) + b)$. Два параметра — мало данных нужно, переобучиться трудно. Если $a < 1$, модель была самоуверенной и логиты «сжимаются».

Изотоническая регрессия

Произвольная неубывающая ступенчатая функция $p' = g(p)$, подобранная алгоритмом PAV (объединение соседних нарушителей порядка). Гибче Платта, но на малой калибровочной выборке переобучается и выдаёт вероятности ровно 0 и 1.

Опыт (ноутбук урока): переобученный бустинг из урока 13 (500 деревьев, ν = 0.3), калибровочная выборка — 300 объектов, тест — 3000. Без калибровки ECE 0.130, log-loss 1.232. Платт: ECE 0.027, log-loss 0.367; найденный наклон $a = 0.16$ — логиты модели были примерно вшестеро самоувереннее, чем нужно. Изотоническая: ECE 0.038, но log-loss лишь 0.645 — на 300 объектах она выдаёт слишком резкие вероятности, и редкие ошибки при $p' = 0$ или $1$ дорого стоят. Платт — строго возрастающее преобразование: порядок объектов и AUC прежние (0.918). Точность при пороге 0.5 может немного сдвинуться (0.853 → 0.851): граница $p' = 0.5$ соответствует уже другому значению логита. Изотоническая функция ступенчатая и объединяет соседние объекты в группы с одинаковым прогнозом. Поэтому AUC у неё чуть ниже (0.913), а точность — 0.838.

Интервалы прогноза

Квантильный бустинг

Две модели с квантильной потерей (урок ) уровней $\alpha/2$ и $1 - \alpha/2$ дают интервал с номинальным покрытием $1 - \alpha$. Ширина подстраивается под шум. Но гарантии нет: модели переобучаются и регуляризуются, и реальное покрытие отличается от номинального.

Сплит-конформный метод

Обучаем любую модель $\hat f$. На отдельной калибровочной выборке считаем остатки $|y_i - \hat f(x_i)|$ и берём их квантиль $q$ уровня $\lceil (n+1)(1-\alpha) \rceil / n$. Интервал $\hat f(x) \pm q$ накрывает новый ответ с вероятностью не меньше $1 - \alpha$ — гарантированно, если объекты перестановочны (например, независимы и одинаково распределены). Минус: ширина одинакова везде.

CQR: конформализованные квантили

Берём квантильный интервал $[\hat q_{lo}, \hat q_{hi}]$ и на калибровочной выборке считаем, насколько он промахивается: $E_i = \max(\hat q_{lo}(x_i) - y_i,\ y_i - \hat q_{hi}(x_i))$. Квантиль $q$ этих промахов расширяет (или сужает) интервал: $[\hat q_{lo} - q,\ \hat q_{hi} + q]$. Гарантия покрытия та же, а ширина по-прежнему подстраивается под шум (Романо и др., 2019).

Опыт (ноутбук урока): шум растёт с $x$; 1000 объектов для обучения, 500 для калибровки, 1500 для теста; цель — 90%; пять повторов. Квантильный бустинг накрыл в среднем 86.6% — меньше обещанного. Сплит-конформный — 91.5% при средней ширине 1.94. CQR — 90.9% при средней ширине 1.72: то же покрытие, но интервал уже там, где шум мал.

Гарантия конформных методов — в среднем по объектам (маргинальная), а не для каждого $x$ отдельно. И она держится, только пока новые данные похожи на калибровочные. При сдвиге распределения (урок ) покрытие может упасть.

В коде

import numpy as np
from gbcourse import datasets, GBRegressor

X, y = datasets.regression_1d(kind="hetero", n=3000, noise=0.5, seed=220)
perm = np.random.default_rng(0).permutation(len(y))       # данные упорядочены по x — перемешиваем
tr, ca, te = perm[:1000], perm[1000:1500], perm[1500:]
alpha, P = 0.1, dict(n_estimators=200, learning_rate=0.05, max_depth=3)
lo = GBRegressor(loss="quantile", quantile_alpha=alpha / 2, **P).fit(X[tr], y[tr])
hi = GBRegressor(loss="quantile", quantile_alpha=1 - alpha / 2, **P).fit(X[tr], y[tr])
E = np.maximum(lo.predict(X[ca]) - y[ca], y[ca] - hi.predict(X[ca]))
n = len(E)
q = np.quantile(E, np.ceil((n + 1) * (1 - alpha)) / n, method="higher")
for name, (L, H) in {"квантили": (lo.predict(X[te]), hi.predict(X[te])),
                     "CQR": (lo.predict(X[te]) - q, hi.predict(X[te]) + q)}.items():
    print(f"{name:9s} покрытие {np.mean((y[te] >= L) & (y[te] <= H)):.3f}, средняя ширина {np.mean(H - L):.3f}")

Итоги

  1. Калибруйте вероятности на отложенной выборке: Платт — надёжен на малых данных, изотоническая — гибче, но требует больше данных.
  2. Квантильный бустинг даёт адаптивные интервалы, но без гарантии покрытия.
  3. Конформные методы гарантируют покрытие в среднем; CQR сочетает гарантию с адаптивной шириной.
