# Урок 7.2. Стохастический бустинг: подвыборки строк и признаков

> Каждое дерево видит лишь часть объектов и признаков — модель учится медленнее, но обобщает лучше и считается быстрее

**Модуль:** [7. Регуляризация градиентного бустинга](../lesson_7/README.md) · **Уровень:** Средний · **Время:** ~35 мин

**Нужно знать:** [7.1 Ранняя остановка и число итераций](../lesson_7_1/README.md), [3.1 Бэггинг и случайный лес: уменьшаем разброс](../lesson_3_1/README.md)

Stochastic Gradient Boosting (Фридман, 2002): subsample без возвращения, colsample по дереву/уровню/узлу, почему случайность помогает только вместе с маленьким темпом, выигрыш по времени, параметры в библиотеках.

## После урока вы сможете

- объяснить механизм стохастического бустинга и его связь с бэггингом
- выбирать subsample и colsample и понимать их взаимодействие с темпом обучения
- настраивать подвыборки в scikit-learn, XGBoost, LightGBM, CatBoost
