## `linear_trend.csv` — Линейный тренд на x ∈ [0, 6]

Данные для демонстрации отсутствия экстраполяции: модели обучаются на [0, 6], прогнозируют на [0, 10].

- Столбцы: `x`, `y`; строк: 60.
- Как получить в Python: `datasets.regression_1d(kind='linear', n=60, noise=0.3, seed=8, x_max=6.0)`
